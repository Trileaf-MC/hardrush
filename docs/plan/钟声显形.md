# 钟声显形：敲钟让附近的怪物玩家发光

2026-11-24 与需求方讨论定稿。状态：已实现，待人工客户端验收。

## 背景

原版（Java 版）敲钟时，如果钟附近有袭击者，钟会发出共鸣声，随后让周围的袭击者发光几秒。HardRush 里，入侵者就是怪物玩家。本机制把怪物玩家当作“袭击者”接入原版这套逻辑，给人类一个认出怪物的反制手段。体验与原版一致：敲钟 → 共鸣 → 白色轮廓透墙亮起 3 秒。

原版依据（26.3 服务端 `BellBlockEntity`）：

- 钟被敲响时，收集周围 48 格方盒内的生物，最多每 60 tick 刷新一次。
- 敲钟后第 5 tick 起，若 32 格（球形）内有袭击者，钟开始共鸣（`block.bell.resonate`）；共鸣 40 tick 后，48 格内的袭击者获得 60 tick 发光效果。
- 原版没有冷却。手敲、投射物、红石都能敲响钟。钟无法合成。

## 规则

| 项目 | 规则 |
| --- | --- |
| 触发 | 与原版相同，手敲、投射物、红石都算。怪物自己射响钟导致自己显形，也照常生效 |
| 共鸣前提 | 钟 32 格内有怪物玩家才会共鸣。没有共鸣声，就说明附近没有怪物玩家 |
| 发光对象 | 只有钟 48 格内的怪物玩家本体。刷怪蛋召唤的随从、自然生成的怪物都不发光；原版袭击者照旧 |
| 时序与时长 | 与原版相同：敲钟约 2.25 秒后共鸣结束，怪物玩家获得原版发光效果 3 秒 |
| 冷却 | 每口钟单独冷却。某口钟让怪物玩家显形后，30 秒内再敲只响不共鸣，也不再让怪物玩家发光；原版袭击者不受影响 |
| 可见性 | 所有人都能看见，白色轮廓（原版默认）。被显形的怪物玩家自己能看到原版的发光效果图标，不另发文字提示 |
| 原版附带效果 | 村民听到钟声躲回屋里，保持原样 |
| 携带 | 钟可以挖走随身携带，任何地方都能用 |

- 冷却记在钟方块实体上，挖掉重放会清零。需求方接受这个漏洞：挖钟要花时间并且暴露自己，规则不为此复杂化。
- 不新增配置。范围和时长沿用原版；30 秒冷却是代码常量。

## 交付

- core：`BellAlarm` 存放范围、时长、冷却常量，并判断一口钟现在能否显形，配单元测试；`ShopOffer.BELL` 及其默认价格和限购；规则书新增「钟声」页。
- platforms/mc263：`MonsterBellMixin` 在原版判断“是不是袭击者”的两处，把可显形的怪物玩家也算进来；在服务端 tick 的前后标出当前是哪口钟；显形后记下冷却。`MonsterBellAlarm` 负责这些判断。`MonsterShop` 和 `RevivalSupplies` 交付钟。
- GameTest：敲钟后怪物玩家发光；冷却期间再敲不发光；人类和原版僵尸不发光。
- 人工客户端测试：透墙轮廓和共鸣声听起来是否像原版。
