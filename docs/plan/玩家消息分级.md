# 玩家消息分级

2026-11-04：定稿分级规则与文案规则。逐条文案见[玩家消息文案](玩家消息文案.md)。

## 原则

聊天栏是比赛的“史书”，只记录过一阵还值得回头翻的事；其余反馈交给游戏画面本身。

原版先例：26.3 的 `AbstractBedBlock.useWithoutItem` 中，“现在不能睡觉／附近有怪物／床被占用”等失败提示都经 `sendOverlayMessage` 发往动作栏；原版聊天栏的系统消息基本只有死亡、进度、进出服等值得记录的事件。

## 档位

| 档位 | 通道 | 用途 | 约束 |
| --- | --- | --- | --- |
| T0 静默 | 音效、粒子、物品、模型／方块变化 | 结果本身已经看得见 | 成功与失败各配音效（失败如 `VILLAGER_NO`） |
| T1 动作栏 | 统一经 `LobbyHints` 优先级系统 | 只关乎自己、现在有用、几秒后过时：失败原因、进度、下一步；特殊物品到手时的一句用法（[手持物品提示](手持物品提示.md)） | 一句一件事，最多 30 字；同原因限流；不绕过 `LobbyHints` 直接发包 |
| T2 标题 | 标题＋副标题 | 每局只发生少数几次的身份转折（见下） | 不与聊天重复同一件事 |
| T3 Boss 栏 | 现有阶段条 | 持续状态与倒计时：救场、庆祝、恢复隔离、复生仪式 | 同时只显示一条；时间用进度条表示，只有要读秒做决定时才写秒数，精确数字放 TAB 栏 |
| T4 个人聊天 | 仅本人 | 之后还要查、画面上看不到：资格变化、离线期间换轮 | 一条一句，每人每轮个位数 |
| T5 全服聊天 | 广播 | 比赛大事 | 不重复原版死亡消息；一件事一条 |

### T2 白名单

只用于每局发生次数很少的事件：

- 复生完成
- 人类阵亡、回到营地（此时尚未选择怪物角色，标题与文案不得称其已变成怪物）
- 本轮胜利／失败（全员）
- 黄昏契约生效／解除
- 庆祝开始（按身份）

怪物出击、返回营地、循迹等可能反复发生的事件不用标题。新增 T2 事件需先经确认。

### T5 白名单

- 回合结果（失败／中止／通关：结果＋用时）
- 管理员在线恢复等干预
- 某玩家在祭坛复生
- 某玩家中途加入

新增 T5 事件需先经确认。

## 判定顺序

1. 画面或音效已经说明结果 → T0
2. 规则或操作说明 → 物品描述＋手持提示（描述第一行即手持时动作栏的那句用法）、规则讲台的书，或每人每轮首次遇到时 T1 提示一次；任何时候都不进聊天栏
3. 只对自己有用、十秒后过时 → T1
4. 持续状态或倒计时 → T3
5. 在 T2 白名单内 → T2
6. 十分钟后还想回翻 → 关乎自己 T4，关乎所有人且在 T5 白名单内 → T5

## 硬规则

- 内部错误（异常、存储、档案、适配器）写日志并通知管理员；玩家只得到一条泛化提示（T1；需要持续可查时 T4）和失败音效。
- `RoundSession.Reply.message()` 不直接展示给玩家，改为返回原因码，由平台层把原因码映射到档位和文案。
- 玩家可见文本禁用系统词：档案、核验、提交、持久化、身份、生命（指“生命序号”这类内部概念；原版用语“生命值”可以用）、适配器、预算、原因码、毫秒等。
- 首次教学提示按“每人每轮一次”记录，不跨轮持久化。

## 文案风格

基调是“世界叙事”：主语是游戏里的东西（罗盘、祭坛、女巫），不是“系统”。按场合和“原版克制”混用，不玩网络梗：

| 场合 | 风格 |
| --- | --- |
| 动作栏里反复出现的失败、冷却、操作提示 | 原版克制：短、平、直接 |
| 标题、全服聊天、女巫等角色台词 | 世界叙事，可以带氛围 |
| 资格、退出、处罚等事关公平的个人聊天 | 原版克制，严肃，不加修辞 |

### 准确性优先

氛围不能以失真或含糊为代价。

- **只说系统真正判定出来的事。** 系统不知道原因时，只说观察到的结果，不替玩家编原因。例如找不到出击位置，不能说成“目标藏得太好”：目标可能只是在海上全速航行，怪物还能附身观战看到这一点。
- **主语和身份必须明确。** 全服消息里，凡是人类和怪物都可能做的事，都要写清是谁、以什么身份。例如写“Bob 作为人类中途加入了挑战”，不写“Bob 踏入了这片荒野”。
- **状态要能直接读懂。** 动词要说清楚现在是进行中、已完成还是已取消，例如写“正在寻找出击位置”，不写“嗅到了气味”这种玩家不知道算不算在追踪的说法。
- **阵亡不等于变成怪物。** 人类阵亡后、在展位选好角色之前，不写他已经“化身”或“变成了怪物”。

### 写法

1. 不用公文腔：不写“请”“操作未受理”，少用“已……”开头。
2. 只说现在该做什么，不解释为什么不行；完整规则放进物品描述或规则讲台的书。
3. 一句话只讲一件事。最多用一个“·”连接“状态 · 怎么操作”。
4. 数字按人能读的方式写：用时写 `h:mm:ss`，钟点写服务器本地时间 `HH:mm`；秒数只用于倒计时；不出现毫秒、ISO 时间戳、UUID、原因码或异常信息。
5. 标点用中文全角；动作栏和标题句末不加句号；省略号统一写“……”。

### 格式与颜色

基调偏硬核、竞技：少用彩色，用明暗对比突出关键信息。

- 正文用灰色，关键信息用白色。关键信息包括玩家名、数字、物品名和结果词。分隔符“·”用深灰色。
- 标题用白色，副标题用灰色。
- 彩色只保留一处：怪物币沿用现有物品的绿色。失败不用红色，失败已经有音效提示。
- 粗体只用于标题，以及全服消息里的玩家名。

## 术语表

玩家可见的文本统一使用左列的叫法，右列的叫法不再出现。

| 统一叫法 | 指什么 | 不再使用 |
| --- | --- | --- |
| 营地 | 两轮之间所有人所在的独立世界，阵亡的人类也回到这里 | 大厅、独立大厅、正式大厅 |
| 集结区 | 营地里人类准备开局、中途加入的圆圈 | 中途门、加入区 |
| 庭院 | 营地东侧怪物活动的区域（角色展位、目标模型、女巫、宝库都在这里） | 怪物大厅、怪物营地、追猎庭院 |
| 角色展位 | 选择僵尸／骷髅／苦力怕的三座模型 | 角色模型、展位（单独使用时） |
| 目标模型 | 庭院里代表在场人类、右键即可发起追猎的模型 | 投影、目标展位 |
| 挑战世界 | 本轮的生存世界（含下界、末地） | 荒野（仅描述落点时可用）、比赛世界 |
| 人类 | 仍在挑战中的玩家 | 在赛人类、人类身份 |
| 怪物 | 已在展位选好角色的玩家 | 大厅怪物、营地怪物 |
| 阵亡的玩家 | 阵亡后回到营地、还没选角色的人类 | 怪物（选角之前） |
| 出击 | 怪物从庭院传送到目标附近 | 出场 |
| 追猎 | 从选目标到出击的整个过程 | 搜索、提交 |
| 返回营地 | 怪物用回响碎片站定若干秒回到庭院 | 归返、归返引导 |
| 暂存 | 返回营地后保留本次出击的物资、装备和身价，下次以同一角色出击时带上 | 停放、暂存的出场 |
| 循迹 | 用追迹罗盘传送到目标附近 | 重新循迹 |
| 复生、复生图腾、复生祭坛 | 怪物站上祭坛重新成为人类 | 复生资格、复生次数（物品数量即次数） |
| 救场 | 没有人类还在玩（全部阵亡，或剩下的人类全部离线）时，留给复生、中途加入或离线人类重连的倒计时阶段 | 救场期 |
| 极限挑战 | 人类阵亡后可以选择怪物角色继续参与的游戏模式 | 极限模式、HARDCORE |
| 身价 | 怪物出击时身上的价值，决定击杀它的奖励 | — |
| 收编 | 用拘魂袋把生物收进去 | 收入、捕捉 |
| 战绩书、第 N 卷 | 书屋发放的每轮成书，第 1 卷是结果与榜单，之后各卷是参赛名单 | 历史成书、主册、分卷、书册 |
| 退出本轮、取消资格 | 主动离开本轮与被管理员处罚 | 观战身份、WITHDRAWN／DISQUALIFIED |

## 场景归档

| 场景 | 档位 |
| --- | --- |
| **进服** 掉线重连，回到原位继续 | T0 |
| 离线期间换轮 | T4 |
| 异常重启、无存档点 | T3（恢复条），管理员另收详情 |
| 存档读取失败 | T4 泛化（需要持续可查），管理员另收详情 |
| **集结** 准备、取消准备、就绪 | T0（粒子＋音效），倒计时 T3 |
| 中途加入 | T5 广播；本人不另发 |
| 加入失败 | T1 |
| **营地** 选角成功 | T0，规则放物品描述 |
| 改选将放弃暂存的出击 | T1（需再点一次确认） |
| 翻页 | T0 |
| 不能选角、庭院未开放、女巫／宝库拒绝 | T1＋失败音效 |
| 购买成功、宝库开出 | T0 |
| 丢出、拾取 | T0；丢出者在线时收 T1 |
| **追猎** 寻找出击位置、等待、冷却 | T1（与现有动作栏合并，删聊天） |
| 找不到出击位置、复检退回出击机会 | T1＋失败音效 |
| 目标在海上、建议改用僵尸 | T1，每次追猎一次 |
| 出击成功 | T1＋音效 |
| 溺尸三叉戟说明 | 物品描述 |
| 出击冷却结束 | T0 音效＋T1 |
| **出击中** 返回营地／循迹开始、中断 | T1（删除重复聊天） |
| 返回营地完成 | T1（暂存与冷却在画面上看不到） |
| 循迹完成 | T0；落点退而求其次时 T1 |
| 罗盘不可用、循迹失败 | T1（罗盘发光本身是 T0） |
| 技能被拒、技能出错 | T1；出错时管理员另收详情 |
| 拘魂袋各类失败 | T1 |
| 浸水／粉雪转化 | T0 |
| 怪物出击中阵亡回营 | T1 |
| **复生** 复生次数增加、被召回祭坛 | T1（图腾数量变化是 T0） |
| 持有复生却去选角／追猎 | T1 |
| 复生完成 | 本人 T2，全服 T5 |
| **阵亡** 人类阵亡、回到营地 | T2；在营地选角之前不称其为怪物 |
| **资格** 主动退出、取消资格 | T4，一句 |
| **结局** 失败、中止、通关 | T5 一句＋全员 T2；庆祝规则交给 T3 |
| 庆祝开始 | T2，与通关标题合并为一次，不连发两个标题 |
| 庆祝结束 | T0（所有人回到营地，不另行宣布） |
| 黄昏契约生效／解除 | T2（现状） |
| 管理员在线恢复 | T5 一句 |
| **命令回复** | 保持聊天，只改文案 |
