# 怪物归返：暂离与引导体验

2026-11-02 与需求方讨论定稿。起因见[归返受阻与脱困排查](../人工客户端测试/怪物归返受阻与脱困.md)。

## 1. 引导打断规则（修复“生不得死不得”）

原规则：位置偏离起点 0.001 格即中断。水流、气泡柱或随从推挤造成的被动位移也会打断；玩家僵尸／骷髅不怕日晒、能在水下呼吸、不会饥饿，因此可能既无法归返也无法死亡。

新规则（归返与循迹相同）：

| 打断 | 不打断 |
| --- | --- |
| 按住方向键或跳跃（服务端读取原版 `ServerboundPlayerInputPacket` 的按键状态） | 水流、气泡柱、生物推挤、无伤害击退等被动位移 |
| 攻击实体或方块、使用其他物品或技能、受到伤害 | 潜行、转动视角 |
| 切换维度、身份或阶段变化、苦力怕膨胀 | 手持归返物或罗盘右键实体（与对空气使用相同，不打断也不重启） |

- 按住方向键时发起引导，直接拒绝并提示先停下。
- 已经在引导时再次使用，不重复提示、不重启。
- 提示文字中的秒数读取配置 `monster.returnChannelMillis`，不再写死“5 秒”。

## 2. 引导表现

归返以重生锚为主题（回到自己的重生点）：

| 时刻 | 本人 | 附近所有人 |
| --- | --- | --- |
| 开始 | 回响碎片出现覆盖引导时长的原版物品冷却遮罩，白色扫掠即进度；动作栏显示剩余秒数 | 重生锚充能音；身体周围冒反向传送门粒子 |
| 引导时长的 1/4、2/4、3/4 | 同左 | 再响一次充能音，音调逐级升高，粒子逐级变密（对应重生锚 1–4 级充能） |
| 完成 | 在营地听到重生锚耗尽音 | 离开处爆散一圈反向传送门粒子，并播放耗尽音 |
| 打断 | 冷却遮罩立即消失，动作栏显示原因 | 信标熄灭音，加少量烟雾 |

循迹使用幽匿主题（幽匿之魂粒子、幽匿感测体咔哒音，节奏相同）；落地沿用现有的物种出场环境音。

## 3. 暂离模型

主动归返是“暂离”，本次出场延续；阵亡、断线、复生优先召回、统一回大厅才是“出场结束”。

| | 主动归返（暂离） | 出场结束 |
| --- | --- | --- |
| 再次追猎冷却 | `monster.returnCooldownMillis`，默认 0 | `monster.deployCooldownMillis`，默认 30 秒（原先是硬编码常量，配置不生效） |
| 绑定物品：出生装备、角色蛋余量、技能物品、宝库装备、药箭、引爆器、归返物、罗盘 | 原样暂存，下次出场按原位置恢复，耐久和数量不变 | 清除 |
| 自己捡到的世界物资（包括捡来穿上的护甲） | 在归返原地掉落一次 | 按原规则结清 |
| 形态（溺尸、流浪者）、苦力怕带电 | 保留 | 重置 |
| 药水效果、着火 | 清除 | 清除 |
| 血量 | 营地身体沿用归返时的血量，靠营地（和平难度）的原版自然回血恢复，每秒 1 点 | 满血 |
| 身价等级、每名人类的伤害上限、商店限购与价格阶梯 | 延续本次出场 | 重置 |
| 随从 | 照常清理 | 照常清理 |

暂离期间：
- 女巫商店和宝库照常开放。新买的消耗品在下次出场时叠加（蛋叠加到角色蛋上，药箭放入背包，药水在出场时生效）。新抽到的宝库装备作为备用件放进背包，不替换身上穿的。
- 在展位改选其他角色时，需在 5 秒内再右键一次确认，确认后暂存作废；改选同一角色不受影响。复生或退出本轮同样作废暂存。
- 断线不影响暂存，重连后回到营地仍然保留。
- 营地动作栏提示暂存状态，例如“上次出场已暂存：带电苦力怕 · 身价 18 级；右键目标继续追猎”。
- 暂存写入本轮存档，停服或崩溃后仍然保留。如果暂存的身体数据损坏或超出大小上限，按新出场发放出生物资，不阻塞出场。

## 4. 其他

- 出场与循迹落点按站立高度检查容纳空间，不再接受只有蹲姿才能容纳的位置。
