# 怪物环境变种

2026-11-27 与需求方讨论定稿。状态：已实现（2026-11-27），GameTest 覆盖，待人工客户端验收。

本文写给实现者，读完即可动手，不需要再看讨论记录。文中的行号是 2026-11-27 的位置，以代码为准。

## 背景

怪物玩家的"形态"（`MonsterForm`）只换身体、不换角色：僵尸系现有僵尸、溺尸，骷髅系现有骷髅、流浪者。目前只有两种触发：

- 落点在水下，僵尸直接以溺尸出场（`MonsterRoles.riseFromSea`）。
- 出击途中泡水约 5 秒变溺尸、陷细雪变流浪者（`MonsterRoles.updateEnvironment`）。

流浪者只能靠细雪获得，实际几乎遇不到；尸壳、沼骸、焦骸、僵尸猪灵完全没有。

原版里这些变种都由环境决定：沙漠刷尸壳和焦骸，雪原刷流浪者，沼泽刷沼骸，下界刷僵尸猪灵而根本不刷僵尸。让怪物玩家也遵守这条规则，人类凭原版常识就能预判"在沙漠追我的是尸壳"，不需要学新规则。

## 讨论结论

| 问题 | 结论 |
| --- | --- |
| 必定还是按原版权重随机 | **必定**。对战双方都需要能预判 |
| 何时判定 | **只在落地时**（出场、暂离后恢复、重新循迹）。途中走进别的群系不变，原版也没有这种转化 |
| 雪地范围 | **放宽**：落点处下的是雪就算，不限于原版只刷流浪者的雪原和冰刺之地 |
| 沙漠地下、室内 | **照搬原版的露天要求**：不露天就是基础形态 |
| 已是变种时再次落地 | **保留**，变种持续到本次出击结束。只有基础形态（僵尸、骷髅）才随落点变 |
| 流浪者的缓慢 | 原版 30 秒，**缩短到 10 秒** |
| 焦骸的虚弱 | 原版 30 秒，**缩短到 10 秒** |
| 沼骸的中毒 | 原版 5 秒，不改 |
| 沼骸、焦骸的代价 | 照搬原版：血量 16（基础 20）、射速更慢 |
| 僵尸猪灵 | 做。免疫火焰和熔岩、自带金剑、群体仇恨都做 |
| 僵尸猪灵随从 | **对人类中立**，不听主人的协攻指令；人类打了任意一只僵尸猪灵才群起攻之 |
| 群体仇恨的范围 | 人类打僵尸猪灵玩家本体也算；**野生的僵尸猪灵同样响应** |

不做：

- 凋灵骷髅（下界要塞）：近战加凋零，等于换了整套玩法。
- 僵尸村民：只有外观差异。
- 苦力怕没有群系变种，不变。
- 焦骸在原版免疫虚弱，这里不实现：怪物玩家很少中虚弱，不值得为它加一条规则。
- 蘑菇岛、深暗之域在原版不刷怪，这里不照搬，否则成了人类的安全区。

## 规则

### 1. 落地时的形态

出场、暂离后恢复、重新循迹，凡是把怪物玩家放到新落点的时刻都判定一次，只有一处例外：重新循迹落入水中不立即变溺尸，沿用[追猎出场与重新循迹](追猎出场与重新循迹.md)的既有规则（保持原形态，之后照常按环境转化），表中其余各条照常判定。按表从上到下取第一条满足的。

| 角色 | 当前形态 | 落点条件 | 结果 |
| --- | --- | --- | --- |
| 僵尸 | 任意僵尸系形态 | 水下落点（`SafeDeployment.Result.submerged()`） | 溺尸 |
| 僵尸 | 僵尸 | 下界（用 `RoundWorldRouting.semanticDimension`，不要用 `level.dimension()`） | 僵尸猪灵 |
| 僵尸 | 僵尸 | 群系怪物生成表里有尸壳，且落点露天 | 尸壳 |
| 骷髅 | 骷髅 | 落点处降水为雪，且落点露天 | 流浪者 |
| 骷髅 | 骷髅 | 群系怪物生成表里有焦骸，且落点露天 | 焦骸 |
| 骷髅 | 骷髅 | 群系怪物生成表里有沼骸（不要求露天） | 沼骸 |
| 其余 | — | — | 不变 |

说明：

- **水下落点是唯一会改掉变种的情况**：尸壳、僵尸猪灵在水下落地也变溺尸，否则在水里没法作战。现有行为里"暂存的溺尸在水下恢复时保持溺尸"不变。
- **群系怪物生成表**读原版数据，不手写群系名单：`level.environmentAttributes().getValue(EnvironmentAttributes.NATURAL_MOB_SPAWNS, pos).getMobsToSpawn(MobCategory.MONSTER)`，看其中有没有对应的 `EntityType`。26.3 的数据里尸壳、焦骸只在沙漠，沼骸只在沼泽和红树林沼泽。
- **降水为雪**：`level.getBiome(pos).value().getPrecipitationAt(pos, level.getSeaLevel()) == Biome.Precipitation.SNOW`。雪山、雪林、冻洋、温带高山雪线以上都算。
- **露天**：`level.canSeeSky(pos)`，`pos` 取落点脚下那一格。破石而出的落点（`burrowed`）在石头里，自然不露天。
- 僵尸走传送门进下界不会变；下一次循迹落在下界才变。僵尸猪灵走回主世界保持形态。

落地变种时给本人一条提示，写法跟现有的"已化身溺尸，从水下出击"一致，例如"已化身尸壳出击"。不发聊天消息。

### 2. 途中转化

| 当前形态 | 条件 | 结果 | 依据 |
| --- | --- | --- | --- |
| 僵尸 | 眼睛在水里，持续现有时长 | 溺尸 | 现有 |
| 骷髅 | 陷在细雪里，持续现有时长 | 流浪者 | 现有 |
| 尸壳 | 眼睛在水里，持续现有时长 | **僵尸**（再泡才变溺尸） | 原版 `Husk.convertsToWhenDrowning` 返回僵尸 |
| 僵尸猪灵 | — | 不转化 | 原版 `ZombifiedPiglin.convertsInWater` 返回 false |

尸壳变回僵尸时播放 `SoundEvents.HUSK_CONVERTED_TO_ZOMBIE`。首次泡水的提示改成"泡在水里会慢慢变回僵尸"。

### 3. 各形态的特性

| 形态 | 特性 |
| --- | --- |
| 尸壳 | 空手命中附加饥饿。近战本来就走原版模型的 `doHurtTarget`（`MonsterRoles.java:808`），不需要额外代码，只需测试确认 |
| 流浪者 | 箭附缓慢，时长改为 200 tick。细雪转化来的流浪者同样适用 |
| 沼骸 | 箭附中毒 100 tick（原版值）；最大生命为骷髅配置值的 80%；射击间隔见下 |
| 焦骸 | 箭附虚弱，时长改为 200 tick；最大生命为骷髅配置值的 80%；射击间隔见下 |
| 僵尸猪灵 | 见第 4 节 |

- **最大生命**：在 `bind` 里用 `skeleton.maxHealth` 乘形态的系数（沼骸、焦骸 0.8，其余 1.0），不要写死 16。
- **射击间隔**：现在 `MonsterRoles.shoot` 写死了困难 20、其余 40 tick。改为读原版模型的 `getHardAttackInterval()` 和 `getAttackInterval()`（在 `MonsterSkeletonAccessor` 上加调用器）。骷髅、流浪者得到 20/40，沼骸、焦骸得到 50/70。三连射的冷却和间隔不变。
- **药效时长**：只改怪物玩家射出的箭，在 `MonsterRoles.shoot` 取到箭之后处理，不要用 mixin 改掉野生流浪者和焦骸的箭。只缩短形态自带的效果，不动买来的药箭带的效果。
- **买来的药箭**：`selectedArrow` 现在优先射买来的药箭。形态已经自带同种效果时跳过它们，留在背包里不消耗：流浪者跳过缓慢药箭，沼骸跳过剧毒药箭。商店不做改动，因为购买时还不知道会落成什么形态。

所有僵尸系形态仍然是僵尸角色：拘魂袋、怪物盲盒、破笼、挖掘、药水盲盒的池子都照僵尸处理。骷髅系同理。

### 4. 僵尸猪灵

**本体**

- 免疫火焰和熔岩：和原版僵尸猪灵一样原生免疫（`EntityType.fireImmune`），不用抗火效果。处于该形态的怪物玩家 `Entity.fireImmune()` 返回 true（`MonsterFireImmuneMixin`），于是不会着火，也不受火、熔岩、岩浆块伤害。理由：用抗火效果时玩家身上仍会着火，别人看到燃烧的模型就知道这只是玩家；而且不占用药水效果，自己喝的抗火照常生效、照常暂存。离开僵尸猪灵形态（变溺尸、出场结束）即不再免疫。
- 金剑：落地时发一把绑定的金剑到手上，原来手里的东西挪到背包。金剑设为不可损坏（金剑只有 32 点耐久，原版怪物也不消耗武器耐久）。暂存、恢复时跟随身体。实现上把现有的 `seaTrident` 推广成"形态武器"：溺尸是三叉戟，僵尸猪灵是金剑。
- 基础攻击仍用 `zombie.baseMeleeDamage`（默认 3），**不**采用原版僵尸猪灵的 5。持金剑时总伤害是 3 + 3 = 6，空手僵尸是 3。
- 移速、生命、护甲照僵尸配置，不改。
- 刷怪蛋是僵尸猪灵蛋。

**随从（僵尸猪灵蛋孵出的）**

- 跟随主人，照现有随从的做法。
- **不听协攻指令**：`MonsterCompanions.onOwnerAttack` 跳过僵尸猪灵随从。
- 对人类中立，直到被激怒。原版 `ZombifiedPiglin.addBehaviourGoals` 本身就只在愤怒时索敌，实现时确认 `MonsterCompanions.configure` 没有给它加上主动索敌的目标。
- 出击结束时照常清理。

**群体仇恨**

原版机制（26.3 `ZombifiedPiglin`）：一只僵尸猪灵有了目标之后，每 4–6 秒在能看见目标时呼叫一次；范围是以自己为中心水平 35 格（跟随范围属性）、垂直 10 格；被呼叫的是范围内**还没有目标**的僵尸猪灵，直接 `setTarget` 成同一个目标。

落到本模组：

1. 人类打随从或野生的僵尸猪灵：原版自己会处理，不需要代码。随从是真实的 `ZombifiedPiglin`，会被原版的呼叫带上。
2. 人类打**僵尸猪灵玩家本体**：玩家不是 `ZombifiedPiglin`，原版不会触发，需要模拟一次呼叫。
   - 触发条件：僵尸猪灵形态的怪物玩家受到伤害，伤害归属于一名人类玩家，且只认主动攻击（近战和投射物；荆棘反伤不算，否则怪物可以去打穿荆棘甲的人，把整群引到没动手的人身上），且这名人类是合法目标（`MonsterRoles.legalTarget`，不在保护期）。
   - 动作：取以怪物玩家为中心、水平 35 格、垂直 10 格内所有 `ZombifiedPiglin`，筛掉已有目标的，对其余的调用 `setTarget(人类)`。野生的和随从都算。
   - 要求怪物玩家能看见那名人类（`hasLineOfSight`）。
   - 同一个怪物玩家每 80 tick 最多呼叫一次。
   - 之后的连锁传播交给原版：被叫到的僵尸猪灵有了目标，自己会继续呼叫别的。
3. 怪物之间的误伤不触发。
4. 被激怒的野生僵尸猪灵仍是野生的：不算随从，击杀功劳不归怪物玩家，出击结束时不清理，何时消气由原版决定。

愤怒的叫声和加速都是原版自带的，人类听得出来。

### 5. 跟随形态的表现

下列内容都按形态区分，新形态各用自己的：

- 伪装的实体类型、本人皮肤和 TAB 头像。
- 环境音（重新循迹时的低吼）、受伤音、死亡音。
- 死亡消息里的形态名（`DeathNarration` 用 `form.type`，新形态自动生效）。
- 营地里暂存身体的名称。
- 骷髅系的弓名：沼骸之弓、焦骸之弓。
- 刷怪蛋的物品和名称。
- 被击杀时的原版掉落（`MonsterNativeLoot` 按模型取战利品表，确认新形态生效）。

**皮肤**：`platforms/mc263/src/main/resources/hardrush/monster-skins.json` 里的皮肤是带 Mojang 签名的纹理。`husk`、`bogged`、`parched`、`zombified_piglin` 四条已于 2026-11-27 补齐：由 `scripts/OwnerSkinGenerator.java` 从原版贴图生成，经 MineSkin 以不公开条目上传，来源记在 `THIRD-PARTY.md`。沼骸、焦骸沿用骷髅皮肤的画法，苔藓和破布画在外层；尸壳把右肢镜像成左肢；僵尸猪灵的头从 10 像素宽裁到 8 像素，鼻子画在帽子层，耳朵没有。以后新增的形态在拿到皮肤之前回退到基础形态的皮肤，不会报错。伪装给其他玩家看到的实体模型不受影响，那是原版实体。

## 实现

### 第一步：整理 `MonsterForm`（先做，单独提交）

现状：加一种形态要改 8 个文件里的 `switch` 和硬编码判断。这次要加 4 种，先把形态的属性收进枚举本身，之后加形态只改一处。这一步不改变任何行为，现有测试应全部通过。

`MonsterForm` 新增这些属性，取代散落的判断：

| 属性 | 取代的位置 |
| --- | --- |
| 中文名 | `MonsterParking.describe`（:103） |
| 环境音、受伤音、死亡音 | `HuntRetracks.announce`（:161）、`MonsterRoles.hurtSound` / `deathSound`（:600–612） |
| 弓名（非骷髅系为空） | `MonsterBowDisplay.bowName`（:50） |
| 刷怪蛋物品（非僵尸系为空） | `MonsterCompanions.egg`、`heldHint`、`usableEgg`、`spawn` 里对 `ZOMBIE_SPAWN_EGG` / `DROWNED_SPAWN_EGG` 的判断；`MonsterRoles` 里所有 `role.form == MonsterForm.DROWNED` 传给 `egg(...)` 的地方（:262、:343、:369） |
| 是否基础形态 | `MonsterRoles.select` 里拒绝直接选变种的判断（:177） |
| 泡水、陷细雪时转化成什么，以及转化音效 | `MonsterRoles.updateEnvironment`（:619–625）、`convert`（:681） |
| 形态武器（溺尸为三叉戟） | `MonsterRoles.seaTrident` 及其调用处（:282、:665–678） |
| 最大生命系数 | `MonsterRoles.bind`（:1061） |
| 箭自带的效果及时长上限 | `MonsterRoles.shoot`（:938 起） |

另外两处：

- `MonsterDisguise.apply`（:52–60）用字符串 `switch` 把形态 id 映射成实体类型。改成直接从 `MonsterForm` 取类型，不再维护第二份映射。
- `MonsterRoles.shotForm`（:1005）只认流浪者。改成按 id 解析任意形态，解析失败时回退到骷髅。

`convert` 里把蛋换成新形态的蛋那一段（:665–677）改成通用逻辑：任何僵尸系形态变化都把背包和光标上的蛋换成新形态的蛋。

### 第二步：落地判定

新建 `MonsterHabitat`（放在 `dev.hardrush.monster`），只做一件事：给定世界、落点、当前形态、是否水下落点，返回应有的形态（第 1 节的表）。纯判定，不改状态，方便单独测试。

接入点：

- `LobbyRuntime.completeDeployment`（:533–536）：现在只处理水下。改成调用 `MonsterHabitat`，结果与当前形态不同就 `convert`。`MonsterRoles.riseFromSea` 并入这条通用路径后删除。
- `LobbyRuntime` 重新循迹落地（:791–800）：传送成功后同样判定。
- 落地变种不播放转化音效（现有 `risen` 参数的语义），途中转化才播放。

### 第三步：新形态

在 `MonsterForm` 里加 `HUSK`、`ZOMBIFIED_PIGLIN`、`BOGGED`、`PARCHED`，按第 3 节补上特性。尸壳 → 僵尸的途中转化在这一步加。

### 第四步：僵尸猪灵的专有逻辑

原生免疫火焰、金剑、随从不协攻、群体仇恨（第 4 节）。群体仇恨的入口放在怪物玩家受伤的现有处理处，找 `MonsterCombatRuntime` 里确认伤害归属的地方接入。

实现完成后更新这些文档里列举形态的地方：[玩家消息文案](玩家消息文案.md)（规则书"角色"页、首次接触提示）、[追猎出场与重新循迹](追猎出场与重新循迹.md)（形态保留规则）、[怪物夜视](怪物夜视.md)（自带效果改为通用结构）、[拘魂袋](拘魂袋.md)（僵尸猪灵随从不协攻）。规则书文本在 `core` 的 `RuleBookText`。

## 测试

单元测试：`MonsterForm` 整理后，每个形态的属性齐全（僵尸系都有蛋，骷髅系都有弓名，变种都指向正确的角色）。

GameTest（无图形）。后台跑 GameTest 必须包一层看门狗：单次测试 10 分钟上限，单个日志 300 MB 上限，超限就结束当前工作区的 java 进程。

- 落地判定：沙漠露天得到尸壳和焦骸，沙漠有顶得到僵尸和骷髅；沼泽有顶仍得到沼骸；下雪处露天得到流浪者；下界得到僵尸猪灵；已是变种时在别的群系落地不变；尸壳水下落地变溺尸；重新循迹落地同样判定。
- 尸壳：空手命中的人类带饥饿；泡水先变僵尸，再泡变溺尸，蛋跟着换。
- 骷髅系：流浪者和焦骸的箭效果时长是 200 tick；沼骸和焦骸最大生命是配置值的 80%，射击间隔是 50/70；流浪者不消耗买来的缓慢药箭，沼骸不消耗剧毒药箭，其他组合照常消耗。
- 僵尸猪灵本体：站在火里和熔岩里不掉血、不着火，身上没有抗火效果；手持不可损坏的金剑；离开该形态后会被火伤；暂存再恢复后金剑还在。
- 僵尸猪灵随从：主人打人类时随从不动；人类打主人后，随从和附近野生的僵尸猪灵都以该人类为目标；人类打随从同样触发；怪物之间误伤不触发；处于保护期的人类不会被设为目标；出击结束后随从被清理、野生的留下。
- 现有的 `MonsterSeaGameTest`、`MonsterRoleGameTest`、`MonsterCompanionGameTest`、`MonsterAppearanceGameTest`、`MonsterNativeWeaponsGameTest` 全部通过。

## 原版依据

均来自 Minecraft Java 26.3 服务端 JAR，用 `.agents/skills/minecraft-knowledge` 查证。

- 群系怪物生成表（`data/minecraft/worldgen/biome/*.json` 的 `gameplay/natural_mob_spawns`）：尸壳只在沙漠（权重 80，僵尸 19）；焦骸只在沙漠（50，骷髅 50）；沼骸在沼泽、红树林沼泽（各 30）；流浪者在雪原、冰刺之地（各 80）；僵尸猪灵在下界荒地（100）、绯红森林（1）。下界所有群系的生成表里都没有僵尸。
- 生成位置规则（`SpawnPlacements`）：尸壳、焦骸用 `Monster.checkSurfaceMonstersSpawnRules`，要求 `canSeeSky`；流浪者用 `Stray.checkStraySpawnRules`，同样要求露天；沼骸用 `Monster.checkMonsterSpawnRules`，不要求。
- `Husk.doHurtTarget`：空手命中附加饥饿，时长 140 tick 乘区域难度取整。`Husk.convertsToWhenDrowning` 返回僵尸。
- `Stray.getArrow`：缓慢 600 tick。`Parched.getArrow`：虚弱 600 tick。`Bogged.getArrow`：中毒 100 tick。
- `Bogged.createAttributes`、`Parched.createAttributes`：最大生命 16。两者的 `getAttackInterval` 为 70，`getHardAttackInterval` 为 50；`AbstractSkeleton` 的默认值是 40 和 20。
- `ZombifiedPiglin`：实体类型带 `fireImmune()`；`createAttributes` 攻击 5、移速 0.23、增援概率 0；`populateDefaultEquipmentSlots` 给金剑（1/20 为金矛）；`convertsInWater` 返回 false；`addBehaviourGoals` 只在愤怒时索敌；`alertOthers`、`maybeAlertOthers` 的呼叫逻辑见第 4 节。
