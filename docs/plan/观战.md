# 观战

2026-11-03 与需求方讨论定稿。状态：已实现，待[人工客户端验收](../人工客户端测试/观战.md)。

## 背景

1. 营地里的人无法观战。观战只有“管理旁观”一种：`RoundRuntime.administrativeSpectatingAllowed` 只放行未参赛未准备的玩家（需管理员 `/gamemode`）和已退出者；营地怪物被拒，锁定的营地身体发出的旁观传送包被 `PlayerIsolationNetworkMixin` 取消。
2. 无法方便地切换目标。原版要数字键 → 传送到玩家 → 点头颅 → 被传到对方旁边 → 再左键附身；列表是 Tab 中全部非旁观玩家（按 UUID 排序），营地的人也混在里面。
3. 原版跨维度丢镜头：被附身的玩家换维度时 `ServerPlayer` 对象不变，`ServerPlayer.tick` 只同步坐标、不换世界，旁观者留在原维度。

## 1. 观战资格

| 群体 | 可观战对象 | 入口 |
| --- | --- | --- |
| 失去资格：主动退出（`WITHDRAWN`）与管理员取消资格（`DISQUALIFIED`），不区分 | 在赛人类 + 已出场怪物 | 望远镜菜单；也可左键庭院人像 |
| 营地怪物（`MONSTER_LOBBY`） | 仅在赛人类 | 仅左键庭院人像 |
| 其他营地玩家（中途入场未参赛等） | 不开放 | 左键人像时动作栏说明原因 |
| 管理员 | 维持现状，可自由飞行 | 原版 `/gamemode` |

- 在赛人类：`HUMAN_ACTIVE`、在线、存活、位于本轮世界。已出场怪物：`MONSTER_DEPLOYED`、在线、位于本轮世界。营地待命的怪物不可被观战。
- 除管理员外只能附身，不能自由飞行。进入观战立即生效，无停留确认。
- 只在挑战（RUNNING）与救场（RESCUE）阶段开放。

## 2. 失去资格的玩家

- 失去资格的那一刻（提交成功后）传回营地，落点按原版散布在营地中央周围（与其他回营地相同的 `CENTRAL` 散布），人形态（冒险模式），不再自动进入旁观。替代原有“退出后自动进入管理旁观”。
- 背包放一个绑定的「望远镜」（原版望远镜），放在快捷栏并选中；不可丢弃、转赠，本轮结束时移除。
- 营地设施（集结区、祭坛、商人、宝库）照旧拒绝，沿用现有提示。
- 管理员 `/gamemode spectator <失去资格的玩家>` 改为拒绝，提示对方使用望远镜。管理员给自己开旁观不变。
- 断线重连、正常重启后仍在营地并持有望远镜。

### 望远镜菜单

右键望远镜打开 6 行箱子界面：

- 上方：在赛人类的玩家头颅（皮肤为本人），顺序同庭院人像。
- 中间隔一行灰色玻璃板。
- 下方：已出场怪物，用原版怪物头表示——僵尸头 / 骷髅头颅 / 苦力怕头，物品名为玩家名。
- 悬停：人类显示名字与已存活时长（从本次生命开始，即最近一次入场或复生）；怪物显示名字与化身类型（如「化身：僵尸」），不显示时长。
- 打开期间每秒刷新时长与名单；点头颅即关闭界面并附身该玩家。目标已失效则刷新并在动作栏说明。

## 3. 营地怪物

- 入口只有庭院人像左键（右键仍是追猎）。瞄准人像的提示改为「右键追猎 · 左键观察」。
- 观战中**长按空格 1 秒**追猎当前附身的人类，效果等同右键其人像，进入伺机：
  - 伺机期间继续附身观看；找到出场点时直接从镜头切到出场点出场。
  - 对正在伺机的同一目标再长按 1 秒取消伺机；对另一名人类长按 1 秒改追此人并重新计时（与点人像规则一致）。
  - A/D 只换视角，不改追猎目标。
  - 长按中途松开不触发；长按进度在 Boss 栏进度条上显示，松开后恢复。
- 观战状态豁免伺机的“离开营地庭院即取消”规则。潜行退出观战回到庭院后伺机继续。
- 任何出场（伺机找到出场点等）都先结束观战。
- 观战中无法拾取同伴丢来的图腾等物品，回营后照常。

## 4. 观战中的操作与显示

| 操作 | 作用 |
| --- | --- |
| A / D | 上一位 / 下一位可观战对象（顺序同望远镜菜单：人类在前，怪物在后） |
| 潜行 | 退出观战，回到进入时的位置；该位置不再可用时，怪物回 `Landing.MONSTER`，失去资格者回 `Landing.CENTRAL`，均按原版散布 |
| 长按空格 1 秒 | 仅营地怪物：追猎当前目标（见第 3 节） |
| 数字键旁观菜单选头颅 | 合法目标直接附身，不传送到旁边；非法目标拒绝并动作栏说明 |
| 左键视野内另一玩家 | 合法目标改为附身它，非法目标忽略 |

- 目标还未被客户端追踪时镜头包会被忽略，因此附身后在第 1、3、10、20、40 tick 及之后每秒补发一次镜头包。
- 两个目标之间（目标失效的 3 秒内）观战身体没有镜头，此时拒绝移动包，不会变成自由飞行。
- 服务端依据：附身时客户端仍每 tick 上报按键变化（`Minecraft.tick` → `LocalPlayer.sendChanges` → `ServerboundPlayerInputPacket`）；旁观模式下右键、交换副手、丢弃不发包（`MultiPlayerGameMode.useItem`、`Minecraft.handleKeybinds`），因此追猎用空格而非右键。
- 原版潜行脱离附身（`Player.wantsToStopRiding` → `setCamera(this)`）改为退出观战回营。
- 个人 Boss 栏，进度为目标血量比例（人类红色、怪物紫色）：
  - 营地怪物：`正在观察 Steve · A/D 切换人选 · 长按空格追猎 · 潜行退出`
  - 失去资格者：`正在观察 Steve · A/D 切换人选 · 潜行退出`
  - 营地怪物伺机中，观察的正是追猎目标：`正在观察 Steve · 伺机追猎中 · A/D 切换人选 · 长按空格取消 · 潜行退出`；观察的是另一人：`… · 长按空格改追此人 · …`
  - 长按空格期间：黄色进度条，`按住空格追猎／改追／取消追猎 Steve…`
  - 目标失效的 3 秒内：白色空条，`Steve 已无法观察 · 即将切换人选 · 潜行退出`
- 观战者不另加动作栏常驻提示。

## 5. 自动跟随与生命周期

- 目标换维度：检测到观战者与目标不在同一世界即重新附身（`setCamera` 会跨世界传送观战身体）。
- 目标阵亡、转为怪物、退出、掉线：停约 3 秒后自动切到下一位；无可观战对象时回营并在动作栏说明。
- 结算、庆祝：释放观战者，交给现有全员集结逻辑。换轮、恢复隔离：回营。
- 观战者掉线或重启：重连后回到营地身体，不恢复附身。
- 观战身体保留营地背包原样（复生图腾、怪物币、刷怪蛋、望远镜等），旁观模式下不可用。

## 6. 被观战者

- TAB 栏（个人页脚）显示 `正在被 x 名玩家观看`，x 为附身在其身上的玩家数，含营地怪物、失去资格者与管理员；为 0 时不显示。
- 观看人数增加时，动作栏轻提醒「有玩家开始观察你」，并播放轻声 `item.spyglass.use`。同一被观战者 10 秒内最多提醒一次。
- 观战者在 Tab 中按原版旁观样式显示（灰色斜体），接受此原版表现。
