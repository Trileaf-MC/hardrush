# 追猎出场与重新循迹

定稿日期：2026-11-01。状态：已实现，自动验证通过，待[人工客户端验收](../人工客户端测试/2026-11-03-营地改版与怪物新玩法.md)。结构内优先只有加分逻辑，没有专门的自动化场景，由人工清单覆盖。

## 背景

旧出场搜索以目标为圆心，在水平 24–40 格环带取列，每列在目标 y ±8 扫描，最后取一次高度图顶面。它只校验「站得住」，不校验「走得到」与「同一空间」，导致：

1. 下界（`has_ceiling`，`logical_height=128`）的高度图顶面就是基岩顶，怪物会被放到 y≥128 上，除了归返什么都做不了。
2. 直线距离不等于路程距离：在要塞、府邸、矿井或多层建筑里，水平 24–40 格往往是墙另一侧、另一层或结构外地表。
3. 玩家怪物步行约 2.3–2.7 格/秒且不能疾跑，人类疾跑 5.6 格/秒。24–40 格直线约等于 30–50 格路程，静止的人类也要等 13–22 秒才会被接触到。

## 1. 出场点选择

### 硬约束

| 规则 | 值 |
| --- | --- |
| 路程距离 | 8–24 格，理想约 14 格，按原版寻路器（`PathFinder` + `WalkNodeEvaluator`）计算 |
| 僵尸、苦力怕 | 必须有完整路径到达目标 |
| 骷髅 | 有完整路径，或 15 格内（原版骷髅弓射程）能看见目标，二选一 |
| 与任何人类的直线距离 | ≥ 8 格 |
| 天花板维度 | 目标不在逻辑高度以上时，候选禁止位于逻辑高度及以上（下界 y≥128） |
| 保留规则 | 安全地板判定、保护区、只读已加载区块、每 tick 2ms 计算预算 |

寻路代理使用不加入世界的原版生物（体型取当前角色），能开木门，不能搭方块，最大安全落差 3 格。这是保守判定：原版生物能走的路，玩家一定能走。

### 候选来源

1. 目标足迹：每 10 tick 采样一次站地位置（不含载具、鞘翅），保留最近 60 秒，按维度分开，换维度清空。
2. 没有足迹时（刚复生、刚换维度），在目标周围 8–24 格环带取点。
3. 目标在跑时（最近约 3 秒均速超过步行），在其移动方向前方约 ±45° 范围内取点拦截。只按当前速度方向外推，不预测路线。

### 打分（在合格候选中取最高分）

- 路程接近 14 格
- 在目标视野盲区（背后约 ±60°）或视线被方块遮挡
- 目标在结构内时，位于同一结构的部件内（下界要塞、猪灵堡垒、林地府邸、废弃矿井、沙漠神殿、古城、要塞、试炼密室）
- 亮度低

### 出场表现

- 视角朝向目标。
- 目标 16 格内出场时，在出场点播放该物种原版环境音；苦力怕不出声。

## 2. 伺机出场

- 点目标模型后进入等待：营地中每 2–3 秒自动重搜，最长 60 秒；动作栏显示当前状态。
- 前 5 秒只接受完整路径。5 秒后启用兜底：取原版寻路器部分路径终点离目标最近的候选。兜底点仍须满足：与目标直线 ≤ 32 格、天花板禁令、人类最小距离、安全地板与保护区。
- 再点同一目标模型或离开营地庭院 → 取消；点另一个目标 → 改追新目标并重新计时；换角色 → 取消；购买、开宝库不受影响。
- 60 秒仍未找到，退回出场机会。

## 3. 重新循迹：追迹罗盘

- 新增绑定物品「追迹罗盘」（原版追溯指针外观），与归返营地物品并存。
- 可用条件：与目标直线 > 40 格持续 10 秒，或目标已在其他维度（立即可用）。可用时显示附魔光效。
- 右键引导 5 秒，打断规则与归返一致。完成后对原追猎目标再执行第 1 节搜索（含 5 秒后兜底），最多原地伺机约 10 秒。允许跨维度。
- 原版物品冷却 15 秒，不限次数；搜索失败不进冷却。
- 保留生命、背包、捡到的物资、身价，不回血。同维度随从自行跟随；跨维度时随从与走下界传送门一致，不跟随也不额外清理（实现时为与现有传送门行为保持一致而调整）。
- 目标阵亡或离线时失效；只在挑战、救场阶段有效。

## 5. 补充：海上追猎与归返暂存（2026-11-02 定稿）

### 海上判定

- 目标「在海上」：不站在地面上，且身处水中或乘坐浮在水上的船。站在浅水里（脚踩地面）按陆地处理。
- 航速：服务端把移动样本延长到约 10 秒（每半秒一个），取最近 5 秒的平均水平速度；≤ 2 格/秒视为「慢速」（游泳、钓鱼、漂流、偶尔挪动），否则视为全速航行。

### 各角色行为

| 情况 | 行为 |
| --- | --- |
| 骷髅、苦力怕，目标在海上 | 不出场，继续伺机（目标一靠岸，陆地规则会自动把怪物放到岸边）。动作栏「某人 在海上，正在等待它靠岸」；首次进入该状态时以淡灰色聊天消息提示一次「TIPS：现在改用僵尸出击，会化身溺尸从水下突袭」 |
| 僵尸，目标在海上全速航行 | 不出场。动作栏「某人 在海上，正在寻找最佳出击时机」 |
| 僵尸，目标在海上慢速 | 只找水中落点：身体完全在水中、头顶至少 2 格水，与目标直线 8–20 格，与目标之间视线不被方块阻隔；落地即为溺尸（不经过转化），并获得一把绑定的三叉戟 |
| 追迹罗盘 | 判断与出场相同，但落入水中时不立即变成溺尸，保持原形态（之后照常按环境转化） |

### 溺尸三叉戟

- 任何拿着三叉戟的玩家溺尸（含自然转化后捡到的世界三叉戟）都可无限投掷：投出副本，手中不减少；投出的三叉戟任何人都捡不起来；原版溺尸投掷间隔 40 tick，投掷后用原版物品冷却显示 2 秒。
- 海中出场赠送的三叉戟被玩家击杀时，按出生装备规则判定 8.5% 掉落。

### 归返暂存（修改 d41d75b）

保留花怪物币得到的升级，不保留出场中环境带来的增益；出场自带物资只保留剩余，绝不补发：

| 内容 | 归返后 |
| --- | --- |
| 带电（雷击或购买） | 保留 |
| 溺尸、流浪者等环境转化形态 | 不保留，下次出场为基础形态 |
| 海中出场赠送的三叉戟 | 不保留 |
| 购买的迅捷、抗火、再生效果 | 记录剩余时长，营地中暂停，下次出场继续 |
| 出生装备、自带蛋、购买的蛋、药箭、宝库装备 | 保留剩余，不补发（不区分自带与购买） |
| 血量、身价、伤害上限、价格阶梯 | 延续 |

新手怪物币只在成为怪物时发放一次，归返与再出场不发放，无需修改。
