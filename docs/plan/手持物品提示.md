# 手持物品提示

2026-11-13 与需求方讨论定稿，对应 [Issue #19](https://github.com/Trileaf-MC/hardrush/issues/19)。状态：已实现，待[人工客户端验收](../人工客户端测试/2026-11-03-营地改版与怪物新玩法.md)。实现时的细化见文末“实现记录”。

## 背景

引爆器、骷髅之弓等特殊物品的用法只写在物品描述里，玩家要打开背包、把鼠标悬停在物品上才看得到。期望是：玩家在快捷栏选中这件物品时，就能看到它的用法。

## 原版依据（26.3 客户端 `net.minecraft.client.gui.Hud`）

- 选中物品名（`extractSelectedItemName`）：画在 `屏幕高度 − 59`；显示 `40 tick × 通知显示时间` 选项，默认 2 秒，最后 10 tick 淡出；物品种类或显示名变化时重新计时。只显示名字，不显示描述。带 `CUSTOM_NAME` 的物品名一律加斜体。
- 动作栏（`extractOverlayMessage`）：画在 `屏幕高度 − 68`，正好在物品名上面一行；每收到一次显示 60 tick，最后 20 tick 淡出。
- 切换快捷栏：客户端每 tick 检查一次（`MultiPlayerGameMode.tick` → `ensureHasSentCarriedItem`），选中格变化就发 `ServerboundSetCarriedItemPacket`。

因此用动作栏显示用法，会和原版物品名上下贴在一起，读起来像原版自带的两行提示，原版客户端无需任何改动。

## 行为

1. **触发**：服务端每 tick 比较玩家主手物品的提示文字。上一 tick 没有提示或提示不同，而这一 tick 有提示，就显示。判断不依赖切栏包，所以这些情况都能触发：切换快捷栏、出击时系统把物品直接放到选中格（引爆器）、捡起物品进入选中格、在背包里拖动。
2. **每次都显示**：每次切到都显示，与原版物品名一致，不限次数。
3. **状态变化重新显示**：手里拿着的物品提示文字变了（弓的三连射冷却结束、罗盘亮起、拘魂袋装进一只），也算一次新的显示。
4. **立即发送**：变化当 tick 就发动作栏，不等 `PlayerFeedback` 每 5 tick 一次的刷新，这样用法和名字同时出现。
5. **时长**：占用动作栏 2 秒，与原版物品名默认时长一致。
6. **切走即清**：切到没有提示的物品或空手时，如果动作栏正显示手持提示，立刻清掉（或者换成当前优先级最高的提示），不让上一件物品的用法在新物品上方残留。
7. **优先级**：`LobbyHints.Priority` 新增 `ITEM`，排在 `READY` 和 `PROGRESS` 之间。手持提示能盖过设施、庭院引导、目标等持续提示，但不盖过返回营地或循迹的倒计时、拒绝提示（`NOTICE`）和恢复提示。被盖住时不排队补发。
8. **只看主手**，副手不提示。

## 文案

规则：一句话，不超过 30 字；不重复物品名，物品名已经由原版显示；只说怎么用，或者现在能不能用。格式与颜色遵守[玩家消息分级](玩家消息分级.md)。用法和原版一样的物品（普通武器、护甲等）不提示。

| 物品 | 手持提示 |
| --- | --- |
| 引爆器 | 按住右键引爆 · 中途松开取消 |
| 骷髅之弓／流浪者之弓 | 就绪：潜行时拉满弓松手，触发三连射；冷却中：三连射冷却中 |
| 僵尸／溺尸刷怪蛋 | 右键方块或水面，放出一只随从 |
| 拘魂袋 | 袋中 **{n}/{容量}** · 右键生物收编，右键方块放出 |
| 回响碎片 | 右键后原地不动 **{秒}** 秒，返回营地 |
| 追迹罗盘 | 发光：右键后原地不动 **{秒}** 秒，循迹到目标附近；未发光：离目标 **40** 格以上持续 **10** 秒后发光 |
| 溺尸三叉戟 | 投出的是副本，可以一直投 |
| 怪物币 | 在庭院右键女巫，购买出击增强 |
| 复生图腾 | 站上营地北侧祭坛的金块 **4** 秒复生 |
| 试炼钥匙／不祥试炼钥匙（已购） | 手持右键庭院的宝库，开出一件装备 |
| 其他已购商品 | 下次出击时自动带上 |
| 宝库装备 | 下次以 **{角色}** 出击时穿上，只用一次 |
| 观察望远镜 | 右键选择一名玩家，附身观察 |

数字（秒数、40 格、10 秒、4 秒、容量）取规则配置里的实际值，不写死。

## 文案来源

用法句与物品描述只维护一份：每件特殊物品描述的第一行就是这句用法，手持提示直接取这一行。只有弓、罗盘、拘魂袋三件物品的提示会根据状态变化，其余都是固定的用法句。

物品身份现在分散在 5 套标记里（`MonsterItems` 的 purpose、`CampKit`、`RevivalTotems`、`Spyglass`、`CampTransfers`）。实现时在 platform 层收拢出一个“物品说明”入口，统一负责给物品写名称和描述，并根据手上的物品给出提示文字。各物品在这里登记，原有的身份标记不改。

骷髅之弓的就绪／冷却状态只体现在发给客户端的显示副本上（`MonsterBowDisplay.dress`），服务端的物品本身没有这个状态，所以弓的提示要从冷却状态算出来，不能读物品描述。罗盘的发光状态写在服务端物品上（`HuntRetracks`），可以直接读。

## 同批改动

- **物品名称与描述**：[玩家消息文案](玩家消息文案.md)第二批草稿 M 节的物品名称与描述改写，与本功能一起实现。描述第一行即上表的用法句。M 节中带 ⚠ 的“已购商品”一行，实现时先核对没用完的商品是在出击后清掉，还是暂存时保留，再补一句准确的说明。
- **去掉斜体**：特殊物品的名字从 `CUSTOM_NAME` 改为 `ITEM_NAME`，与拘魂袋一致，避免原版把名字画成斜体，看起来像改过名；描述统一设成灰色、非斜体。引爆器的描述现在没有设样式，显示的是原版默认的紫色斜体。
- **去掉重复的规则说明**：删除 `LobbyRuntime.beginReturn` 里“每轮第一次返回营地时讲一次规则”的提示（以及 `returnTaught`）。玩家拿起回响碎片时已经看过同样的内容。完整流程 gametest 里对“原地不动”的断言要同步调整。
- **判定顺序**：[玩家消息分级](玩家消息分级.md)“判定顺序”第 2 条改为“物品描述＋手持提示、规则讲台的书”，T1 档的说明里补上手持提示。

## 验收

自动测试（gametest）：

- 切栏到特殊物品，以及系统直接放到选中格，当 tick 发出对应的动作栏提示；切到普通物品时清掉。
- 优先级：返回营地倒计时、拒绝提示不会被手持提示盖住；设施提示会被盖住 2 秒后恢复。
- 状态变化：手持骷髅之弓时三连射冷却结束，手持罗盘时罗盘亮起，提示都会重新显示。

人工客户端测试（追加到最新一篇待测试的文档）：用法句是否正好贴在原版物品名上方、两者时长是否合拍，以及切换过快时会不会闪烁或残留。

## 实现记录

- **仲裁器**：`LobbyHints` 新增 `flash`（只发一次、不刷新，撤回时清空动作栏）和 `render(now, refresh)`。这一改动对所有提示生效：换了来源的新提示当 tick 就发，不再等 5 tick 一次的刷新；同一来源的文字变化（倒计时）仍按刷新节奏发。
- **入口**：`lobby/HeldItemHints` 按顺序询问各物品族的 `heldHint`；`notice/ItemText` 统一写物品名（`ITEM_NAME`）和描述（与动作栏相同的灰／白标记）。“上一次显示的用法”按玩家的仲裁器记录，重连后会重新显示手里的物品。
- **文案细化**（以描述第一行为准，两处写法不一致时取描述）：
  - 回响碎片：“右键后原地不动 **{秒}** 秒，回到庭院”。名字已经是“返回营地”，不再重复。
  - 追迹罗盘未发光：“离目标 **40** 格以上持续 **10** 秒，或目标去了其他维度时发光”。补上维度条件，仍在 30 字内。
  - 拘魂袋：“袋中 **{n}/{容量}** · 右键生物收编，右键方块或水面放出”。
  - 溺尸三叉戟：“投出的是副本，可以一直投 · 每 **2** 秒一次”。
  - 怪物币：描述第一行改为用法，第二行是“共 **{n}** 枚”。
  - 复生图腾：第一行是用法；持有超过一组（99 个）时，第二行补“共 **{n}** 个”。
  - 宝库装备：护甲写“穿上”，武器等写“带上”；不能用当前角色带出时写“以 **{角色}** 出击时才会穿上／带上”。
  - 已购商品（M 节的 ⚠）：按 `MonsterWallet.deploy/park/endSortie` 核对，写“已购 ×**{n}** · 出击结束时用剩的作废，返回营地则随身暂存”；手持提示在当前角色买不到这件商品时改为“以 **{角色}** 出击时才会带上”。
- **未改的名字**：怪物币、复生图腾、望远镜、女巫商品原本就设了非斜体，仍用 `CUSTOM_NAME`；怪物币的名字还是女巫交易价格的匹配条件之一。
