# 追猎预兆：出击落地时目标听到一声洞穴音

2026-11-23 与需求方讨论定稿。状态：已实现，待人工客户端验收。

## 背景

人类被追猎时几乎拿不到信息：「来自 X 的追猎」Boss 栏只在追猎自己的怪物进入 5 格（潜行约 4 格）内才出现，16 格内落地的叫声苦力怕没有，外形和自然生成的怪物、随从完全一样。怪物落地时离人类约 14 格路程，从落地到贴脸的十几秒里人类什么都不知道。最初的设计是为了让怪物能隐蔽、伏击，实际游玩下来压迫感过强，需要**稍微**平衡。

讨论中否决了较重的方案：状态图标显示追猎者数量、TAB 栏常驻行、放大 Boss 栏距离、怪物潜行静音补偿。需求方只要一个轻量提示：告诉目标“有东西来了”，不告诉在哪、是谁、有几只。

## 规则

| 项目 | 规则 |
| --- | --- |
| 触发 | 怪物从营地出击、落地成功（个人追猎提交并应用身体之后），含暂存恢复的出击和破石而出的落地 |
| 不触发 | 追迹罗盘循迹落地；营地里锁定目标、伺机中、取消；观察 |
| 声音 | 原版洞穴音（`ambient.cave`），所有维度统一 |
| 听众 | 只发给这次出击的目标一人；其他人类和怪物都听不到，怪物也不会被告知 |
| 方向 | 不带方向：声音绑定在目标自己身上播放。开着原版字幕时，若听到后横移，约 3 秒内的字幕箭头会指回自己刚才的位置；它不含任何怪物信息，与原版洞穴音的随机方向箭头同性质，接受 |
| 间隔 | 同一名目标 10 秒内最多响一次；10 秒内落地的第二只怪物不再响，所以声音次数不泄露数量 |

- 洞穴音在原版里只在黑暗封闭处偶尔响起：在地表听到它很反常、容易识别；在洞里真假难辨，正好是“好像有东西”的程度。
- 现有表现不变：16 格内落地时在落点播放物种叫声（苦力怕不出声）、破石而出的蠹虫声、5 格 Boss 栏。
- 不新增配置。10 秒间隔是代码常量。

## 交付

- core：`HuntOmens`，按目标记录上次响起的时间，判断这次落地是否响；单元测试覆盖间隔与不同目标互不影响。
- platforms/mc263：`LobbyRuntime.completeDeployment` 落地成功后调用；`HuntOmen` 只向目标的连接发送绑定在其身上的原版声音包。
- 规则书「追猎」页补一句说明；追迹罗盘拆为单独一页（原页按像素折行后超出书页可见的 14 行），页长测试改为按原版字宽近似折行。
- GameTest：营地出击落地后，只有目标收到洞穴音；循迹落地不发。
- 人工客户端测试：地表与洞里各听一次，判断是否够明显、是否像原版洞穴音。
