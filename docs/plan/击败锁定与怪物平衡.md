# 击败锁定与怪物平衡

2026-11-23 与需求方讨论定稿。状态：已实现，待人工客户端验收。

## 背景

怪物阵亡后有 30 秒全局出击冷却，期间只能观战或购物，无事可做。另一方面，主动归返的冷却早已是 0，死亡冷却实际上只剩一个作用：给人类喘口气。

本次把它改成一条原则：**死亡惩罚 = 打败你的那个人类获得的喘息时间**。怪物阵亡后可以立刻去追猎别人，只有击败它的人在一段时间内不会被它追猎。这样怪物玩家有事可做，也缓解“多只怪物总盯着同一个人类”的情况；主动迎战的人类获得个人奖励，一直逃跑的人类得不到。

## 1. 击败锁定

“锁定”指：这只怪物在锁定期内不能在庭院选这名人类为追猎目标。战斗不受影响，在野外碰到照样可以打。锁定时长读取 `monster.deployCooldownMillis`，默认改为 45 秒。

| 怪物的死法 | 锁定谁 | 全局出击冷却 |
| --- | --- | --- |
| 被人类击杀（原版击杀归属：被人打过 5 秒内摔死、烧死也算这个人的） | 击杀者 | 无 |
| 苦力怕自己引爆（不管有没有炸到人、之前有没有被人打过） | 本次追猎的目标 | 无 |
| 苦力怕被人类强制点燃后爆炸（见第 5 节） | 本次追猎的目标 + 点火者 | 无 |
| 纯环境死亡（摔死、岩浆、溺水），没有人类击杀归属 | 不锁 | 无 |
| 出击中断线 | — | 45 秒 |
| 人类刚死、变成怪物 | — | 45 秒 |
| 复生优先召回 | — | 不变（马上变回人类） |

- 锁定按玩家身份记录，存进本轮存档。同一只怪物被同一个人再次击败时重新计时，不叠加。
- 锁定倒计时在怪物在线时走（庭院中和出击中都走），离线时暂停；停服期间按原有出击冷却的规则冻结。
- 怪物变回人类、退出本轮时清空。
- 只剩一个人类时，效果等同于全局冷却。
- 不处理“同伴问题”（击败者站在目标旁边时，怪物仍可出击到目标身边）：人类结伴而行本来就是很强的增强。
- 被锁定的人类不会成为追迹罗盘的目标（罗盘只指向本次出击的目标，出击时已经排除）。

### 表现

| 谁 | 时刻 | 表现 |
| --- | --- | --- |
| 怪物 | 庭院里看着被锁定的人类模型 | 名字行末尾显示“提防你 · 32 秒”，只有这只怪物看得到 |
| 怪物 | 右键被锁定的模型 | 拒绝：“B 刚击败了你 · 32 秒后才能再追猎他” |
| 怪物 | 锁定结束 | 提示“可以再次追猎 B 了” |
| 怪物 | 所有在场人类都被锁定 | 庭院动作栏显示最近一个解锁的倒计时 |
| 人类 | 击败怪物、产生锁定时 | “你击退了 M · 一段时间内它无法再找你” |

## 2. 出击冷却 45 秒

`monster.deployCooldownMillis` 默认从 30 秒改为 45 秒，同时用作击败锁定时长、断线和刚成为怪物的全局冷却。主动归返仍读 `monster.returnCooldownMillis`（默认 0），不变。

## 3. 归返营地：边走边引导

作为延长惩罚的补偿：

- 归返改成和循迹一样边走边引导，打断规则也与循迹相同：受伤、攻击、挖掘、施放技能、使用其他物品、切换维度会打断；走路、跳跃、转视角、被动位移不打断。这取代《[追迹罗盘改版](追迹罗盘改版.md)》第 2 节“归返营地仍要求站立”。
- 引导时长拆成两个配置：`monster.returnChannelMillis` 默认改为 4 秒，用于归返；新增 `monster.retrackChannelMillis` 默认 5 秒，用于循迹。已有对局存档里没有新配置时，循迹沿用归返时长。

## 4. 被人类击杀的怪物币

`coin.killedByHuman` 从 5 提高到 8。仍要求被人类打过（原版的“最近被玩家伤害”判定），自杀不会给。

## 5. 苦力怕

### 5.1 引爆器换成打火石

- 外观从火药换成打火石（原版就是用打火石点燃苦力怕），名称仍为“引爆器”，用法不变：按住右键膨胀，中途松开取消。
- 冒险模式下对方块使用打火石不会生火，客户端会接着发出“使用物品”，所以对着方块按右键也能引爆。
- 用引爆器右键原版苦力怕：按原版点燃它（点燃音效，原版引信），引爆器不掉耐久。这只原版苦力怕的爆炸算作这名苦力怕玩家的随从伤害：伤害计入怪物币，炸死人类时照样获得复生次数。
- 暂存身体和旧存档里的火药引爆器，出场时按当前规则重新发放为打火石。

### 5.2 循迹、归返的打断

旧规则在苦力怕“膨胀值大于 0”时就以“比赛状态变化”打断。原版苦力怕落地会按掉落高度增加膨胀值，普通跳一下、走下一格台阶都会让膨胀值变成 1，所以边走边循迹时经常被误打断。

新规则：只有主动点燃（使用引爆器）才打断，原因显示“施放技能”；落地带来的被动膨胀不打断。被人类强制点燃时打断，原因显示“被点燃”。

### 5.3 人类强制点燃苦力怕玩家

- 人类手持打火石或火焰弹右键苦力怕玩家，就会点燃它（原版：用打火石或火焰弹右键苦力怕）。打火石按原版消耗 1 点耐久，火焰弹消耗 1 个。
- 引信不能取消，时长与苦力怕自爆相同；苦力怕玩家在引信期间可以走动。苦力怕玩家收到提示“你被 X 点燃了”。
- 爆炸与自爆完全相同：威力相同，带电时翻倍，点火者也会被炸到；炸死人类算苦力怕的击杀，苦力怕照样获得复生次数。
- 苦力怕的死亡算点火者击杀：点火者被锁定，苦力怕获得被击杀的怪物币，点火者获得击败怪物的悬赏分。本次追猎的目标同样被锁定。

## 6. 庭院显示追猎人数

庭院的目标模型名字行显示“N 只怪物在追”（N ≥ 1 时才显示），只给庭院里的怪物玩家看。人数包括已经出击、目标是他的怪物，以及正在庭院里等待出击、目标是他的怪物。人类那边不显示，保留未知的紧张感。

## 7. 不改的部分

- 被人类点燃的苦力怕玩家断线时，引信随身体一起作废：它付出断线的 45 秒全局冷却，点火者拿不到锁定和悬赏分。断线本身代价不小，又和其他断线处理一致，暂不单独处理（2026-11-23 评审裁决）。
- 击败锁定、断线冷却和刚成为怪物的冷却共用 `monster.deployCooldownMillis` 一个配置，这是需求方的决定。
- 追迹罗盘保持普通罗盘外观。追溯指针的指针只指向玩家自己上次死亡的位置（客户端只在登录、重生时收到），无法指向目标。

## 实现记录

- 原版依据（26.3）：`ItemStack.useOn` 在冒险模式下、物品没有 `can_place_on` 时直接返回 PASS，客户端随后改为使用物品，所以打火石引爆器对着方块也能按住引爆。`Creeper.mobInteract` 对 `#creeper_igniters`（打火石、火焰弹）调用 `ignite()`，打火石扣 1 点耐久、火焰弹消耗 1 个，强制点燃照此处理。
- 已有服务器的待开局规则里，仍等于旧默认值的 `monster.deployCooldownMillis`（30 秒）、`monster.returnChannelMillis`（5 秒）、`coin.killedByHuman`（5）会改为新默认值；管理员改过的其他值保留。已经开始的一轮沿用开局时的规则；没有 `monster.retrackChannelMillis` 的旧对局，循迹沿用归返时长。
- 强制点燃的击杀归属：点燃时把点火者记为“最近伤害者”（原版 `lastHurtByPlayer` 与本模组的击杀归属记忆各记一次，5 秒窗口覆盖 1.5 秒的引信），爆炸杀死苦力怕时按这份记忆归给点火者。引信期间另有人类打了苦力怕，归属就换成那个人。
- 顺手修复：怪物阵亡回到庭院时的提示以前只在已不再使用的单人死亡事件里触发，实际的阵亡（死亡批次）从来不提示；现在会提示，并带上被锁定的人类。
