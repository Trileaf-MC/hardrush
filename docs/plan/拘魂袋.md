# 拘魂袋（Soulcatcher）

2026-11-02 与需求方讨论定稿。状态：已实现，待[人工客户端验收](../人工客户端测试/2026-11-03-营地改版与怪物新玩法.md)。实现中的偏差：猪灵、猪灵蛮兵、疣猪兽、僵尸疣猪兽、旋风人使用原版大脑 AI，不执行跟随与协攻目标，放出后改为普通原版生物（见《[玩家怪物与原版差异](../玩家怪物与原版差异.md#拘魂袋)》）；角色蛋孵出的僵尸收回后按新蛋处理，再次孵出不保留血量和装备。

## 背景

玩家僵尸／溺尸放出的随从经常与主人脱节：

1. 正常追逐时，随从一旦锁定人类就不再执行跟随（`CompanionFollowGoal.canUse` 要求没有目标）。原版僵尸移速属性 0.23，约 2.3 格/秒，追不上疾跑约 5.6 格/秒的人类；要被甩出原版追踪范围 35 格（`Zombie.createAttributes` 的 `FOLLOW_RANGE`、`TargetGoal.canContinueToUse`）才会放弃目标，回到主人身边。
2. 追迹罗盘长距离循迹后，随从留在原地。所在区块不再被模拟时，随从冻结，无法按狼式跟随传送赶上来。
3. 跨维度不跟随。

讨论过自动归队（隐蔽落点、循迹随行），最终放弃：随从脱节交给玩家自己处理。玩家用一个袋子把随从收起来带走，到了再放出来，并借此把能力扩展为收编自然生成的生物。

## 1. 范围

- 只给僵尸／溺尸角色。骷髅、苦力怕保持各自的特色。
- 不做：自动归队、循迹或换维度时自动随行、一键收队、暂离时自动收队。

## 2. 物品

- 僵尸／溺尸每次出场绑定发放一个「拘魂袋」，外观是原版收纳袋。
- 绑定规则与其他绑定物品相同：不能丢弃、转交、放进外部容器，也不能放进别的收纳袋。
- 袋里只装本人收编的蛋：世界物资放不进去，袋里的蛋不能取出，只能手持袋子直接放出。
- 原版按住右键使用收纳袋会把内容全部倒出（`BundleItem.use` → `onUseTick` → `dropContent`），拘魂袋禁用这个行为。
- 品阶外观：原版物品稀有度决定名称颜色，同时换用对应颜色的原版染色收纳袋图标。悬停说明列出当前品阶可收编的物种。

## 3. 操作（手持拘魂袋右键）

| 对象 | 效果 |
| --- | --- |
| 可收编的生物 | 收编：生物化为原版对应物种的刷怪蛋装进袋里，蛋内用原版 `entity_data` 完整保留实体数据（血量、装备、幼年、带电、驯服者、村民交易、凋灵充能、监守者愤怒值等）。播放原版收纳袋装入音效 |
| 自己的随从 | 收回。出生自带僵尸蛋放出的那只，回到对应的绑定僵尸蛋，不占名额；其他随从（收编放出的，以及增援、感染、转化产生的）回到袋里，占名额 |
| 方块；对准水源或熔岩源 | 放出袋里当前选中的那只，判定与原版刷怪蛋相同（`SpawnEggItem.useOn` / `use` 的 `Fluid.SOURCE_ONLY` 射线），现有绑定僵尸蛋已按此实现 |

- 放出的对象默认是最近收进的那只（原版收纳袋取出顺序）。在背包界面悬停袋子滚动滚轮，可以用原版功能挑选。
- 水中：对准水底方块，在方块表面放出；对准水面，或者人在水下对准前方的水，在水中放出（人在水下时，射线一出发就命中自己所在的水源方块，所以怪物出现在身边）。陆地生物放进深水，按原版规则处理，例如僵尸泡久了会转化为溺尸。
- 收编的生物如果有乘客或坐骑，只收点中的那只，其余按原版脱离；被拴住的，按原版掉落拴绳。
- 收编没有额外门槛，满血也能直接收编。
- 对着当前品阶收编不了的生物使用时，动作栏提示类似“需要稀有拘魂袋才能收编苦力怕”。
- 只能在出场期间收编或放出：挑战、救场阶段，以及屠龙庆祝（与其他技能一样照常可用）；保护区与世界交互限制同现有角色蛋。

## 4. 名额

- 只统计袋里的蛋：一只算一份，不分体型。默认 3 只。
- 用原版收纳袋重量表示容量：原版每个物品的重量是 1/最大堆叠数，袋子重量满 1 就装不下（`BundleContents.getWeight`）。把收编蛋的最大堆叠数设为当前名额 N，袋子就正好装 N 只，满度条就是名额。名额升级后，同步改写袋内蛋的最大堆叠数。
- 接受“放出后再收编”带来的扩充：自然生成的生物数量有限，人类又跑得快，构不成失控的威胁。

## 5. 品阶与可收编物种

只有会主动仇恨人类、并且能在地面跟随的敌对生物，放出后才成为**随从**；其余生物放出后都是**普通原版生物**。

| 品阶（名称颜色） | 新增可收编 | 放出后 |
| --- | --- | --- |
| 普通·白（初始） | 僵尸、尸壳、溺尸、僵尸村民 | 随从 |
| 罕见·黄 | 骷髅、流浪者、沼骸、焦骸、蜘蛛、洞穴蜘蛛、蠹虫、末影螨、史莱姆、岩浆怪 | 随从 |
|  | 幻翼 | 普通原版生物 |
| 稀有·青 | 苦力怕（保留带电状态）、女巫、掠夺者、卫道士、凋灵骷髅、猪灵、疣猪兽、僵尸疣猪兽、烈焰人 | 随从 |
|  | 全部中立和被动生物（含村民、流浪商人、铁傀儡、被驯服的宠物、亡灵坐骑、水生与飞行生物）；潜影贝、守卫者、嘎枝 | 普通原版生物 |
| 史诗·紫 | 唤魔者（召出的恼鬼同属随从）、劫掠兽、猪灵蛮兵、旋风人 | 随从 |
|  | 恶魂、恼鬼、凋灵、监守者、远古守卫者 | 普通原版生物 |

高品阶包含低品阶的全部物种。

**始终不能收编：**
- **末影龙**：屠龙是本轮的胜利条件，收走会破坏胜负判定和屠龙结算。
- **别人的随从。**

除此之外不另设排除（命名牌命名过的、被驯服、被拴住、被骑乘的生物，村民和流浪商人都可以收编），一切按原版自然结果处理。例如被驯服的宠物放出后仍属于原主人，被骑乘的生物收编时，骑手按原版脱离。

### 随从

沿用现有随从规则：跟随主人、永不以主人为目标、主人成功攻击后协攻、伤害计入主人的战斗来源、主人离场时以死亡表现清理且无收益。增援、感染、转化产生的后代继承主人与战斗来源。

### 普通原版生物

完全按原版行为：不跟随、不协攻、不附加主人保护，主人离场时不清理，留在世界里。例如铁傀儡会按原版规则攻击僵尸玩家，误伤僵尸猪灵会引来整群报复。

### 范围伤害

一律按原版：自己的苦力怕爆炸、女巫药水、唤魔者尖牙等，同样会伤到主人和其他随从。“永不以主人为目标”只约束选敌，不屏蔽波及伤害。

## 6. 女巫商店升级

升级本轮永久有效：购买后，本轮之后每次以僵尸／溺尸出场都生效，复生为人类或换轮时清空。它和“只用于下一次出场”的现有消耗品是两类商品，不参与出场窗口内的价格翻倍。

| 商品 | 价格 | 规则 |
| --- | --- | --- |
| 升阶 | 罕见 30、稀有 60、史诗 120 | 必须按顺序购买，买完显示原版售罄 |
| 扩容 | 20 → 40 → 80 | 每次 +1 只，最多 3 次，上限 6 只 |

- 已经出场、暂离或在营地时购买的升级，下次领取或继续出场时，拘魂袋按新品阶与名额刷新：改外观、改说明，并改写袋内蛋的最大堆叠数。
- 一个原版交易栏位最多放一组 64 个绿宝石（`MonsterCoins.MAX_PRICE`）。超过 64 的价格要用原版交易的第二个费用栏位，单笔最多 128，所以史诗 120 也能放得下。
- 价格、名额、扩容次数都写进规则快照；没有这些规则的已保存对局，不启用拘魂袋。

## 7. 生命周期

- 收编后的生物（随从和普通原版生物）设为不会因距离而自然消失。
- **暂离**：拘魂袋连同里面的蛋，作为绑定物资随身体按原槽位暂存，继续出场时原样恢复；场上随从照常清理，普通原版生物留在世界里。
- **出场结束**（阵亡、断线、召回、放弃暂离、复生、退出）：拘魂袋和蛋按绑定物资清除，场上随从照常清理，普通原版生物留在世界里。
- 出生自带的成年／幼年僵尸蛋、购买的额外僵尸蛋保持现有规则，不进袋子。

## 8. 实现要点

- **随从泛化**：`MonsterCompanions` 目前只支持 `Zombie`（`configure(Zombie)`、`CompanionFollowGoal` 以及蛋的类型判断）。需要泛化到所有“随从”物种的 `Mob`：跟随与安全传送、主人保护、协攻、战斗来源标记（含骷髅箭、苦力怕爆炸、女巫药水、唤魔者尖牙与恼鬼、史莱姆分裂后代）、离场清理与卸载实体的失效检查。
- **收纳袋防藏规则**（`MonsterInventory`）：现在一律禁止绑定物品与收纳袋互相放入。改为只允许本人的收编蛋进入本人的拘魂袋，同时禁止从拘魂袋里取出、禁止放入其他物品、禁止把拘魂袋放进其他收纳袋。客户端预测失败时回同步背包。
- **蛋的实体数据**：收编时保存完整实体数据，去掉 UUID、位置、乘客与拴绳关系，放出时由原版生成流程重新分配。暂存时注意存档的大小上限。
- **原版机制复核**：实现前用 minecraft-knowledge 核实以下几点，并把结论写进差异文档——
  - 凋灵对亡灵的豁免，能否套用到“按当前物种识别的玩家僵尸”上；
  - 监守者会不会因振动盯上僵尸玩家；
  - 凋灵充能、监守者愤怒值、嘎枝与嘎枝之心的绑定关系，经刷怪蛋数据往返后的表现。
