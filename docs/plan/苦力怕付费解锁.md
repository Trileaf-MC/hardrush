# 苦力怕付费解锁

2026-11-24 与需求方讨论定稿（[#78](https://github.com/Trileaf-MC/hardrush/issues/78)）。状态：已实现，待人工客户端验收（[2026-11-17 场次](../人工客户端测试/2026-11-17-界面挡住动作栏的提示.md)第十八段）。

## 背景

僵尸和骷髅的出场物资随目标的悬赏星级分档（见[悬赏分档与追猎强度](悬赏分档与追猎强度.md)），苦力怕的爆发来自引爆本身，按星级加减物资没有意义，所以没有参与分档。结果是贴脸自爆对刚起步、没有护甲的一、二星玩家几乎是秒杀。

本方案把苦力怕改成要花怪物币解锁、只追三星以上人类的角色：它仍然是追猎强者、一击翻盘的手段，但不再是随时都能拿来对付弱者的选择。

## 1. 出击资格

- 右键苦力怕展位时扣 **40 怪物币**（`coin.creeperUnlock`），得到 **1 次苦力怕出击资格**，同时把角色切换为苦力怕。价格固定，不随目标星级变化。
- 资格只在出击**真正结束**时用掉：

  | 情况 | 资格 |
  | --- | --- |
  | 搜索失败、出击取消（还没落地） | 保留 |
  | 落地出击 | 保留（出击中） |
  | 主动归返（暂存） | 保留 |
  | 自爆、阵亡、掉线、被召回、持有复生图腾被收回 | 用掉 |

- 持有资格时再右键苦力怕展位，不重复扣钱，只切换角色。
- 持有资格时改选僵尸或骷髅，资格不作废，换回苦力怕时还能用。改选会照旧放弃暂存的苦力怕出击，但资格本身留在钱包里。
- 出击结束、资格用掉后，角色仍是苦力怕，但再右键人类模型会被拒绝，提示回展位付款。
- 变成怪物（每条新的怪物命）时没有资格；复生变回人类、本轮结束时作废。不退款。
- 钱不够时拒绝解锁，提示"需要 40 怪物币，现有 N"，角色不变。
- **场上没有三星以上人类时拒绝解锁**，不扣钱，提示"场上还没有三星以上的人类，苦力怕暂时无人可追"。"场上"指在线、以人类身份在比赛中的玩家。

## 2. 只追三星以上

- 苦力怕只能追 ★3 及以上的人类（`HuntPressure.CREEPER_MIN_STARS = 3`，写在代码里，由单元测试固定）。
- 苦力怕视角下，庭院里一、二星人类模型的名字行追加"苦力怕只追三星以上"；右键会被拒绝，不扣资格。
- 星级在一条命内只升不降，已经出击的苦力怕不会因为目标星级变化被收回。
- 第 3、4 节的同时追猎上限和失败锁定（见[悬赏分档与追猎强度](悬赏分档与追猎强度.md)）照旧适用。

## 3. 展位：石像苦力怕

展位模型本来就是只发给每名玩家自己的数据包实体，所以每个人看到的是自己的解锁状态。

- **未解锁**：一尊灰色石像（若干缩小的方块展示实体拼成苦力怕的头、身体和四条腿），身上交叉缠着两条锁链，胸前挂一个缩小的宝库方块当锁头。名字行：`苦力怕 · 40 怪物币解锁`。
- **解锁瞬间**：石像和锁链消失，真苦力怕现身，播放宝库开锁音效并喷出一圈粒子。
- **解锁后**：苦力怕带金色发光描边（仅这名玩家可见），周围偶尔冒出零星火花。名字行：`苦力怕 · 已解锁 · 右键选择角色`。
- 资格用掉后回到石像。
- 实现（26.3 客户端 JAR 核实）：
  - 石像用 6 个 `block_display`（磨制安山岩）按 `CreeperModel` 的像素尺寸拼成：头 8×8×8、身体 8×12×4、四脚各 4×6×4，头顶 1.625 格。锁链是 `iron_chain` 方块展示，锁头是缩小的 `vault`（`block_display` 只画外壳，不画里面旋转的物品）。
  - 隐形生物在原版客户端不显示名字，所以石像不用隐形苦力怕：右键由约 0.75×1.65 格的 `interaction` 实体接收，名字由 `text_display` 显示。
  - 金色描边：只给这名玩家发一个金色的虚拟队伍（仿照 `TotemDrops` 的做法），成员是假苦力怕的 UUID，再设置发光标志位。拆展位或离开大厅时，向原连接发送移除队伍的包。
  - 粒子用 `wax_on`（橙金色星点），解锁音效用 `block.vault.open_shutter`，都只发给这名玩家。
- 庭院未开放时，名字行照旧显示"极限挑战时开放"，石像外观仍按解锁状态显示。

## 4. 兼容

- 只有本轮规则里有 `coin.creeperUnlock` 时才启用本方案；旧对局、非极限模式的苦力怕照旧免费、不限星级、展位是普通苦力怕。
- 资格存进钱包，轮次快照格式 17 写入；旧快照读作没有资格。

## 5. 文案

- 规则书新增「苦力怕解锁」页（「角色」页放不下）：每次出击先在展位付费解锁、只追三星以上、返回营地不用重新付、自爆或倒下后要重新解锁。
- 女巫说明第 2 页"化身成他们"之后补一句苦力怕要先交钱，价格按本轮规则；苦力怕免费的对局不说这句。

## 6. 交付

- core 单元测试：解锁扣钱、钱不够、无三星人类拒绝、重复解锁不扣钱、换角色保留、各结束路径是否用掉资格、主动归返（含无暂存身体的归返）保留、出击取消保留、追一二星被拒、未解锁出击被拒、旧规则免费、快照 17 往返与旧快照迁移。
- gametest：未解锁时出击被拒；付费解锁后对三星目标出击，自爆后资格用掉、再出击被拒；主动归返后再出击不扣钱；对一二星目标被拒。
- 人工客户端测试：石像外观、解锁瞬间的音效粒子、金色描边与火花、资格用掉后回到石像。
