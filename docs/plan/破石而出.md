# 虫蚀伏击：破石而出

2026-11-22 与需求方讨论。状态：方案草稿，待对抗性评审。

## 背景

人类少、又基本都在狭窄矿道里时，怪物玩家几乎无事可做：

1. 出场和循迹的落点要求怪物能用原版寻路器走到目标身边，路程 8–24 格，且离任何人类 ≥ 8 格（`SafeDeployment`）。
2. 怪物不能挖方块，只有僵尸能敲开木门（`MonsterDoorBreaking`）。
3. 在 1×2 矿道里，离人类 8 格外又走得通的点很少；人类一封路，就一个都没有。5 秒后的部分路径兜底只会把怪物放进附近另一个洞，隔着石头过不去。

人类被石头保护着，怪物又没有任何穿过石头的方法。原版的蠹虫藏在石头里，挖开虫蚀方块会冲出一只，老玩家在要塞和山里都见过。本方案把这个现象做成怪物进入矿道的方式：

- 怪物获得挖开基础方块的能力。
- 普通落点找不到时，怪物被放进目标附近石头里的一个封闭空腔（虫穴），自己选择何时破石而出。

## 1. 怪物挖掘

### 规则

| 项目 | 规则 |
| --- | --- |
| 谁能挖 | 僵尸、骷髅（含溺尸、流浪者等环境转化形态）。**苦力怕不能挖**：没有手，挖墙也会让它过强 |
| 何时能挖 | 在挑战世界出场期间（与敲门相同的“能行动”判定），整个出场期间都能挖，不只限于虫穴 |
| 可挖方块 | 主世界：石头、圆石、深板岩、深板岩圆石、花岗岩、闪长岩、安山岩、凝灰岩、泥土、沙砾；下界：下界岩、玄武岩、黑石、灵魂沙、灵魂土；末地：末地石 |
| 不可挖 | 表外的一切，包括矿石、石砖等建材、木头、黑曜石、玻璃、沙子。人类用石砖、木板等认真盖的建筑依然安全 |
| 时长 | 固定 7.5 秒，不论方块种类、手持物品、效率附魔、急迫或挖掘疲劳。7.5 秒是原版空手挖石头的时间 |
| 一次挖多大 | 一次挖开 1×2，刚好够自己钻过去，见下文“1×2 的取法” |
| 掉落 | 不掉落任何物品，避免怪物刷资源或给人类送物资 |
| 输入 | 空手按住左键，与敲门相同。松开、移开准星、切换手持物会中断进度 |
| 表现 | 进度用原版挖掘裂纹显示，附近所有人可见，两格同时显示；破开时播放原版方块破坏音效和粒子 |
| 限制 | 保护区（大厅、出生点保护）内不能挖；遵守 `mobGriefing` 游戏规则（与敲门相同）。是否也像敲门一样要求困难难度，见“待议” |

### 1×2 的取法

以准星对准的方块为主格：

- 主格高度等于怪物脚下一格或头部一格（脚的方块 y 或 y+1）时，挖开该列上的这两格，也就是脚和头两个高度。
- 主格在头顶以上或脚下以下（向上或向下挖）时，只挖主格。这样不会出现一次向下挖出 2 格深坑这类坠落或卡位。
- 另一格不在可挖表内（例如是矿石）或在保护区内时，只挖主格。

### 与现有规则的关系

- 挖掘会打断循迹引导（《追迹罗盘改版》已把“挖掘方块”列为打断项），也打断归返引导。
- 敲门不变：仍只有僵尸能敲，12 秒，要求困难难度。

## 2. 虫穴（破石而出）

### 触发

不需要任何新物品或选择。出场（营地点目标）和循迹（罗盘）共用一条流程：

1. 前 5 秒只接受完整路径的普通落点，与现在相同。
2. 5 秒后仍没有普通落点，先找虫穴位置。
3. 找不到虫穴，再退回现有的部分路径兜底。

骷髅、苦力怕、僵尸都可以进虫穴。苦力怕不能挖，只能等人类挖到它，或者在里面自爆，不做额外处理。海上规则不变：目标在海上时不找虫穴。

### 虫穴位置（硬约束）

| 规则 | 值 |
| --- | --- |
| 空腔 | 1×1×2，按站立高度检查，能放下当前角色的身体 |
| 空腔原有方块 | 两格都必须在“可挖方块”表内（不吞矿石、不碰方块实体） |
| 封闭 | 空腔的所有相邻方块都是实心方块，没有空气或液体。人类看不到怪物，也看不到传送过程 |
| 隔墙 | 空腔有一个水平侧面（脚和头两格高度）与目标所在空间只隔 1 格墙；墙两格都在可挖表内，怪物挖一次就能出去 |
| 同一空间 | 墙外那侧的空气格能按原版寻路器走到目标（复用现有寻路代理），路程 ≤ 24 格 |
| 距离 | 空腔与目标直线 3–10 格；与任何人类直线 ≥ 3 格 |
| 液体 | 空腔与隔墙都不贴着液体（挖开后不会被淹） |
| 其他 | 不在保护区；只读已加载区块；与其他怪物的虫穴不重叠；天花板维度禁令沿用 |

### 打分

- **首选目标前方**：根据目标最近挖掉的方块推断挖掘方向，没有最近挖掘时用朝向；隔墙位于目标前进方向上的位置得分最高，他继续往前挖就会撞上。
- 其次是目标身后隧道的侧壁（沿足迹）。
- 路程、视野盲区、亮度沿用现有打分，权重另调。

### 入穴

1. 原地删除空腔两格（不掉落），把怪物放进去，视角朝向目标。
2. 在空腔位置播放一次原版蠹虫音效（`entity.silverfish.ambient`），替代普通出场的物种环境音。附近的人类能隐约听到墙里有东西。
3. 不放蠹虫，不生成虫蚀方块，墙保持原样。

### 潜伏与破石

- 潜伏没有时限。怪物可以随时挖墙破石而出，也可以朝目标挖过去，或者用罗盘、归返离开。
- 人类先挖到隔墙时，空腔直接暴露，不做特殊处理。
- 挖开的方块和空腔都不还原，所以没有回滚状态，也不需要写进存档。

## 3. 引导与文案

- 手持提示：空手对准可挖方块时，显示“按住左键挖开 1×2，约 7.5 秒”（与敲门提示同一机制）。
- 入穴时提示一次：“你藏进了石头里，挖开前面的墙破石而出”。
- 寻找落点期间的动作栏状态，增加“正在寻找能破石而出的位置”。
- 规则书和角色说明补上挖掘能力（苦力怕不能挖）。

## 4. 实现要点

- `MonsterDoorGameModeMixin` 现在把怪物的所有挖掘动作都交给 `MonsterDoorBreaking`。建议把它扩成统一的“怪物挖掘”入口，敲门和挖石各是一种目标：
  - 共用输入模式切换、零挖掘速度（防止客户端提前预测破坏）、按住判定、中断与重新同步；
  - 不要再复制一份挖石逻辑。
- 虫穴搜索：`SafeDeployment` 的定位是“只读、不改地形”的搜索。
  - 虫穴候选的评估仍是只读的，可以作为新的候选来源（`Source.BURROW`）接入，复用寻路代理、区块预算和打分。
  - “挖空腔”只在确认传送前、重新校验通过后执行。
- 可挖方块表定义为本模组的方块标签，规则书文案从同一处读取。
- 7.5 秒做成配置项 `monster.digMillis`（默认 7500）。

## 5. 交付

无图形 GameTest：

- 挖掘：
  - 可挖表内外、苦力怕不能挖、保护区和 `mobGriefing`；
  - 1×2 的取法（脚高、头高、向上、向下、另一格不可挖）；
  - 时长读取配置、无掉落；
  - 中断（松手、换手持物）；
  - 挖掘打断循迹和归返引导。
- 虫穴：
  - 普通落点优先；
  - 5 秒后先选虫穴再部分兜底；
  - 封闭、隔墙 1 格且墙外能走到目标；
  - 距离约束、液体与保护区拒绝；
  - 前方优先；
  - 三个维度各一例；
  - 循迹也能进虫穴；
  - 多名怪物的虫穴不重叠。

人工客户端测试：

- 原版客户端上 1×2 挖掘的裂纹、手感，以及有没有提前预测破坏的闪烁；
- 墙里的蠹虫音效能不能被注意到；
- 被封在矿道里的人类遭遇破石而出的体验；
- 苦力怕虫穴是否过强。

## 待议

- 挖石是否也像敲门一样要求困难难度。倾向：不要求。敲门的困难限制来自原版僵尸破门，挖石是本模组的能力，不应在普通难度下失效。
- 目标贴着掌子面时，前方虫穴常常不满足“与人类 ≥ 3 格”，前方优先可能经常落空，实际会多在身后侧壁出现。是否接受。
