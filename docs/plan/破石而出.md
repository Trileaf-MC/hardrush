# 虫蚀伏击：破石而出

2026-11-22 与需求方讨论。状态：已实现（2026-11-22），无图形 GameTest 通过，待人工客户端验收（[2026-11-17 场次](../人工客户端测试/2026-11-17-界面挡住动作栏的提示.md)第八段）。实现中的偏差见文末“实现记录”。

## 背景

人类少、又基本都在狭窄矿道里时，怪物玩家几乎无事可做：

1. 出场和循迹的落点要求怪物能用原版寻路器走到目标身边，路程 8–24 格，且离任何人类 ≥ 8 格（`SafeDeployment`）。
2. 怪物不能挖方块，只有僵尸能敲开木门（`MonsterDoorBreaking`）。
3. 在 1×2 矿道里，离人类 8 格以外又走得通的点很少；人类一封路，就一个都没有。5 秒后的部分路径兜底只会把怪物放进附近另一个洞里，隔着石头过不去。

原版的蠹虫藏在石头里，挖开虫蚀方块就会冲出一只，老玩家在要塞和山里都见过。本方案借这个现象，给怪物一条进矿道的路：

- 怪物获得挖开基础方块的能力。
- 普通落点找不到时，怪物被放进目标附近石头里的一个封闭空腔（虫穴），自己决定什么时候破石而出。

### 挖哪两格

按准星对准的方块（主格）和怪物所在列的位置关系决定。下面的 y 指怪物脚所在方块的高度。

| 主格位置 | 挖开 | 用途 |
| --- | --- | --- |
| 怪物自己这一列（正上方或正下方） | 只挖主格 | 往上开头顶空间、往下一格一格挖；不会一次挖出 2 格深坑 |
| 相邻列，高度 y | 主格和它上面一格（y、y+1） | 平着往前挖 |
| 相邻列，高度 y+1 | 主格和它下面一格（y、y+1） | 平着往前挖 |
| 相邻列，高度 y+2 及以上 | 主格和它下面一格（y+1、y+2），保留 y 当台阶 | 往上挖台阶 |
| 相邻列，高度 y-1 及以下 | 只挖主格 | 往下挖台阶 |

- 往上爬一级要挖两次：先挖头顶，再挖斜上方。这和人类在 1×2 矿道里往上挖台阶的步骤相同。
- 另一格不在可挖表里，或者在保护区内，就只挖主格。
- 另一格本来就是空气时，只挖主格。

### 与现有规则的关系

- 挖掘会打断循迹引导（《追迹罗盘改版》已经把“挖掘方块”列为打断项），也会打断归返引导。
- 敲门规则不变：仍然只有僵尸能敲，12 秒，要求困难难度。

## 2. 虫穴（破石而出）

### 触发

不加任何新物品或选择。出场（在营地点目标）和循迹（用罗盘）共用同一条流程：

1. 前 5 秒只接受走得到的普通落点，与现在相同。
2. ~~5 秒时仍然没有普通落点，就看有没有合格的虫穴。虫穴候选在前 5 秒的每轮搜索里就一并评估，并保留最好的一个。~~ 已由《破壁落点》修改：本轮扫描没有步行落点时立即评估破壁落点（含虫穴），找到就立即采用，不等 5 秒。
3. 没有合格虫穴，再退回现有的部分路径兜底。

其他条件：

- 只有 `mobGriefing` 开启时才找虫穴。规则关闭时，挖空腔本身就算破坏地形，而且僵尸和骷髅进去后也挖不出来。
- ~~僵尸、骷髅、苦力怕都能进虫穴。苦力怕不能挖，只能等人类挖到它，或者在里面自爆，不做额外处理。~~ 已由《破壁落点》修改：苦力怕不再进虫穴，只取站位本来是空气的破壁落点。
- 海上规则不变：目标在海上时不找虫穴。

### 虫穴位置（硬约束）

| 规则 | 值 |
| --- | --- |
| 空腔 | 1×1×2，按站立高度检查，能放下当前角色的身体 |
| 空腔原有方块 | 两格都在“可挖方块”表里，所以不会吞掉矿石，也不会碰到方块实体 |
| 封闭 | 空腔的所有相邻方块都是实心方块，没有空气或液体。人类看不到怪物，也看不到传送过程 |
| 地板 | 空腔下面一格可以站人，而且不是危险方块（岩浆块等），沿用现有落点的地板判定 |
| 会下落的方块 | 空腔上面一格和隔墙上面一格都不能是会下落的方块（沙子、沙砾、混凝土粉末等），以免挖空腔时窒息，或者洞被重新填上 |
| 隔墙 | ~~空腔有一个水平侧面（脚和头两格高度）与目标所在空间只隔 1 格墙。墙的两格都在可挖表里，怪物挖一次就能出去~~ 已由《破壁落点》修改：隔墙每格有完整碰撞、怪物挖得动即可，不再限天然方块；墙外的出口格不再要求头顶为空。另有隔一层地板、落在目标头顶的上方虫穴 |
| 同一空间 | ~~墙外那一侧的空气格能按原版寻路器走到目标（复用现有寻路代理），路程 ≤ 24 格~~ 已由《破壁落点》修改：出口格在目标所在空间（从目标身体所在格广度优先展开）里的步数 ≤ 12，不再寻路 |
| 距离 | 空腔与目标的直线距离 2–10 格，与任何人类的直线距离 ≥ 2 格。中间隔着墙，还有全员可见的裂纹作预警 |
| 液体 | 空腔和隔墙都不贴着液体，挖开后不会被淹 |
| 其他 | 不在保护区；只读已经加载的区块；不与其他怪物的虫穴重叠；沿用天花板维度禁令 |

### 打分

- **首选目标前方**：根据目标最近挖掉的方块推断挖掘方向，没有最近挖掘记录时用朝向。隔墙位于目标前进方向上的候选得分最高，他继续往前挖就会撞上。
- 其次是目标身后隧道的侧壁（沿足迹找）。
- ~~路程、视野盲区、亮度沿用现有打分，权重另调。~~ 已由《破壁落点》修改：改为距离、前方、上方、空腔型、足迹、亮度、挖开耗时、出口步数八项，见《破壁落点》4.4。

### 入穴

1. 传送前先重新校验一次虫穴条件。虫穴有自己的一套校验，与海上落点一样不走普通落点的校验，因为普通校验要求离人类 ≥ 8 格、落点没有方块碰撞。
2. 原地删除空腔两格，不掉落。先把两格的方块更新发给这名怪物，再传送进去，视角朝向目标。
3. 在空腔位置播放一次原版蠹虫音效（`entity.silverfish.ambient`），替代普通出场时的物种环境音。苦力怕进虫穴也播放：这是石头里的声音，不是苦力怕的叫声。附近的人类能隐约听到墙里有东西。
4. 不放蠹虫，不生成虫蚀方块，墙保持原样。
5. 循迹进入虫穴时，**不把随从传送过来**；怪物还待在空腔里时，随从的追赶传送也暂停。否则随从会被放到人类所在的隧道里，破坏“看不到传送”和距离约束。怪物离开空腔（空腔被挖开或怪物走出去）以后恢复正常。

### 潜伏与破石

- 潜伏没有时限。怪物可以随时挖墙破石而出，也可以朝目标挖过去，或者用罗盘、归返离开。
- 人类先挖到隔墙时，空腔直接暴露，不做特殊处理。
- 挖开的方块和空腔都不还原，所以没有需要回滚的状态，也不用写进存档。

## 3. 引导与文案

- 手持提示：空手对准可挖方块时显示“按住左键挖开，约 N 秒”，N 是这一次的实际时长（与敲门提示用同一机制）。拿着东西对准可挖方块时，提示“空手才能挖”（已由《怪物破笼》取消：拿着东西也能挖）。骷髅出场时 0 号栏是弓，不提示的话会以为自己挖不了。
- 入穴时提示一次：“你藏进了石头里，空手挖开前面的墙，破石而出”（已由《怪物破笼》修改：去掉“空手”，改为“你藏进了石头里 · 挖开前面的墙，破石而出”；苦力怕另给“苦力怕挖不动，等人挖到你再引爆”）。
- 寻找落点期间，动作栏增加一种状态：“正在寻找能破石而出的位置”。
- 规则书和角色说明补上挖掘能力，并写明苦力怕不能挖。

## 4. 实现要点

- **统一挖掘入口**：`MonsterDoorGameModeMixin` 现在把怪物的所有挖掘动作都交给 `MonsterDoorBreaking`。建议把它扩成统一的“怪物挖掘”入口，敲门和挖石各是一种目标。
  - 共用的部分：输入模式切换、零挖掘速度（防止客户端提前预测破坏）、按住判定、中断与重新同步。
  - 现有的 `available()` 写死了僵尸模型和困难难度；`BreakDoorGoal` 只适用于门。挖石要单独实现一个计时目标，按角色判断能不能挖，不能直接复用这两处。
  - 原版客户端按破坏者编号记录裂纹，一个编号同时只显示一个方块（待在 26.3 上核实）。两格同时显示裂纹，需要给每名破坏者分配两个编号；自己看的和别人看的要分开，一共四个。
- **虫穴搜索**：作为 `SafeDeployment` 的新候选来源（`Source.BURROW`）接入，复用寻路代理、每 tick 计算预算和打分。
  - 评估仍是只读的。
  - 在 `Result` 里加一个虫穴标记，`LobbyRuntime` 据此决定挖空腔、提示文案、音效和随从处理。
  - 5 秒时的优先级：普通落点 > 虫穴 > 部分路径兜底。
- **可挖方块表**：只定义在一处（当时的 `MonsterDiggable.BLOCKS`，现为 `NATURAL`）。虫穴判定仍从这里读取；挖掘判定已由《怪物破笼》改成排除表。规则书在 `core`，不依赖 Minecraft，只用文字概括。

## 评审记录（2026-11-22，一轮对抗性评审）

已采纳：

- 往上挖时会连台阶一起挖掉，导致怪物上不了楼。已改为按“自己这一列 / 相邻列”区分。
- `mobGriefing` 关闭时不找虫穴。
- 会下落的方块、空腔地板安全。
- 循迹进入虫穴时，随从会被传送到人类的隧道里。
- 5 秒兜底的时序问题；普通落点的重新校验会拒绝没挖开的空腔。
- 两格裂纹需要多个破坏者编号；`available()` 写死了僵尸。
- 开挖规则：开始时就确定两格、站在地面、交互距离、中途变化。
- 先同步方块再传送；苦力怕入穴也播放音效；拿着东西去挖时提示“空手才能挖”（该提示已由《怪物破笼》取消）。

评审对争议点的立场与方案一致：不要求困难难度；必须空手；固定 7.5 秒（后由需求方改为取原版空手时间与 7.5 秒中较小的一个）、整个出场期间都能挖。

## 需求方裁决（2026-11-22）

1. 距离下限从 3 格降到 2 格（空腔与目标 2–10 格，与任何人类 ≥ 2 格）。原因：侧壁空腔离隧道中线 2 格，正前方空腔离贴着掌子面的人类也只有约 2 格；按 3 格算，人类刚把自己封进短于 3 格的空间时永远不会出现虫穴。
2. 挖掘时长取原版空手时间和 7.5 秒中较小的一个。
3. 可挖表补上泥土类（草方块、灰化土、砂土、缠根泥土、菌丝体）和下界的两种菌岩。
4. 接受两种风险：怪物挖掉人类脚下的桥或末地边缘，让人类掉下去；挖开水或岩浆的口子，把液体放进隧道。前者有挖掘裂纹作预警，原版里苦力怕炸桥是同类玩法；后者是原版挖矿本来就有的风险。

## 实现记录

- 原版依据（26.3 服务端源码）：`BlockBehaviour.getDestroyProgress` 每 tick 进度为 `挖掘速度 / 硬度 / (能正确掉落 ? 30 : 100)`，空手速度为 1，所以空手时间 = 硬度 × 30 tick，需要工具的方块 × 100 tick。石头 1.5 × 100 = 150 tick，正好 7.5 秒。`ServerLevel.destroyBlockProgress` 只向 32 格内、编号不等于破坏者的玩家发裂纹。原版客户端按破坏者编号各记一处裂纹这一点，本地没有客户端源码可查，留给人工验收。
- 统一挖掘入口：`MonsterDoorBreaking` 改名为 `MonsterMining`（mixin 同步改名为 `MonsterMiningGameModeMixin`），敲门和挖石是两种目标，共用输入模式切换、零挖掘速度、按住判定、中断与重新同步。被拒的右键现在同时重新同步被点的方块和它被点的那一面，以免生存输入模式下客户端预测放置出幽灵方块。
- 两格裂纹用两个不属于任何实体的编号（`~玩家编号` 和 `Integer.MIN_VALUE + 玩家编号`），发给 32 格内的所有人，挖掘者自己也看得到。
- 挖掘手持提示在开始挖时显示实际秒数，与敲门相同；没有做成“对准就提示”，因为在矿道里准星几乎一直对着可挖方块，会刷屏。拿着东西挥手打可挖方块时提示“空手才能挖”（已由《怪物破笼》取消）。
- 打断引导的原因：左键方块（开始、停止、放弃挖掘）显示为“挖掘”，以前统一写“攻击”。
- 挖掘方向：`HuntTrails` 记下每名玩家最近一次亲手挖掉的方块（10 秒内有效），出场搜索据此判断“前方”；没有记录时用朝向。
- 虫穴搜索：从目标所在格出发，在 11 格内的连通空气里找站立格（最多 1024 格），检查它四个水平方向上“1 格墙 + 1×2 空腔”。按廉价打分取前 12 个候选，再逐个用寻路代理确认墙外能走到目标。只有某一轮普通候选全部评估完、仍没有可走落点时，才扫描虫穴，而且扫描单独占一个 tick，不和寻路挤在一起；找到普通落点的那一轮不付这份开销。第 5 秒时的优先级：普通落点 > 虫穴 > 部分路径兜底。在 23×23 的大洞穴里实测：普通搜索第一 tick 约 1.9 ms，虫穴扫描约 1.1 ms。
- “封闭”判定为空腔每一面的邻格都是不透明的完整方块（`isSolidRender`），所以玻璃、树叶这类看得穿的方块不算封闭。
- 只有 `mobGriefing` 开启时才找虫穴，入穴后才在空腔里播放蠹虫音效，不再播放物种叫声。怪物待在封闭的空腔里时，随从不会被传送过来（包括循迹落地时的集合）；空腔任意一面被挖开，或者怪物离开空腔后，恢复正常。
- 旧的无图形测试“下界顶棚下封闭小洞里找不到落点”，现在按新规则会给出虫穴，测试改为断言“给出的是顶棚以下的虫穴”。
- 构建：新增 `-PhardrushGameTestFilter=<套件名>*`，可以只跑指定的 GameTest 套件。
