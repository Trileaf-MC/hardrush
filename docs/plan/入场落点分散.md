# 入场落点分散

2026-11-03 与需求方讨论定稿。状态：已实现，待[人工客户端验收](../人工客户端测试/2026-11-03-营地改版与怪物新玩法.md)。

## 背景

开局、中途加入、祭坛复生都把玩家传送到同一个精确的出生点方块中心，朝向固定。开局时所有玩家模型叠在一起。营地也一样：开新一轮回营地、新玩家进营地、死后化身怪物回营地，都落在同一个精确点。

原版并不这样：新玩家首次进入和无床重生都走 `PlayerSpawnFinder`，在出生点周围 `respawn_radius`（默认 10）的方格内找落点。HardRush 的死亡无床重生本来就沿用原版，只有自己写的这几条传送叠在一点。

另外，中途加入和祭坛复生都是空装、无出生保护；极限模式下人类直接击杀人类可获得复生次数，守在出生点击杀新人有收益。

## 1. 开局全员入场：原版散布

- 落点按原版 `PlayerSpawnFinder` 的方式：以本轮主世界出生点为中心，取本轮主世界的 `respawn_radius`（按世界边界收缩），按原版的随机起点加互质步长遍历方格，取第一个合格落点。
- 合格条件：原版 `getLevelRespawnPos` 的地表判定（最高完整顶面、不在液体下），并通过 `RoundWorldBundle.safeStanding`。只看已加载区块（准备阶段已加载出生点周围 ±16 格），不额外加载。
- 不做去重，与原版一致，极小概率两人落在同一格。
- 朝向使用世界出生数据里的原版朝向。
- 一个合格落点都没有时（例如 `respawn_radius` 设为 0），退回精确出生点。
- “开局”指玩家在挑战开始前已经准备、随开局一起成为人类。开局时因档案未就绪而稍后才入场的玩家也按开局处理。

## 2. 中途加入与祭坛复生：远点落地

- 落点在以本轮主世界出生点为圆心、128–1000 格的环带内，按面积均匀随机（多数落在外圈）。
- 不检查附近有没有其他玩家，接受落在别人面前的可能。
- 先用生物群系噪声（不生成地形）排除海洋和河流，再加载区块；找落点用原版地表判定加 `safeStanding`，先试选中的那一列，不行再试同一区块内 4×4 网格。
- 落点池：挑战或救场期间后台预备 3 个落点，用加载票据把区块留在内存里。离开挑战/救场阶段、换世界或停服时释放全部票据。
- 集结区和祭坛站满 4 秒时先为本人预留一个落点再提交；暂时没有可用落点就继续等待，Boss 栏显示「正在寻找远方的落点…」，离开即取消。预留 30 秒内未使用（例如提交被拒）会退回落点池。
- 实际入场时依次使用：本人的预留、池中其他落点、阻塞搜索（原版找出生点同样会阻塞），最后才退回开局散布。正常流程只会用到第一项。
- 朝向使用世界出生数据里的原版朝向。
- 落地且客户端加载完成后，动作栏显示约 6 秒：「你位于出生点东北方约 620 格」（8 个方位，距离取整到 10 格）。
- “中途加入”判定：玩家成为人类时本轮已在挑战或救场阶段。该记录只在内存中；服务器重启后，按加入时挑战计时是否大于 0 判断。

## 3. 营地落点：原版散布

所有送往营地的传送都按营地世界的 `respawn_radius`（默认 10）在用途落点周围散布：

| 用途 | 原落点 | 散布范围 |
| --- | --- | --- |
| 回营地（开新一轮、新玩家进营地、档案隔离等，`CENTRAL`） | 营地中央 | 集结圈外 1.5 格以外，不进怪物营地 |
| 圈外等待 `WAIT_OUTSIDE` | 集结圈南侧 | 同上 |
| 恢复准备 `RESTORE_READY` | 集结圈圆心 | 完全在集结圈内（距圆心不超过半径减 1） |
| 怪物回营地 `MONSTER` | 怪物营地入口 | 怪物营地内 |
| 召回祭坛 `ALTAR` | 祭坛南侧台阶前 | 台阶前 ±2 格的空地 |

- 所有用途都避开设施点周围 1 格、祭坛平台周围 3 格和追猎目标模型周围 1 格；落点脚下需安全，脚和头所在方块都是空气（不会站进告示牌、灯笼）。
- 朝向保持各用途原来的朝向。
- 没有合格落点时退回原精确落点。
- 区域规则在 `LobbyLayout.scatterAllowed`，保证落地不会意外准备或取消准备。

## 4. 不改动

- 普通模式死亡后的无床重生仍走原版（原本就会散布；普通模式击杀人类不给复生次数，守点没有收益）。
- 追猎出场照旧，怪物玩家仍可选刚落地的新人为目标。
- 管理员旁观、庆祝集结等其他传送不变。

## 实现位置

- `core/spawn/SpawnScatter`：原版候选顺序、环带采样、方位文案。
- `core/lobby/LobbyLayout.scatterAllowed`：营地各用途的散布区域。
- `world/NativeScatter`：原版散布与开局落点。
- `world/FarLandings`：远点落点池、预留与方位提示。
- `world/LobbyWorld.scatteredLanding`：营地散布；`PlayerProfiles.placeInLobby` 和回营地的落点改用它。
- `PlayerProfiles.admit` / `revive`：落点改为按需解析，只有新生命真正入场时才取落点。
