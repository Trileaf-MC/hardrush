# 悬赏改版：威胁值、相对星级与庭院展示

2026-11-23 与需求方讨论定稿。状态：方案已定，待对抗性评审后实现。

## 背景

怪物玩家倾向于“柿子挑软的捏”：集中追猎弱小的人类，回避最强的人类，造成两极分化。现有悬赏有两个问题：

1. 只靠目标模型名字后面的“悬赏 ×1.75”展示，不显眼，怪物在庭院里看不出谁最值得追。
2. 倍率 = 1 + 维度加成 + 本条命存活加成（`MonsterCoins.bountyPermille`），太笼统，强者和弱者常常倍率相同。

需求方明确：**悬赏不碰复生**。击杀给复生的规则不变，不做头号悬赏额外奖励、协助分成或弱者保护（刚复生的保护由需求方在其他地方协调）。悬赏的职责是：

- 把人类之间的实力差距直接暴露给怪物；
- 打高悬赏的人类，怪物币与身价涨得更快（沿用现有“倍率乘伤害计入值”的通道）。

## 1. 威胁值

每名人类每条命一个威胁值，**死亡清零**，复生的新命从 0 开始。只计下面两类来源；存活时间、所在维度、击杀自然生成的怪物都**不计入**。

### 1.1 战斗

| 事件 | 分值 |
| --- | --- |
| 击杀一名怪物玩家 | +8 |
| 撑过一次追猎 | +3 |

- **击杀**：怪物玩家出击中死亡，原版击杀归属（死亡时的 kill credit）是这名人类。
- **撑过一次追猎**：一次出击**真正结束**时（怪物阵亡、主动归返且不暂存、被召回、掉线、放弃暂存的出击），在这次出击里与该怪物交过手、且此刻仍是同一条命的人类各 +3。
  - 交过手 = 本次出击中该怪物对他造成过伤害，或他对该怪物造成过伤害。按实际交手的人算，不看怪物出击时选的目标。
  - 暂存（主动归返保留身体）不算结束；之后恢复的出击仍是同一次，真正结束时只结算一次。
  - 同一次出击对同一名人类只计一次；如果是他击杀了这只怪物，记 +8，不再叠加 +3。

### 1.2 进度里程碑（非线性）

| 原版进度 | 分值 |
| --- | --- |
| 石器时代、获得升级、不吃这套 | 1 |
| 来硬的、整装上阵、这不是铁镐么、热腾腾的、冰桶挑战 | 2 |
| 附魔师、本地酿造厂 | 3 |
| 钻石！、阴森的要塞 | 4 |
| 勇往直下（进入下界） | 5 |
| 用钻石包裹我、与火共舞（烈焰棒） | 6 |
| 隔墙有眼（找到要塞） | 8 |
| 结束了？（进入末地） | 10 |

- 表外进度记 0。进度 ID 与中文名在实现时按 `.agents/skills/minecraft-knowledge/SKILL.md` 核实。
- 每条命独立：**人类复生时撤销该玩家的原版进度**，新命重新达成时会再弹原版提示并重新计分。战绩里的进度数仍按整轮并集统计，不能因撤销而减少。
- 同一条命内同一项进度只计一次（威胁状态里记录已计入的进度 ID，重启后不重复计分）。

## 2. 相对星级与倍率

- 比较范围：当前角色为人类（`HUMAN_ACTIVE`，含离线）的参赛者。
- 星级 = ⌈5 × 本人威胁值 ÷ max(最高威胁值, 10)⌉，最低 1 星。下限 10 让开局几分的差距不被放大。
- 倍率：★1 ×1、★2 ×1.25、★3 ×1.5、★4 ×2、★5 ×2.5。
- **头号悬赏**：威胁值最高且 ≥ 10 的人类（即 5 星中的第一名）；并列最高时都算。
- 倍率在**伤害计入时**按当时快照里的排名计算，替代现在的维度与存活时间公式。现有的 `coin.bounty.*`、`coin.survival.*` 配置删除，改为星级倍率与威胁分值配置（规则快照中的不可变数值）。

## 3. 怪物侧展示

### 3.1 营地庭院的目标模型（位置保持稳定，只做高亮）

- **所有可追猎目标的模型都穿上对应人类的实时装备**：头、胸、腿、脚、主手、副手，保留附魔光效。装备变化时只发装备包增量更新，不重建整页模型。
- **名字行**：`名字 · ★★★☆☆ · 下界 · 绯红森林`；星级颜色按档位：1–2 星白、3 星黄、4 星金、5 星红。
- **头号悬赏的模型**：头部显示不祥旗帜（代替头盔显示，袭击队长的标志），发光轮廓，名字金色并标注“头号悬赏”。
- 非可追猎状态（离线、阵亡、复生中等）的模型不显示星级，保持现状。

### 3.2 提醒

- 头号悬赏**易主**时，提醒营地里的怪物玩家：`X 成为头号悬赏`，对这些玩家播放袭击号角。同一名人类成为头号悬赏的提醒至少间隔 60 秒。
- 出击后的追猎 Boss 栏显示目标的星级。

## 4. 人类侧展示

### 4.1 TAB 栏

只显示自己的悬赏：`你的悬赏 ★★★★☆`；是头号悬赏时 `你的悬赏 ★★★★★ · 头号悬赏`。

### 4.2 关键变化提示（动作栏）

| 事件 | 提示 |
| --- | --- |
| 成为头号悬赏 | `你成为了头号悬赏，怪物会优先盯上你`，配一声不祥音效（实现时核实原版音效） |
| 失去头号悬赏 | `你不再是头号悬赏`，无音效 |
| 从低于 4 星升到 4 星或 5 星 | 每次进入都提示，如 `悬赏升至 ★★★★☆`；由自己的行为引起时带原因，如 `击退了追猎 · 悬赏升至 ★★★★☆` |
| 升到 2 星或 3 星 | 同一档在一条命里只提示一次 |

- 星级下降不提示，只更新 TAB 栏。
- 防抖：同一档提示至少间隔 30 秒。
- 同一时刻既成为头号悬赏又升到 5 星时，只发头号悬赏那条。

## 5. 实现要点

**core**
- 新增威胁状态，挂在 `Participant`、随 `RoundSnapshotCodec` 持久化：怪物击杀数、撑过追猎数、本命已计入的进度 ID 集合。死亡与复生时清零。
- 新增纯函数：威胁值、星级、头号悬赏判定、星级倍率，写单元测试。
- `RoundEngine`：
  - `proposeDeathBatch`：怪物玩家死亡且击杀归属为人类时，该人类 +8。
  - 出击真正结束的路径（`endSortie`：阵亡、不暂存的归返、召回、掉线、放弃暂存）：对本次出击交过手、仍存活的人类 +3（击杀者除外）。
  - 新增进度里程碑事件，带人类的 `lifeSequence` 校验，防止旧命的进度记到新命上。
  - `creditDamageCoins` 改用星级倍率；`DamageCoins.dimension` 不再需要，删除。
- “交过手”的集合：怪物对人类的伤害已经在 `MonsterWallet.sortieDamage` 里；人类对怪物的伤害需要新增按出击记录的集合（由适配层的伤害事件提交）。
- `RuleBookText` 中怪物币一页的悬赏说明更新。

**platforms/mc263**
- 进度：`PlayerAdvancementIsolationMixin` 的 award 返回处上报里程碑；人类复生时撤销原版进度（`PlayerProfiles` 复生身体流程）；确认 `ProgressTracker` / 战绩持久化按并集保存，撤销后不缩水，服务器重启后也不缩水。
- `LobbyProjections`：`Target` 携带星级、是否头号悬赏、装备快照；新增装备增量包、发光标志、不祥旗帜头部显示。
- `LobbyRuntime.bounty` 改为读取核心星级。
- `TabListRuntime`：按玩家追加自己的悬赏行。
- `HuntBossBars`：标题加星级。
- 新增人类提示与营地怪物提示的状态跟踪（每人上次星级、上次提示时间、头号悬赏集合），只在内存中保存，重启后以当前状态为基准，不补发。

- 人工客户端测试：模型装备与旗帜显示、发光、TAB 行、提示与音效，追加到最新的待测试场次。
