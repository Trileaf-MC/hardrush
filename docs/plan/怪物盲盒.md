# 怪物盲盒

2026-11-26 与需求方讨论定稿（[#92](https://github.com/Trileaf-MC/hardrush/issues/92)）。状态：已实现，待人工客户端验收（[2026-11-17 场次](../人工客户端测试/2026-11-17-界面挡住动作栏的提示.md)第二十段）。

## 背景

僵尸玩家在女巫商店能买到的召唤手段只有成年、幼年僵尸刷怪蛋，结果固定，没有惊喜。本方案加一种开出什么全凭运气的「怪物盲盒」：奖池随拘魂袋品阶扩大，史诗品阶下极小概率开出凋灵或监守者，给僵尸玩家一个升级拘魂袋的理由，也给双方制造戏剧性时刻。

讨论中顺带重新厘清了拘魂袋的语义：**是不是随从由生物的来历决定，拘魂袋只负责记功劳**。这部分改动写在[拘魂袋](拘魂袋.md)的 2026-11-26 修订里，本文第 5 节只说明它和盲盒的关系。

## 1. 商品

- 女巫商店新增「怪物盲盒」，只卖给僵尸角色，属于"下次出击带上"的消耗品（`ShopOffer.Kind.CARRIED`）。
- 价格 **25**，同一出击窗口内多买照旧翻倍，限购 **3**（25 / 50 / 100）。受 `RulesConfig` 的"翻倍后不超过 128"校验约束，25 的底价最多只能限购 3。
- 本轮规则没有拘魂袋（`MonsterCoins.soulcatcher` 为假）时不出售：奖池由拘魂袋品阶决定，没有袋子就没有意义。
- 商店里这件商品显示为带光泽的僵尸刷怪蛋，说明是"下次出击多带 1 个怪物盲盒 · 升级拘魂袋，它能开出更疯狂的东西"。

### 1.1 价格调整

为配合盲盒，调整以下默认价格，作为默认值第 6 版修订（`RETUNED_DEFAULTS`）。待用规则仍停在旧默认值的自动迁移，管理员改过的值保留。

| 商品 | 原价 | 新价 |
| --- | --- | --- |
| 成年僵尸刷怪蛋 | 6（6/12/24） | 8（8/16/32） |
| 幼年僵尸刷怪蛋 | 16（16/32） | 20（20/40） |
| 拘魂袋升阶 | 30（30/60/120，共 210） | 32（32/64/128，共 224） |
| 拘魂袋扩容 | 20/40/80 | 不变 |
| 怪物盲盒 | — | 25（25/50/100） |

32 是翻倍阶梯下拘魂袋升阶能取的最高底价（第三档正好 128）。

## 2. 物品

- 原版僵尸刷怪蛋外观，带附魔光泽；名称「怪物盲盒」，名称颜色跟随当前拘魂袋品阶的原版稀有度颜色（白、黄、青、紫）。拘魂袋升阶后，背包里的盲盒随拘魂袋一起刷新颜色。升阶只能在营地买，所以刷新发生在出击或继续暂停的出击时。
- 光泽和名称颜色要能让玩家一眼区分它和角色自带或购买的成年／幼年僵尸蛋。
- 悬停说明只有一行：**"升级拘魂袋，它能开出更疯狂的东西"**。不列奖池，不公示概率。
- 手持时动作栏提示（沿用[手持物品提示](手持物品提示.md)的做法）："右键方块或水面，放出一只随机生物"。
- 绑定规则与其他出场物资相同：不能丢弃、转交、放进容器或收纳袋。暂离时随身体暂存，出场结束时清除，未开的盲盒不退款。

## 3. 开盒

- 判定与原版刷怪蛋相同：右键方块的表面，或右键视线上的液体源方块（复用 `MonsterCompanions.landingOn` / `landingInLiquid`）。只能在出场期间使用（`MonsterRoundRuntime.canAct`）。
- 先检查位置，再抽奖：位置在**保护区、未加载区块、世界边界外**时拒绝，**不消耗盲盒**。拒绝发生在抽奖之前，提示里不会透露结果。
- 除此之外**不检查空间**，按原版刷怪蛋直接放出。不沿用拘魂袋"放不下就拒绝"的做法，因为那会在提示里说出开出了什么。
- 按使用那一刻的拘魂袋品阶抽取（品阶本轮永久，购买后升阶的，开盒时按新品阶算）。
- 开出后，主人的动作栏显示"开出：<生物名>"。开出稀有新增组、史诗新增组或 Boss 时，额外在原地播放原版试炼宝库吐出物品的音效。
- 抽奖逻辑放在 `core`（纯 Java，注入随机源），由单元测试固定各品阶的权重和边界。

### 4.3 组合结果

- **僵尸骑兵**：僵尸马驮着手持铁矛的僵尸。仿照原版僵尸马自然生成时的组合（`ZombieHorse.finalizeSpawn` 在 `NATURAL` 原因下生成骑手），因为刷怪蛋原因不会自带骑手。
- **鸡骑士**：幼年僵尸骑鸡。
- **蜘蛛骑士**：骷髅骑蜘蛛。
- 组合里的每只生物都算盲盒开出的随从（第 5 节）。
- 普通的"僵尸""幼年僵尸"结果要显式指定幼年与否，并压掉原版刷怪蛋生成时附带的随机幼年和鸡骑士（做法同现有 `MonsterCompanions.spawn`），概率只由本表决定。装备、附魔等其余随机内容照原版生成流程。
- 彩蛋村民被旁边的僵尸咬到时按原版处理：困难难度下必定转化为僵尸村民，并按随从后代规则继承主人。

## 5. 开出的生物：主人的随从

盲盒和角色自带或购买的僵尸蛋一样，开出的**全部是主人的随从**，沿用现有随从规则（`MonsterCompanions.adopt` 一类的归属与清理）：

- **不选主人当目标**。范围伤害照原版：凋灵蓄力结束时的爆炸、苦力怕爆炸、女巫药水同样会伤到主人。
- **只有能在地面跟随的物种会跟随和协攻**（现有 `MonsterCompanions.configure` 的物种判定）；凋灵、监守者、旋风人、猪灵蛮兵、彩蛋动物等记在主人名下，但不跟随，按原版自行行动。
- **伤害和击杀的功劳都给主人**：造成的伤害计怪物币，击杀人类计复生图腾（盖战斗来源印记，同现有随从）。
- **主人离场时立即以死亡表现清理，不掉落**：阵亡、断线、召回、主动归返、放弃暂离、复生、退出都算离场。被人类在场上打死时照原版掉落，例如凋灵掉下界之星。
- **增援、分裂、感染、转化、召唤产生的后代**继承主人，按同样规则清理。
- **别的僵尸玩家不能收编**，视同"别人的随从"。
- **主人自己可以用拘魂袋收回**，收回后占名额，并且不受拘魂袋品阶限制（普通拘魂袋也能收回盒子里的凋灵）。放出时仍是主人的随从，主人离场照样清理。想让盲盒怪跨主动归返保留，就先收进袋里。

带战斗来源印记的实体打不了末影龙（`MonsterCombatRuntime.rejectMonster`），所以盲盒怪不会替人类屠龙，Boss 不按维度限制。

**实现要点：目标限制要覆盖大脑 AI。** 现有"不选主人当目标"的约束针对以 Goal 驱动的物种。监守者（`Warden.canTargetEntity` 不排除僵尸）、旋风人、猪灵蛮兵等用大脑 AI，需要补上同样的约束，否则它们会对主人空挥（印记让近战打不到主人）。凋灵本来就不以亡灵为目标（`WitherBoss.LIVING_ENTITY_SELECTOR` 的 `WITHER_FRIENDS`），僵尸玩家按物种识别已被豁免。

## 6. Boss 登场

两种 Boss 都按原版召唤式登场，留出反应时间：

- **凋灵**：放出后调用原版 `WitherBoss.makeInvulnerable()`，从 1/3 血开始蓄力 **11 秒**（220 tick）、期间无敌，结束时在原地发生威力 7 的爆炸，并全服广播登场音效（`globalLevelEvent(1023)`，大厅里也听得到）。爆炸本身能把它从墙里炸出来。开出时，主人的动作栏提示"凋灵正在蓄力，快离开"。
- **监守者**：以原版 `TRIGGERED` 原因生成，破土而出，破土期间无敌（`Warden.finalizeSpawn` / `isInvulnerableTo`）。位置先按原版尖啸体召唤监守者的方式在点击位置周围搜索合适地点；找不到时直接在点击位置生成，不拒绝。原版的 60 秒挖掘冷却（`DIG_COOLDOWN`）照常生效：之后一直没人惊动它，它会钻回地下消失。这是原版给人类留的反制手段，保留。

已用 minecraft-knowledge 核实（26.3）：尖啸体由 `SculkShriekerBlockEntity` 调用 `SpawnUtil.trySpawnMob(WARDEN, TRIGGERED, …, 20, 5, 6, Strategy.ON_TOP_OF_COLLIDER, false)`，即最多尝试 20 次，水平 ±5、垂直从 +6 向下扫到 −6，找上方无碰撞、自身顶面完整的方块，再检查生成规则和实体遮挡。盲盒照搬这套搜索，只额外跳过未加载的区块，避免搜索时加载地形。
