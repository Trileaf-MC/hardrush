# 怪物夜视

2026-11-25 与需求方讨论定稿（[#85](https://github.com/Trileaf-MC/hardrush/issues/85)）。状态：已实现（2026-11-26），GameTest 覆盖，待人工客户端验收（[2026-11-17 场次](../人工客户端测试/2026-11-17-界面挡住动作栏的提示.md)第十五段）。

## 背景

人类可以用火把照明，怪物玩家不能放方块，在洞穴、末地和夜里往往什么都看不见。出场落点的打分本来就偏好暗处，怪物落地后自己却看不见，两者是矛盾的。

原版敌对生物索敌只看距离和视线，不受光照影响：僵尸在漆黑的矿洞里照样能追人。所以让化身怪物的玩家天生看得见黑暗，符合原版，也不需要另外解释。

## 讨论结论

- issue 原文写的是“夜间出击时获得夜视”。但怪物玩家白天不会被晒伤，白天同样出击；白天进洞穴，和夜里一样黑。所以改为**出场期间全程都有**，不分昼夜、不分维度。
- 不按亮度或时间动态开关。进出洞口时画面会忽明忽暗，玩家也看不出规律。
- 不做成女巫商品。“看得见”是基础体验，不该收费。
- 不和悬赏星级或追猎强度挂钩。所有出场都给。

## 规则

| 项目 | 规则 |
| --- | --- |
| 谁有 | 在挑战世界出场的怪物玩家本体。包括僵尸、骷髅、苦力怕，以及溺尸、流浪者形态 |
| 何时有 | 出场期间全程都有，不分昼夜、维度 |
| 效果 | 原版夜视（`MobEffects.NIGHT_VISION`），等级 I，**无限时长**（`-1`），所以没有到期前的闪烁 |
| 粒子 | **不显示**（`visible=false`）。效果粒子所有人都看得见，会让人类认出哪只怪物是玩家变的，破坏随从混淆和钟声显形的设计 |
| 图标 | 显示（`showIcon=true`）。只有怪物自己看得到，用来让玩家知道自己有夜视 |
| 何时没有 | 不再是怪物角色时移除：回营地、暂离或掉线暂存、出场结束、恢复成人类 |
| 被清除后 | 不自动补回。牛奶等原版途径清掉夜视后，要等下一次重新绑定身体时才会再给：重生、重连、再次出场、跨维度、溺尸或流浪者转化 |
| 苦力怕滞留云 | 苦力怕自爆时，身上的效果会照原版复制进滞留云，但**夜视不复制**。只有夜视时不留云，和没有效果的原版苦力怕一样。否则人类走进云里就能拿到无限夜视，而且每次自爆必留云，会暴露玩家身份 |
| 说明 | 不另发文字提示，也不改物品说明。只靠原版的效果图标 |

不在本方案范围内：

- 观战者夜视。
- 刷怪蛋召唤的随从：原版生物本来就不受光照影响。
- 女巫卖的迅捷、抗火、再生药水：照旧显示粒子，不改。

## 实现要点

以下是落地时的接入点，实现时以代码为准。

1. **给予**：在 `MonsterRoles.bind` 里给。`bind` 覆盖了首次选择角色、`AFTER_RESPAWN` 重生、`onJoin` 重连、跨维度重新绑定、形态转化这几条路径；原版重生会清空效果，所以必须每次绑定时都给。用 `new MobEffectInstance(MobEffects.NIGHT_VISION, MobEffectInstance.INFINITE_DURATION, 0, false, false, true)`（ambient、visible、showIcon 三个参数的含义以 26.3 源码为准）。
2. **识别**：`MonsterRoles.intrinsic` 判断一个效果是不是身体自带的夜视（夜视、无限时长、不可见）。移除和滞留云都用这一个判断，以后加别的自带效果也只改这里。
3. **移除**：在 `MonsterRoles.restoreOriginal` 里只移除自带的夜视。它覆盖了 `clear`、`suspend`、`onDisconnect` 三条路径。回营地时 `PlayerProfiles` 的 `removeAllEffects` 本来就会清掉所有效果，这里是为了保证离开怪物身体时一定没有夜视，不依赖后续流程。`clear`、`suspend` 另外清掉其余无限时长效果（临别礼物）；`onDisconnect` 本身不清，对局中断线会先经过 `LobbyRuntime.disconnected` 的 `clear`。
4. **滞留云**：`MonsterCreeper.spawnCloud` 复制效果时跳过自带的夜视，过滤后没有效果就不生成云。
5. **暂存**：`MonsterParking.PAID_EFFECTS` 不加入夜视，capture 只跳过 `intrinsic` 判定的自带夜视（2026-11-27 起持续到阵亡的临别礼物也要暂存，见[女巫药水与药水盲盒](女巫药水与药水盲盒.md)第 9 节）。恢复暂存的身体时，夜视由 `bind` 重新给。
6. **形态转化**：溺尸、流浪者转化（`convert`）会重新调用 `bind`，夜视照常保留（GameTest 已覆盖）。
7. **跨维度**：原版传送门跨维度时效果本来就保留；`MonsterRoles.tick` 发现模板和玩家不在同一维度时会重新 `bind`，所以被清掉的夜视此时也会再给。
8. **原生模板与伪装**：`syncNativeContext` 会把玩家的效果复制给原生模板 `role.model`。模板不会生成到世界里，所以没有影响。伪装（`MonsterDisguise`）转发的是玩家自己的实体数据，夜视的 `visible` 为假，所以不会带上粒子。

## 测试

GameTest（无图形）：

- 三种角色出场后都有夜视：无限时长、等级 I、`isVisible()` 为假、`showIcon()` 为真。转化后仍在。
- 掉线时移除，重连后重新给；被清掉后不每 tick 补回，跨维度重新绑定时再给。死亡重生走的是同一个 `bind`，没有单独测。
- 暂存的身体里没有夜视（只有付费效果）；回营地暂存（`suspend`）、出场结束后没有夜视。
- 只有夜视的苦力怕自爆不留云；带药水效果自爆时，人类走进云里拿不到夜视。

人工客户端测试只需要顺带确认一件事，写进当时最新一篇待测试的文档：怪物玩家在洞穴里能看清；人类看怪物玩家时没有夜视粒子。
