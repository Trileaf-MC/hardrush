# 死亡消息

2026-11-23：需求方确认定稿。档位、风格与术语见[玩家消息分级](玩家消息分级.md)，逐条文案同步登记在[玩家消息文案](玩家消息文案.md) G 节。

## 问题

聊天栏里的死亡消息完全由原版生成。怪物玩家出手时，原版看到的攻击者是模板怪物：近战是 `role.model.doHurtTarget`，骷髅的箭由 `MonsterRoles.nativeArrowShooter` 换成模板骷髅，苦力怕自爆的伤害来源是真苦力怕。所以人类被怪物玩家杀死时只显示“被骷髅射杀”，看不出是谁。苦力怕自爆后，本人还会以 `genericKill` 死亡，留下一条“Bob被杀死了”。

## 原则

1. **句式沿用原版。** 原版的翻译键和参数结构都保留，客户端照常本地化，“在逃离……时注定要摔死”这类说法原样保留。我们只替换句中代表实体的名字。
2. **名字说清是谁、以什么身份。** 怪物玩家写作“化身{形态}的{玩家}”。形态以出手那一刻为准：箭射出后本人回营改选了别的角色，仍按射箭时的骷髅写。溺尸、流浪者照写。
3. **凶手与击杀归属一致。** 原版会用 5 秒内最后一个伤害者补上“在逃离……时”的说法，`KillCreditMemory` 按同一规则判定复生图腾与战绩。所以只要名字换对，聊天栏、图腾归属和战绩说的就是同一个人。
4. 名字的改写只看实体本身：只有已出击的怪物身体、召唤物和收编生物才会改名，所以营地和普通模式的死亡消息与原版一致。复仇只认挑战世界里人类的阵亡，庆祝期不算。
5. 复仇和原地复生的句子与原版死亡消息放在一起看，所以沿用原版死亡消息的白色纯文本，不套用 T5 的灰白配色。

## 名字规则

| 实体 | 显示为 | 例 |
| --- | --- | --- |
| 怪物玩家（凶手或阵亡者） | 化身{形态}的{玩家} | 化身骷髅的Bob |
| 怪物召唤的僵尸 | {主人}召唤的{生物} | Bob召唤的僵尸 |
| 拘魂袋放出的生物 | {主人}收编的{生物} | Bob收编的烈焰人 |
| 人类、野生生物 | 原版不变 | Alice、僵尸 |

召唤物和收编生物只写主人的名字，不写主人的形态：句子里会少一个“的”，而且收编生物的主人可能是人类。

鼠标悬停沿用原版实体信息：名字为玩家名，类型为形态对应的原版生物。

## 场景

| 场景 | 文案（原版中文句式，以客户端翻译为准） |
| --- | --- |
| 怪物玩家近战击杀人类 | Alice被化身僵尸的Bob杀死了 |
| 怪物玩家射杀人类 | Alice被化身骷髅的Bob射杀 |
| 苦力怕玩家炸死人类 | Alice被化身苦力怕的Bob炸死了 |
| 被怪物玩家打中后 5 秒内摔死、淹死、烧死 | Alice在逃离化身骷髅的Bob时注定要摔死 |
| 召唤物、收编生物致死 | Alice被Bob召唤的僵尸杀死了 |
| 人类击杀怪物玩家 | 化身骷髅的Bob被Alice杀死了 |
| 怪物玩家死于环境 | 化身骷髅的Bob试图在熔岩里游泳 |
| 苦力怕玩家自爆，本人那条 | 化身苦力怕的Bob爆炸了（原版 `death.attack.explosion`，替换 `genericKill`） |

怪物玩家的死亡全部照常广播。

## 复仇（新增 T5）

- **记仇**：人类 B 阵亡，击杀归属是 A（A 当时是人类或怪物都行），就记下“B 的仇人是 A”。B 每次以人类身份阵亡都会覆盖这笔记录；阵亡时没有击杀归属，就清除记录。因此 B 复生后就不会再触发旧仇：要再成为怪物，B 必须再次以人类身份阵亡，记录随之更新。
- **触发**：B 作为出击中的怪物，拿到了人类 A 的击杀归属。B 召唤的僵尸、收编的生物杀死 A 也算。
- **一次性**：触发后清掉。回合结束时全部清空。
- **文案**：化身骷髅的Bob终于杀死了Alice：“这次我要夺回失去的一切！”
- 替换这次的原版死亡消息，不另发一条，A 的死亡画面上也显示这句。形态按致命一击判断；由召唤物或收编生物完成的复仇，取 B 当前的形态。
- 只记在内存里，服务器中途重启后丢失。复仇只是点缀，丢失不影响公平。

## 原地复生（新增 T5）

人类手持复生图腾阵亡时当场复活，全服广播：

| 情况 | 文案 |
| --- | --- |
| 有凶手 | Alice险些被化身骷髅的Bob杀死，靠复生图腾挺了过来 |
| 凶手是人类、野生生物 | Alice险些被Carol杀死，靠复生图腾挺了过来 |
| 没有凶手（岩浆、摔落等） | Alice险些丧命，靠复生图腾挺了过来 |

凶手按原版死亡消息的规则取：先看致命一击的来源，没有时取 5 秒内的击杀归属。原地复生不算阵亡，不记仇，也不触发复仇。本人仍收到原有的动作栏提示“复生图腾生效 · 还剩 n 个”。

## 实现

- `dev.hardrush.death.DeathNarration` 统一负责：在 `ServerPlayer.die` 计算死亡消息时打开命名范围，范围内实体名字按上表改写（`Entity.getDisplayName`）。范围之外的名字不变，`/kill` 反馈、进度等不受影响。
- 苦力怕自爆的本人消息、复仇消息都在同一处替换整句。
- 记仇规则是纯规则，放在 core 的 `RevengeLedger`，由单元测试覆盖。
- 原地复生广播在 `TotemSave.pop` 发出，和死亡消息同样以原版广播方式发给全服。
