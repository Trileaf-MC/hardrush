# 大厅工坊：自己建营地，打包分享给别的服主

HardRush 的准备大厅不是写死的地图。服主可以在游戏里搭一座自己的营地，把集结区、复生祭坛、女巫商人、宝库这些功能绑上去，然后打包成一个 `.hrlobby` 文件，自己装，也可以发给别的服主。别人做好的营地，下载下来放进文件夹就能装。

全程用原版客户端，不用装任何客户端模组。

## 几个特点

- **在游戏里搭**：每份草稿有一个独立的世界，原版命令和 WorldEdit 都能用。功能靠放“标记”来绑定，标记放在哪里，功能就在哪里生效。缺了什么、哪里有问题，工坊里都会提示。
- **一个文件就是一座营地**：发布出来的大厅包是单个 `.hrlobby` 文件，方便分享。换上新大厅时不打断正在进行的比赛，不满意也能一键回到上一个大厅。
- **陌生人的包也能放心装**：安装时会清洗包里的内容，命令方块、刷怪笼等方块会被去掉，容器会被清空，点击命令会被剥掉，只保留几类装饰实体；体积过大或格式不对的包直接拒绝。
- **跟得上模组更新**：大厅包做好时如果还没有某个新功能，安装时会自动补一个临时设施，并告诉 OP 缺了什么。
- **已有的地图不用重建**：可以直接导入整个存档，或者 `.schem`（WorldEdit／FAWE）、`.litematic`（Litematica）、`.nbt`（原版结构）建筑文件，导入后再放标记。

## 上手

2 级以上 OP 站在营地时，快捷栏里会自动出现一个“大厅工坊”制图台，右键打开菜单，之后全部点选（也可以输入 `/hardrush lobby`）。进工坊搭建、绑定功能需要 2 级 OP；发布、安装、导入、回滚需要 4 级 OP。

在草稿里搭建时，顶部状态栏直接写出还有哪些问题挡着发布；右键快捷栏里的“验收清单”，补齐缺失功能要用的标记和方块会放进快捷栏，所有问题也会列在聊天栏里。

需要放文件的位置（相对服务端根目录）：

| 用途 | 位置 |
| --- | --- |
| 大厅包库：发布的包写到这里，别人分享的包也放这里 | `hardrush/lobby/packs/` |
| 要导入的存档或建筑文件 | `hardrush/workshop/import/` |

## 建筑清单：导入建筑时顺带绑好功能

建筑文件旁边可以放一个同名的清单 `<文件名>.hardrush.json`（例如 `camp.schem` 配 `camp.hardrush.json`）。导入这个建筑时，模组按清单放好功能标记、给告示牌写上字，还可以把栅栏、玻璃板、墙按原版规则连起来。用外部工具或 AI 建图时，这样就不用进工坊再一个个放标记。

```json
{
  "format": 1,
  "origin": [0, 0, 0],
  "update_shapes": true,
  "markers": [
    {"function": "assembly", "as": "zone", "shape": "flood", "at": [20, 0, 30]},
    {"function": "landing_central", "as": "point", "at": [24, 1, 24], "yaw": 180},
    {"function": "rules", "as": "click", "at": [22, 1, 20]}
  ],
  "signs": [{"at": [31, 2, 10], "front": ["右键模型", "选择僵尸"]}]
}
```

- 坐标是建筑文件里的方块坐标；`origin` 是建筑最小角在你自己坐标系里的位置，用来直接沿用建造时的坐标。
- 落点、模型、方框区域的 `at` 是脚所在的那一格；连片区域、方块、点击、文字的 `at` 是被绑定的方块本身。
- 清单写错时整个导入失败，并说明是第几条、什么问题。

完整格式见 [建筑清单与大厅包构建](plan/建筑清单与大厅包构建.md) 第 1 节。

## 不开游戏构建大厅包

`lobby-packs/<id>/` 下放 `lobby.json`（名字、作者、版本）、建筑文件 `build.schem` 和清单 `build.hardrush.json`，然后：

```bash
python3 scripts/lobby-pack.py build <id>
```

它在无头服务端里导入、验收并发布，产物和验收报告写到 `lobby-packs/<id>/out/`。仓库里的示例大厅包都是这样构建的；用 AI 建造示例包的流程见 `.claude/skills/lobby-pack-builder/SKILL.md`。

## 默认大厅

模组自带的默认营地本身也是一个大厅包（`platforms/mc263/src/main/resources/hardrush/lobby/default.hrlobby`），和服主自己做的包走同一条安装路径。要改默认大厅，就在工坊里改默认草稿、发布，再用发布出的包覆盖这个文件。
