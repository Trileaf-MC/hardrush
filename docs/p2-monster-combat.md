## 正式入口与身体

角色身体只在已持久化的 `MONSTER_DEPLOYED`、当前原生玩家对象、正确本轮维度和档案就绪后执行。大厅、死亡、返回、停服及比赛冻结均拒绝新的攻击／技能，取消尚未发射的连射或未完成引爆；角色选择必须匹配正式出场记录，同角色重复请求不会治愈身体。

从不可变轮次配置读取生命、原版移动属性及护甲、僵尸近战、蓄力／连射间隔和苦力怕引爆值；默认遵循现有 26.3 原版数值，移动属性换算为玩家输入。沿用已有自动装备、物资守恒、饥饿／疾跑／自然回血与亡灵环境规则。固定技能物品新增说明及剩余冷却显示；右键、`/hardrush skill`、菜单技能按钮统一进入同一服务端请求。

## 持久冷却与效果门槛

`Participant` 按 UUID／技能 ID 保存绝对毫秒到期时间，僵尸召唤和骷髅连射分别保存；跨返厅、换角、败退、重连和同轮新生命保留，离线及正常停服期间按现实时间继续流逝。首次怪物技能可用。快照编码升为 4，兼容读取 1／2／3；数据库 schema 仍为 5。写出新版后回退旧程序须使用升级前的一致性备份。

施法请求重验轮次、生命、外出序号、角色、在线及冷却，先提交 SQLite，再应用效果；提交中对同 UUID 去重。数据库失败不发射或生成实体。召唤先准备两处已加载安全站位，提交后复查地形、保护和距当前身体距离，再完整生成一对；失败时删除半份实体，通过本次真实 reservation 的 CAS 退回冷却，旧回调不能退回新施法。身份已离开本次出场的中断保留已受理的冷却；未知的执行异常记录日志、释放请求锁并保留冷却，避免重试造成重复效果。该边界不代替 P3 的强制终止恢复。

## 统一攻击白名单

原生模型、召唤物和箭矢在创建时冻结轮次、主人 UUID、生命和外出序号，实体存档保留来源。箭矢不能因射手后续身份变化替换已冻结来源；旧轮来源、损坏来源、非法身份及比赛冻结均拒绝作用。已发箭和召唤物可以在同轮主人离线／换身份后继续命中合法人类，主人本人始终排除。

原生近战最外层、箭矢命中前、爆炸和伤害／效果／击退／点火入口共享策略；只有同轮、当前原生对象、在线、存活、非旁观、非隔离且不在保护区的人类才是合法受害者。动物、其他怪物、龙／龙部位、水晶和保护区目标在副作用前拦截；保留合法人类的原版护甲、盾牌、附魔及荆棘反伤。物品、容器及地形操作继续由固定装备协议与保护挂钩限制。

原生模型与召唤物的近战同时写入 P1 攻击因果，记录主人创建时的怪物身份，不能被误算为人类龙尾刀。该来源基础不代表已接通击杀复生资格；资格、死亡批次与救场仍属 P2-12～15。

本批 125 core＋71 persistence＋77 platform＝273 项 JUnit、89 项必需无图形 GameTest（含 3 项未启用专用场景的门禁）通过。独立正式大厅技能整链与正式身份回归各 1 项；命令、实际结果、构建和源码校验见本批证据。
