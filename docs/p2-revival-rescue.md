# P2 第四批：技能专验、死亡批次、复生与救场

日期：2026-10-15。继续提前推进 26.3 的 P2 开发，基础为 `f53c795`。本批源码与证据一同提交，未推送或发布；源码与制品指纹见 [证据](evidence/p2-revival-rescue-20261015/manifest.json)。P0／P0b／P1 和 P2 阶段验收仍未通过。

## 死亡与资格

原生 `AFTER_DEATH` 先锁住身体，记录 UUID／生命／外出序号；原生伤害返回后补实际致死 `CombatEvent`，最外层因果 scope 关闭时才一次提交整个批次。所有受害者的死亡身份、怪物的非叠加资格、自身败退及救场／结束同属一次 SQLite 快照。苦力怕的爆炸和自身死亡由同一外层 scope 包裹，不能先团灭后发资格。每 UUID 的已受理死亡身份去重，不缓存无界伤害批次；旧轮、旧生命与重复关闭不能重新奖励或中断当前轮。

资格只根据实际致死来源的轮次、创建时怪物身份和当时仍为怪物的主人发放，近战、箭、召唤和苦力怕保留不同来源类型。离线／大厅怪物可以获得资格，主人已复生为人类不再发放；人类旧箭、旧轮箭、环境伤害及间接推落不追溯奖励。一次多杀仅保留一份资格，自己的怪物死亡不会清除资格。

## 主动复生与救场

大厅按钮与 `/hardrush revive` 共用服务端重验入口，校验轮次、原生对象、生命、出场序号、阶段与资格，出场冷却期间也可消费。SQLite 先原子消费并增加生命序号，人类在线计时在安全安置和档案保存完成后才开启。身体清除怪物属性、装备／控制物品、经验、效果及旧传送物，恢复人类生命、饥饿和生存能力，回本轮主世界出生保护区；同轮进度、末影箱和持久技能冷却保留。不会恢复旧人类背包，原有死亡掉落仍在原世界。档案错误保留数据并停止适配，不假称复生成功。

极限模式按全体人类身份判断：有人类但全部离线，只暂停计时；无人类且有资格才开启 60 秒救场；两者都没有则失败。新资格不延长正在运行的救场截止。救场内可正常回大厅、消费资格或接受新参赛者，成功恢复人类后返回运行。5 秒返厅引导完成时若仍有持久化写入，等待该操作完成再受理返厅，检查点竞争不会吞掉完成的引导。正常停服冻结剩余救场时间，重开不重新获得 60 秒。截止与消费按服务端受理顺序串行，已受理的有效消费不因 SQLite 回调较晚而失效；同批可信首龙通关优先，成绩边界使用首龙实际死亡观测时刻。原生伤害前以独立截止查询关门，普通检查点／选角写入不会因 SQLite 延迟延长救场；已在截止前受理的复生／加入保留继续权，截止后的新箭命中不能再触发首龙终局。

计时、死亡／复生统计、末地 UUID 去重、进度 ID 去重、TAB 人数／救场倒计时及历史书沿用正式投影，并以完整循环复核。普通模式仍原生重生，不发资格或因死亡画面团灭。死亡提交成功回调同步开放原生重生许可，避免立即到达的重生包等待下一 tick 而被拒绝；正常十轮整链含此立即重生回归。

## 技能专项与验证边界

僵尸的一对幼年召唤物新增持久召唤事件 ID，位置距离取轮次配置；保留自然消失，不加持久标志或区块票。专项覆盖实体 NBT 归属回读、无物品／经验、连射真实间隔与当前朝向、取消未发箭、默认 30 tick 引爆和提前死亡；爆炸按难度／距离／遮挡／护甲与实际原版苦力怕对照。

最终 143 core＋73 persistence＋79 platform＝295 项 JUnit、94 项必需无图形 GameTest（含 3 个未启用专场门禁）通过；独立正式大厅的 20 次循环、正式身份整链和普通模式真实世界十轮回归各 1 项通过。命令、日志和指纹见本批证据。正式运行时循环使用原生玩家登录／替换、真实 SQLite／档案 IO、原生菜单包和怪物近战；关闭自然刷怪并冻结主人召唤物 AI 的受控夜间场地、嵌入网络及可推进测试计时明确属于无图形夹具。它不能替代客户端画面、输入、自然地形战斗体验或 P2-17 所要求的人工 20 次完整循环。人工步骤见 [P2 完整闭环测试](人工客户端测试/P2复生救场与完整闭环.md)。

强制终止恢复、磁盘／数据库故障注入、完整集成、多版本和负载仍由后续阶段处理。本批未改变快照编码 4 或 SQLite schema 5；回退程序仍须遵循上一批的备份约束。

验证中修复了首龙持久化标签只接受旧 `FINISH`、复生档案写盘前提前解锁、救场截止被 pending 视图冻结，以及返厅引导被普通写入竞争丢弃的问题。另收紧测试隔离：安全出场地形夹具随当次随机结构原点建立，避免上次残留宽平台填平窄边；连射夹具保留真实时间等待，生产从一次实际发射完成后计算下一箭期限，600 ms 和朝向断言不放宽。
