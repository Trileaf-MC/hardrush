# P2 第一批：正式身份转换与出生保护

日期：2026-10-15。范围为 Minecraft 26.3 的 P2-01／P2-02 开发，按本次指示在 P1-G 尚未验收时提前推进。P0／P0b／P1／P2 阶段均未因此通过。

## 身份与原生档案

普通和极限均使用已冻结的当轮规则，允许正式加入／就绪开赛。普通死亡仍保留人类重生资格：原版选择有效床／锚、失效则回本轮主世界，原生替换对象在下一生命提交并完成档案核验前禁止操作。全员死亡画面只暂停挑战计时，不按极限团灭结算。

极限死亡先让原版处理掉落，立即锁定该原生死亡对象的操作，再把 UUID／当前生命从 `HUMAN_ACTIVE` 提交为 `MONSTER_LOBBY`。只有提交成功后才执行原版玩家替换并送往长期大厅；不消费人类床／锚。怪物大厅档案保持隔离，不能通过再次加入、死亡画面请求或退出重连恢复人类身份。保留本轮生命序号、进度、末影箱、参与历史及原版累计统计，背包中的死亡物资不还原。SQLite 参赛投影把极限身份转换计为一次死亡。自动原生重生补齐调用方负责的网络玩家引用、位置同步和加载计时器，确保重连／断线操作属于替换后的对象；隔离阻止原生档案写入时仍独立保存累计统计，避免断线清空缓存后丢失原版历史。

死亡对象的临时操作锁不提前写成“已隔离档案”标志，否则正常停服／重连会优先恢复较旧的活人悬挂档案。原生死亡快照和已完成的怪物大厅悬挂档案分别按原有持久化屏障保存。

## 出生与大厅保护

长期大厅全区保护；本轮主世界保护区以出生点为中心，采用当轮半径（默认 32 格）、全高度圆柱。拒绝保护内的伤害、攻击、击退、负面效果、方块修改、容器／一般物品交互和掉落拾取；历史书保留专用领取／阅读入口。近战、投射物、爆炸、流体、活塞及原生传送／载具移动分别在服务端路径检查，不依赖客户端 GUI。

`Participant.hasLeftProtection` 随当轮快照持久化。首次离区在持久化成功前被阻止，成功后允许离开；后续步行、传送、珍珠、传送门及载具都不能进入或穿过保护区。普通合法新生命重置该标志；区外床／锚出生的新生命在区外消费离区权限。未来极限消费资格的入口需要沿用新生命重置规则，本批未提供资格消费。

阻回使用已加载且仍安全的站位，清除速度和跌落残留；不清除区外既有火焰／负面效果，避免借边界洗掉战斗状态。合法新生命按原版重生与档案处理清理火焰／负面效果。没有安全回退位置时隔离到大厅并暂停该轮，不制造战术地形或把玩家放进虚空。内部正常停服／隔离送大厅保留权威通道，不受竞技离区提交阻挡。

当轮快照编码从版本 1 写为版本 2，仍可读取版本 1；旧快照没有离区历史，现有生命获得初始权限，区外身份由保护适配器重新提交为已离区。数据库 schema 仍为 5。升级后写出的版本 2 快照不供旧版模组读取，回退应使用升级前一致性备份。
