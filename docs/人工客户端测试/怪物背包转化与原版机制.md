# 怪物背包、转化与原版机制人工验收

日期：2026-10-26。适用版本：Minecraft Java Edition 26.3。状态：**全部待用户手动测试**。本轮 `build assemble`、425 项 JVM 测试和 170 项默认无图形 GameTest 已通过，定向正式流程结果见[差异文档](../玩家怪物与原版差异.md)。未运行真实客户端，自动结果不能作为本页打勾依据。

使用包含本轮改动的独立测试实例，记录实例 UUID、源码提交、JAR SHA-256、规则指纹、客户端版本、实际世界难度、测试者和日期。至少准备一名人类、两名可转怪物的玩家及旁观者；涉及正常死亡掉落、雷击、药效和稀有装备的场景，可以由管理员设置夹具，但必须记录设置内容。不要重置日常服务器、存档或数据库。

玩法依据见[玩家怪物与原版差异](../玩家怪物与原版差异.md)。本文替代旧清单中“固定技能槽位”“90 秒召唤两只幼年僵尸”“点击后不可取消的苦力怕倒计时”等旧预期。保持正常正式大厅入口，不使用管理员外观探针代替正式角色出场。

## 出场、装备与旁人显示

- [ ] 三种基础角色仍从大厅展位选择；溺尸和流浪者只能在本次出场中通过环境转化得到。
- [ ] 僵尸每次出场获得成年、幼年僵尸蛋各 1 枚；骷髅有弓与三连射物品；苦力怕第一格为火药“引爆器”；归返物品初始在第 8 格。说明清楚，不要求记住槽位才能使用。
- [ ] 玩家出生装备可能包含铜甲、铁矛和附魔装备；切槽、开关背包/容器、模型重新进入观察范围、跨维度不会重抽装备或补回已用物品。概率边界和 5–30 附魔输入以自动测试为准，不凭少量人工样本判断概率通过。
- [ ] 僵尸、骷髅及转化形态手动替换主手、副手和四件护甲，旁人立即看到相同装备；切槽、交换副手、持盾、受击后无旧装备残影或重复装备。
- [ ] 装备带来的伤害、护甲、附魔和原版耐久行为与实际库存一致，换掉装备后不保留旧加成。
- [ ] 怪物攻击穿荆棘护甲的人类或怪物时，反伤落在真实攻击者身体上；怪物穿荆棘护甲受到攻击时也能正常反伤。旧出场的箭、三叉戟或模型不会把反伤转移到新出场身体。
- [ ] 苦力怕能在背包/手中携带物资，但护甲槽不能装备，所持武器不能近战或提供额外攻击能力；旁人仍看到不持物的苦力怕模型。
- [ ] 僵尸、骷髅及对应转化形态裸头日晒不燃烧、头盔不因日晒损耗；真实火焰和岩浆仍能伤害。不能疾跑、滑翔或自然回血；亡灵呼吸、药效与治疗/伤害反转保持正确。

## 自由整理与绑定物资防外流

- [ ] 三种角色均可拾取世界物资、整理背包、交换副手、丢弃普通物资，拾取不会自动换掉已经穿好的装备；地面和背包总数守恒。
- [ ] 依次在本人背包使用普通点击、右键拆分、Shift、数字键交换、拖拽、双击收集和 F 键，普通物资及绑定物资均可按允许的库存操作移动。
- [ ] 将蛋、连射物品、引爆器和归返物品分别移到其他快捷栏和副手再使用；按实际持有物品识别，原来的槽位不会自动补出第二份。
- [ ] 只重命名一个普通火药/骨头/回响碎片不会获得技能；其他玩家的绑定物资、旧出场遗留物资也不能用于本次身体。
- [ ] 对绑定物资分别尝试 Q、Ctrl+Q、鼠标拖到窗口外、容器 Shift 转移、数字键交换、拖拽跨到容器和双击收集；绑定物品不会落地或进入外部容器，普通世界物资仍可正常转移。
- [ ] 将绑定物品放入收纳袋，或用收纳袋点击绑定物品，不能把绑定物资藏入可转交的物品。普通物资的收纳操作不复制或吞掉物品。
- [ ] 打开箱子、木桶、潜影盒、漏斗、发射器/投掷器、末影箱和适用的储物载具，测试普通物资存取；加工、合成、附魔等界面仍不可使用。
- [ ] 背包已满时，鼠标拿着绑定物品关闭界面、走远关闭或断线，不丢失控制物、不产生可拾取的绑定掉落；如果普通物资被挪回地面，数量只出现一次。
- [ ] 用夹具准备入场前的满背包、鼠标所持和个人合成格物资，经历出场与归返后统计背包和地面总量；不会因关闭界面先掉地、退场再从快照还原而复制物资。
- [ ] 用普通食物、药水、珍珠、非角色刷怪蛋等右键方块/空气/实体均不能绕过限制；破坏、放置方块和用角色蛋修改刷怪笼均被拒绝。

## 归返、死亡与物资结清

- [ ] 携带可辨认数量的普通物资、绑定出生装备/道具、鼠标所持物品，分别主动归返、正常死亡、断线、复生、退出；绑定物资清除，剩余随身世界物资仅掉在原战场一次。
- [ ] 正常死亡时带消失诅咒的世界装备按原版消失；主动归返等非死亡结清不把它当作死亡销毁。重复死亡/清理回调、重连或回营地不会再次掉出相同物资。
- [ ] 已经合法存入普通容器的世界物资保持原位；不能因角色退出把同一物资再掉一份。
- [ ] 角色改变、失败出场补偿和跨维度时不会恢复旧控制物、用掉的蛋或旧装备。断线回营地后，下一次出场重新给予新身体补给；同一身体内不重复补给。
- [ ] 屠龙庆祝仍走既有封存和临时装备流程，不在结算后的世界额外掉出整包物资，不把怪物绑定物带到下一轮。

## 僵尸水下转化与溺尸三叉戟

- [ ] 眼睛持续浸水后按原版 600/300 阶段参数成为溺尸；分别在准备段和转化段离开水，转化取消，重新浸水重新开始。与原版实体对照进入/完成边界，不把参数之和当成精确完成 tick；低 TPS 时不以固定现实秒数替代。
- [ ] 只让脚或身体接触水、眼睛在水外时不会提前转化。转化完成时外观、声音、AI 物种关系同步，原生命、装备、库存和已用物品状态保留，不回血或补给。
- [ ] 将未用成年/幼年蛋分别放在不同快捷栏、副手、主背包及鼠标上；转化后对应年龄/数量的蛋变为溺尸蛋。已经使用的一枚不会重新出现，普通非绑定蛋不被替换。
- [ ] 转化后的玩家本人及已经存在的僵尸随从保留旧装备，不凭空获得三叉戟。用剩余溺尸蛋生成的成年/幼年随从均持三叉戟，正常死亡不保证必掉。
- [ ] 溺尸持三叉戟按住不足 10 tick 松开不投掷；至少 10 tick 后可投掷，每次间隔至少 40 tick。手中的武器保留，投射物不可捡回或收进背包。
- [ ] 分别测试无附魔、忠诚、激流和其他合法附魔三叉戟；不会激流冲刺、忠诚返还复制武器，也不会在命中、落地、卸载/重载后出现可拾取副本。
- [ ] 转化后的溺尸跨维度、暂时失去观察者后仍保持当前形态、装备和物品余量；归返后重新出场从基础僵尸开始。

## 随从的生成、跟随与生命周期

- [ ] 成年蛋和幼年蛋各独立生成一只对应年龄的真实实体，成功才消耗；方块被占用、边界、保护区或无有效位置时不扣蛋。普通空气右键不无条件生成，方块/水面交互符合说明。
- [ ] 分别右键整块顶面、方块侧面、下半砖/地毯等薄方块及水面，落点按实际碰撞和原版蛋的位置偏移处理；不悬空卡墙、不把随从埋进方块，失败时不扣蛋。
- [ ] 随从保留实际世界的原版装备、日晒、拾取、经验、掉落、增援与尸系转化；其装备不使用玩家固定最高难度/5–30 增强。正常击杀与管理员清理夹具分开记录。
- [ ] 同维度离开一段距离后随从寻路跟随，距离更远且存在安全位置时传送；不会进入保护区、危险碰撞位置或强制加载未加载区块，不自动跨维度追随。
- [ ] 无主人指令时，随从永不攻击主人，也不主动攻击怪物玩家或其他随从；被怪物玩家攻击后仍不会自行绕过限制报复。
- [ ] 没有主人协攻指令时，附近合法人类仍能被僵尸随从按原版规则主动发现和追击；并非必须由主人先打一下才允许攻击人类。溺尸的白天自动选敌限制单独验证。
- [ ] 主人实际伤害一个合法目标后，随从尝试协攻该目标；空挥、被保护拦截或未造成伤害的攻击不发出指令。原版其他自动选敌继续有效，溺尸白天的自动选敌限制不被取消。
- [ ] 主人和其他玩家可正常攻击随从；随从自然死亡、玩家击杀时按原版掉落装备/物品与经验，不因为绑定主人而统一禁止掉落。
- [ ] 在隔离夹具中触发增援、村民感染和僵尸转溺尸，后代继承原主人和原出场来源；尸系转化不失去归属。治愈出的普通村民不继续作为怪物随从，原主人随后离场时村民保留，不被整队清理误杀。
- [ ] 主人归返、败退、断线、复生、退出或换轮时，整队及后代出现死亡表现后清理，无掉落、经验或击杀收益；不会因为模型重绑误杀仍有效的队伍。
- [ ] 主人离场前先卸载一名随从所在区块，再重新加载：失效实体补做无收益清理；旧轮、旧出场以及历史旧技能召唤物不重新获得攻击资格。

## 骷髅转化、弹药与近战武器

- [ ] 骷髅持续处于粉雪后按原版 140/300 阶段参数转为流浪者；两个阶段分别离开粉雪都会取消，进入/完成边界与原版实体一致。身体按原版骷髅/流浪者抗冻结规则处理，不用额外冻伤代替转化。
- [ ] 转化保留生命、主副手、护甲、库存和连射状态规则；外观、声音及物种关系同步。跨维度保留当前流浪者形态，下一次出场重置为基础骷髅。
- [ ] 副手、快捷栏第 1/9 格、主背包不同位置分别放普通箭、药箭、光灵箭，验证副手优先，其次快捷栏从左到右，再到主背包；切换优先物品后下一箭即采用新弹药。
- [ ] 普通射击与三连射都不消耗箭数；背包没有箭时可射出普通箭，第 9 格不会自动出现占位箭。复制箭不能从地面捡回。
- [ ] 流浪者普通箭造成原版缓慢；药箭保留原药效并按原版叠加，光灵箭不额外出现缓慢。记录实际效果及持续时间，不把所有箭都预设为同一缓慢时长。
- [ ] 三连射第一箭立即发出，后两箭间隔各 0.6 秒，总计 3 箭，默认冷却 20 秒；逐箭改变朝向/优先弹药能反映在对应箭上，期间不能叠普通射击。
- [ ] 连射开始后死亡、归返或失去资格仅取消未发箭；已有箭保留原来源。重连、换角色和正常停服重开不会绕过已保存的连射冷却。
- [ ] 僵尸/溺尸使用铁矛左键刺击、右键举矛，测试距离、移动速度、附魔、盾牌、击退及卸骑；非法目标不出现先受副作用再免伤的情况。
- [ ] 僵尸/骷髅可以使用其支持的普通近战武器；骷髅/流浪者拿铁矛不会获得僵尸矛能力。苦力怕拿剑、矛或三叉戟仍不能武器攻击。

## 苦力怕引爆器、带电与药水云

- [ ] 苦力怕在主手或副手携带普通不死图腾时，致死伤害不会触发图腾保命；死亡后图腾作为世界物资完整掉落。
- [ ] 第一格火药名为“引爆器”，说明为“按住右键膨胀，松开后逐渐消退”；图标保持火药外观，没有进食/饮用动画，不消耗数量。
- [ ] 按住约 20 tick、松开约 10 tick、再次按住，确认从剩余膨胀进度继续；完全消退后不留下定时爆炸，连续按住默认第 30 tick 爆炸且只执行一次。
- [ ] 将引爆器移到其他快捷栏或副手重复测试。打开背包、切换物品、交换手和原版释放使用操作能正确终止按住状态，不因旧槽位继续膨胀。
- [ ] 膨胀期间前进、横移、转向保持正常步速，无停步/回弹且不能疾跑；旁人看到身体移动、闪烁与预警。爆炸发生在当前身体位置。
- [ ] 尚有进度时归返被拒绝；松开并消退到零后可以开始 5 秒归返。提前死亡、断线或失去出场资格后不发生迟到爆炸。
- [ ] 无按住状态下摔落只增加一定膨胀并自然消退，不直接爆炸；按住时摔落保留原版摔伤，并按距离推进到最多引信减 5。记录旁观者动画与真实爆炸时机的差别：原版协议不能精确同步瞬时进度跳变。
- [ ] 实际雷击后当前身体出现带电电弧，雷击伤害和火焰只结算一次；跨维度/模型重绑保留，离场后新身体不继承带电。
- [ ] 带电爆炸范围/伤害与原版带电苦力怕对照，强度为普通的两倍；普通和带电爆炸均不破坏方块或生成火。
- [ ] 带电爆炸同时杀死多只满足原版条件的真实生物，头颅数量遵守原版额度；关闭生物掉落规则后不掉头颅。人类玩家与怪物玩家均不额外掉头颅。
- [ ] 身上有现有效果时爆炸产生药水云；无效果时不凭空生成云。检查半径、10 tick 等待、300 tick 生命周期、效果持续倍率和命中后缩小表现。
- [ ] 云在主人自死后仍按原来源判断合法目标；主人换身份不把旧云变成新身份攻击。保护区、黎明保护、退赛、比赛冻结与旧轮边界均能阻止非法伤害/药效。
- [ ] 云的瞬时伤害与持续效果分别记录。持续药效的延迟死亡沿用现有直接来源结算，不能仅因玩家最近碰过某朵云就补发奖励。

## 战斗保护、奖励与历史兼容

- [ ] 已出场怪物玩家可以互相伤害，也可攻击普通生物和随从；追猎菜单仍只显示合法人类。打败另一名怪物只触发败退，不新增人类击杀复生奖励。
- [ ] 对受保护人类/怪物、旁观者、隔离/退出者、龙、龙部位和末地水晶，分别尝试近战、刺击、举矛、箭、三叉戟、爆炸和药水云；伤害、点燃、击退、卸骑和附魔副作用都被正确限制。
- [ ] 黎明契约期间上述 PvP 手段不能提前生效；解除后恢复当前合法交战关系，旧轮投射物、云或随从不会恢复攻击权限。
- [ ] 苦力怕同次爆炸同时击杀最后人类与自己，按同一死亡批次结算，资格/救场不会先判团灭而吞掉合法奖励；混合人类与怪物受害者时，怪物死亡不计作人类击杀。
- [ ] 用复制出的旧存档验证历史 `zombie.summon` ID、冷却和规则快照仍能读取，原规则指纹不变；旧技能不能重新施放，界面没有旧 90 秒召唤入口，旧召唤物无收益退场。
