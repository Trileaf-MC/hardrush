# 怪物归返受阻与脱困

## 2026-10-30 排查结论

基线：`bad37ee`，Minecraft Java 26.3。此次只排查并补充人工测试清单，未修改生产行为，未启动真实客户端。

1. **持续外力位移可能造成归返软死锁。** 默认归返引导为 5 秒，位置偏离起点超过 0.001 格就中断；移动包也按同样阈值中断，不区分方向键移动与水流推动。僵尸、溺尸、骷髅、流浪者可以水下呼吸，怪物饥饿逻辑也被停用。若地形让玩家一直移动、无法找到稳定站位，又没有其他致死来源，就可能无法归返，也无法靠溺水或饥饿结束出场。并非所有流水都会卡住：水流将人推到墙边后若位置稳定，仍可完成归返。
2. **反复右键实体会重启归返。** `handleInteract` 无条件中断归返，之后怪物的实体交互回调又识别手中归返碎片并开始新的引导。对着随从或生物持续右键，可能不断重置倒计时；对空气/方块使用归返物则有专门的中断豁免。攻击实体应继续中断归返，问题在于归返物的右键交互也被一并处理。
3. **潜行本身不会阻止归返。** 归返开始与持续条件都不检查潜行或蹲姿；保持潜行的服务器身体已经成功归返。出场传送没有主动设置潜行，但也没有清除原来的潜行输入/姿态。安全落点检查使用玩家当前包围盒，可能接受只有当前蹲姿/趴姿能容纳的空间。原版 `Player.updatePlayerPose` 在站立空间不足时会保持蹲姿或游泳姿态。这能解释部分“传送后蹲着”的现象，但不能单独解释归返失败；具体客户端表现仍待人工确认。
4. **存在重连兜底。** 正常对局及存储正常时，出场怪物断线会结束本次出场，重连后进入怪物营地并按规则进入出场冷却。`Shift + F` 的退出确认也是出口，但确认后会失去本轮参赛资格，不应作为正常脱困方式。`/hardrush return` 与归返物走同一个引导，不能绕过水流中断。

## 已执行的无界面验证及其边界

在 `LobbyRuntimeGameTest` 中临时插入诊断探针，使用正式对局、原生服务端连接和独立 SQLite/世界目录执行：

```bash
./gradlew :platforms:mc263:runGameTest -PhardrushCompetition=true -PhardrushLobbyRuntime=true
```

最终运行 1 个完整生命周期 GameTest 通过，包含原有出场、归返、死亡、重连和循环出场流程。诊断探针确认：

- 无方向键输入时，原版水流计算产生 `(0.014, 0, 0)` 的速度；将此位移通过原生移动包报告后，正在进行的归返立即中断。部署中的僵尸身体 `canBreatheUnderwater()` 为真。
- 手持实际绑定的归返碎片，对真实随从发送 3 次实体交互包，3 次均将已有的成熟引导替换为新引导。
- 通过原生输入包保持潜行，并设置蹲姿后，归返成功，同一身体返回营地；该测试沿用原夹具推进引导起始时间，不代表真实等待 5 秒的客户端体验。
- 原有正式流程的断线重连检查通过，返回身份为营地怪物。

水流测试验证的是“原版流体速度 → 位移包 → 归返中断”，没有运行客户端游泳物理，也没有证明某一种闭环陷阱能够无限维持位移。实体测试验证收到重复交互包后的结果，客户端长按时的发包与画面仍需人工确认。

临时测试代码已撤回。本机证据保留在 `.local/return-audit-20261030/`：`diagnostic.patch`、`LobbyRuntimeGameTest.probe.java`、`gametest.log`、`gametest-entity.log`；这些是忽略目录中的本地证据，不随仓库提交。

## 待人工测试

使用隔离测试服和原版客户端，按正式营地入口出场。每项记录角色、地形、主副手、潜行设置、实际操作和中断提示；不要在日常世界制造陷阱。

- [ ] **平地对照：** 僵尸、骷髅、苦力怕各测试一次，拿回响碎片对空气单击，松开右键并停留超过 5 秒，确认回营地。
- [ ] **潜行对照：** 分别使用按住潜行和切换潜行，出场前/出场后进入潜行；在平地保持潜行且不移动归返。单独记录“按键潜行”和“低顶强制蹲姿/趴姿”，不要混为同一种状态。
- [ ] **低顶落点：** 潜行时发起追猎，观察是否进入只能蹲着容纳的落点；松开潜行后尝试站立，再原地归返。记录是否只影响站立，而不影响归返。
- [ ] **普通水流：** 无方向键输入时单击归返，记录位移和中断提示；让水流推到稳定墙角后再次尝试，确认“稳定后可归返”的对照成立。
- [ ] **持续水流/气泡柱陷阱：** 为僵尸、骷髅分别准备无法站稳但不会窒息的封闭测试地形，多次单击归返，记录是否每次都因移动中断。水下保持足够时间，观察是否不受溺水伤害，以及僵尸转化为溺尸后是否仍受困。若找不到能持续移动的地形，不把此项记为已复现无限死锁。
- [ ] **实体右键：** 静止、手持归返碎片，分别对空气、方块、附近随从单击和长按右键。重点记录对随从长按时是否反复出现“攻击／实体交互”中断和重新引导；移开视线或松开右键后是否恢复。主手、副手都测试。
- [ ] **受困后重连：** 不退出本轮，只断开连接后重新加入，确认回营地、出场冷却正常、随身世界物资按既有离场规则只结清一次。

## 后续修复方向（尚未实施）

- 归返碎片的实体右键应与对空气/方块使用一致，避免每次重启引导；左键攻击仍中断。
- 为持续环境位移提供无需命令的脱困入口，例如通过同一归返物触发较长的紧急归返，并明确主动行动、战斗伤害与被动位移如何影响它。仍按正常离场结算物资和冷却，避免依赖重连。
- 对低顶落点单独决定是否要求站立空间；不要仅凭出现蹲姿就强制清除潜行，也不要把它当成已证实的归返根因。
