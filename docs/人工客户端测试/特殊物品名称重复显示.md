# 特殊物品名称重复显示

适用版本：Minecraft Java Edition 26.3；更新日期：2026-11-01；状态：待用户手动测试，未运行真实客户端。

## 问题与修复

切换手持物品时，原版客户端会在快捷栏上方显示物品名称。此前 `PlayerFeedback.tick` 又把怪物玩家手持物品的自定义名称发送到动作栏，每 5 tick 刷新一次，形成上下两行相同文字。现已移除这条重复提示，物品名称、说明和使用功能保持原样。

原版依据：本地 Java 26.3 客户端 `Hud.extractSelectedItemName` 使用物品的 `getHoverName()` 显示名称；`Hud.extractOverlayMessage` 在另一高度显示服务端动作栏消息。两条独立显示路径均已核对源码，画面仍需人工确认。

## 验收步骤

使用更新后的服务端构建和原版客户端，通过大厅选角与追猎正式出场。避免使用管理员伪装代替正式角色。

- [ ] 僵尸出场后，在幼年僵尸蛋、成年僵尸蛋与普通物品之间切换。每次切换仅出现一行当前物品名称；停留后名称按原版行为淡出，不再留有持续刷新的第二行。
- [ ] 将两枚蛋移至其他快捷栏位置再切换，结果相同。浸水转为溺尸后，剩余成年、幼年溺尸蛋也各只显示一行名称。
- [ ] 分别检查归返碎片、骷髅三连射物品、苦力怕引爆器，同样没有重复名称。
- [ ] 打开背包悬停上述物品，原有中文名称和使用说明仍完整显示；刷怪蛋仍能正常召唤并在成功后消耗。
- [ ] 使用归返物品，归返进度和中断反馈仍正常显示；救场阶段的倒计时与营地设施交互提示仍正常显示。
