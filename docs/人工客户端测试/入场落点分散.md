# 入场落点分散

日期：2026-11-03。状态：待人工测试。方案见[入场落点分散](../plan/入场落点分散.md)。使用本次构建，客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端，没有启动真实客户端）：

- 原版散布候选顺序覆盖整个方格且不重复；环带采样落在 128–1000 格内，并按面积均匀分布；方位文案的 8 个方向和取整
- 营地各用途的散布区域：只有恢复准备会落进集结圈，且完全在圈内；怪物只落在怪物营地内；不会落在祭坛平台或追猎目标模型上
- 开局入场的人类落在本轮出生点周围 ±10 格内，站位安全
- 集结区中途加入的人类落在距出生点 128–1000 格处，站位安全；客户端加载完成后动作栏出现「你位于出生点…方约…格」
- 极限模式死亡化身怪物后落在怪物营地内；击杀人类获得复生次数后被召回到祭坛台阶前的空地内

下面的观感由人类手动验证。至少准备三名玩家 A、B、C。

## 开局

- [ ] A、B 一起站进集结区开局：两人落在出生点附近不同的位置（原版散布，相距通常几格到十几格），不再叠在一起；镜头朝向一致（原版出生朝向），没有被掰到奇怪的方向。
- [ ] 多开几轮，每次落点都不同，且没有落进水里、岩浆里或卡在方块中。
- [ ] 管理员在本轮主世界执行 `/gamerule respawn_radius 0` 后的下一次开局不受影响（每轮都是新世界）；营地世界里改 `respawn_radius` 会改变营地散布范围（可选）。

## 中途加入

- [ ] 挑战中 C 站进集结区 4 秒：Boss 栏照常倒计时；如果偶尔多等一会儿，Boss 栏显示「正在寻找远方的落点…」，随后正常加入。
- [ ] C 落在远离出生点的荒野（F3 查看坐标，与出生点相距 128–1000 格），不在海上或河里，脚下踩得稳。
- [ ] 地形加载完成后，动作栏显示约 6 秒「你位于出生点某方约 N 格」，方向和距离与 F3 坐标相符。
- [ ] 屏幕上方的定位栏能看到其他人类所在的方向，可以找过去。
- [ ] 站满 4 秒前走出集结区，取消加入；之后重新站入能正常加入。

## 祭坛复生（极限模式）

- [ ] 怪物 A 站上祭坛 4 秒复生：Boss 栏文字为「复生仪式 · 消耗 1 个复生图腾 · 空装降落在远离出生点的荒野 · 无出生保护」。
- [ ] A 降落在远离出生点的荒野，播放「重获人身」标题和不死图腾动画；动作栏显示方位提示。聊天栏提示「复生完成：已空装恢复人类，降落在远离出生点的荒野，无出生保护。」
- [ ] 两名怪物先后复生，落点不同。

## 营地

- [ ] 一轮结束返回营地时，所有人散落在营地中央附近，不叠在一起，也不会直接落进集结圈（不会自动准备）或怪物营地。
- [ ] 新玩家第一次进服、重新登录时，落在营地中央附近的随机位置，不在告示牌、讲台或灯笼里。
- [ ] 极限模式死亡化身怪物后，落在怪物营地内的随机空地，不站在角色模型、目标模型、宝库或女巫身上。
- [ ] 怪物击杀人类获得复生次数被召回时，落在祭坛南侧台阶前的空地，面朝光柱，不会站上金块自动开始仪式。
- [ ] 服务器重启后恢复上次集结的玩家，落在集结圈内的随机位置，仍处于准备状态。
