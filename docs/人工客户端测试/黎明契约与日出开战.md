# 黎明契约与日出开战

状态：待人工验收。本次仅运行无图形服务端测试，不代表原版客户端画面、音量、字幕遮挡或紧张氛围已经验收。

## 准备

- 使用独立 26.3 演示实例及本次构建的 HardRush JAR，两名原版客户端玩家；不要求客户端模组、资源包或玩家输入命令。
- 从大厅集结区开始全新极限轮次。不要复用日常存档进行测试调时。
- 音效应能通过原版音量设置控制；确认客户端没有关闭主音量。

## 显示与节奏

- [ ] 入场看到绿色顶部状态条“黎明契约 · 日出前暂息纷争 · xx:xx”，进度从首日逐渐缩短；准备世界及等待开局的时长没有吃掉第一天。
- [ ] 入场聊天说明为“黎明契约保护你免受来自其他玩家的伤害，契约持续到明天日出”，日常刷新不会重复刷屏。
- [ ] 剩余现实 03:00 变黄色，文案为“黎明契约即将解除 · 距猎杀开始还有 03:00”，一次轻音。正常 20 TPS／一倍昼夜速度下为距清晨 3600 tick；服务器卡顿时以实际日夜进度为准，不强行提前开战。
- [ ] 剩余现实 01:00 变红，只显示“准备作战”；进度条继续缩短，不重置，不在整整一分钟内逐秒响声。
- [ ] 最后 10 秒每秒一次短音，最后 3 秒音高稍高；同一秒不重复响，也不刷聊天。确认音量和节奏适合实战。
- [ ] 日出瞬间状态条消失，字幕“黎明契约已解除”／“极限追猎开始，祝你好运”，结束短音与聊天提示各一次，实际 PvP 同时开放。
- [ ] 下界／末地玩家的状态条和解除时刻与主世界一致；怪物大厅的本轮怪物也能看到倒计时。
- [ ] 其他阶段的集结、救场、庆祝状态条及技能／返厅行动栏仍可正常显示；保护未结束却进入结算或恢复隔离时不误报开战。

## 伤害与提示

- [ ] 保护期间玩家近战互击不扣血，不留下附带点燃；行动栏短暂显示“黎明契约期间，你不可攻击其他玩家”。连续挥砍不刷屏，不遮盖正在进行的返厅进度或恢复提示。
- [ ] 玩家箭、火焰药箭、三叉戟、烟花和伤害／滞留药水不能伤害其他玩家；药箭不留下火焰和中毒，友好治疗效果仍正常。
- [ ] 玩家 TNT、床／锚和末地水晶因果链爆炸不会伤害、击退其他玩家；发起者断线或变更身份后的遗留攻击也受保护约束。
- [ ] 极限模式先通过自然环境死亡成为怪物：玩家怪物近战、箭、苦力怕爆炸和召唤物攻击均不能伤害其他玩家；人类也不能伤害玩家怪物。
- [ ] 自然怪物、摔落、火焰、岩浆及自身爆炸伤害仍正常；不将普通碰撞／落入玩家放置的岩浆等无可信攻击来源的环境伤害变为无敌。
- [ ] 日出后上述玩家来源攻击恢复原本规则，怪物攻击白名单、真实击杀奖励和归属仍正常。

## 生命周期

- [ ] 首日中途加入只获得当前余量；死亡、复生、跨维度和重连不会重新得到完整首日。
- [ ] 重连显示当前余量；替换连接不造成重复 BossBar。
- [ ] 首夜睡觉跳到次日清晨，状态条随实际日出解除，没有保留一段脱离昼夜的保护。
- [ ] 隔离实例正常停服后重开：首日余量保持；已解除的契约不能通过回拨时间重新获得。
- [ ] 世界轮换后新一轮重新开始一份契约，旧状态条、旧声音及旧攻击提示不遗留。
- [ ] 普通模式同样保护首日，结束用“黎明契约已解除，祝你好运”，不提示不存在的极限追猎。
