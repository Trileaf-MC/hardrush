# P2 第一批人工客户端测试：身份转换与出生保护

日期：2026-10-15。状态：待用户执行。对应 P2-01／P2-02、S01／S02；26.3 原版客户端。自动化结果与功能边界见 [开发记录](../p2-identity-protection.md)。本清单未由 AI 启动客户端或代玩。

## 准备

在独立测试存档启用正式运行时（`-PhardrushP1=true`），使用本批 JAR。模式通过管理命令设为下一轮生效，确认 `hardrush status` 所示当轮模式与规则。至少两名玩家；保留另一名活人用于观察和计时，先做好测试存档备份。按正常 `/hardrush join`、`/hardrush ready` 入场。

本批怪物死者留在隔离大厅；选角色、出场、击杀资格与主动极限复生尚未接入。不要用 P0 管理员形态探针替代正式极限身份验收。

## 普通身份

- [ ] 在本轮主世界设置床，离开保护区后携带物品死亡。物品按原版掉落；死亡画面不能移动、攻击或操作库存。点重生后在有效床附近，物资不凭空返还，末影箱与已获进度保持。
- [ ] 用本轮下界有效重生锚重复；恰好消耗一次充能。移除床／耗尽锚后重生到本轮主世界保护区，不去长期大厅或另一轮。
- [ ] 全员同时停在普通死亡画面：不团灭、不结束该轮；无人重生前挑战计时暂停，第一人重生后恢复。
- [ ] 普通死亡画面退出重进，以及死亡画面时正常停服重启：仍可完成同轮原版重生，不回滚到旧活人库存或丢失当轮进度。

## 极限身份

- [ ] 离开保护区，携带物品死亡。旁人确认原地一份掉落；死者自动进入长期怪物大厅，原版视角／加载正常，不在床／锚处出生、不消耗锚充能。
- [ ] 怪物大厅退出重进、再次输入 join／ready、正常停服后重进：始终保持怪物身份，不能变为人类或恢复死亡背包；历史中的死亡只增加一次，进度和原有人类参与时长保持。
- [ ] 普通／极限轮切换后确认 UUID 的本轮身份隔离正常；不把上轮死亡状态带到新轮。

## 保护与重入

- [ ] 主世界出生点水平 32 格边界内，低处／高空都不能近战、射箭、爆炸伤害、击退或施加负面效果；大厅同样受保护。
- [ ] 分别从区内攻击区外、区外攻击区内：近战、弓箭、范围药水、爆炸、点燃均不能越界伤害。区内发出的箭离区后仍不能造成伤害。
- [ ] 区内放置／破坏、容器、丢弃／拾取物品被阻止，历史书仍能通过专用命令领取和阅读；区外水／岩浆、爆炸、活塞不能改变区内方块。
- [ ] 人类第一次离区成功后，步行、末影珍珠、传送、传送门、乘载具或被击退都不能再次进入／穿过；客户端及时同步，落点没有窒息、坠落或速度残留；不能借返区洗掉区外原有火焰／负面效果。
- [ ] 已离区后退出重进／正常停服重启，仍不能重入。边缘位置恢复时不会卡在保护区内；缺乏安全站位时留大厅并显示具体诊断。
- [ ] 普通死亡重生回保护区后重新获得一次离区权限；床／锚在区外的重生不能绕回保护区。
- [ ] 出生区有多条无需破坏方块即可走出的出口，可停留等待，没有强制离区时限。
- [ ] 在保护区内正常停服、管理员中止或档案隔离，能安全送回长期大厅，不遗留玩家挂在旧轮世界。
