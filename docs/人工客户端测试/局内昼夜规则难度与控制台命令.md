# 人工检查：局内昼夜

日期：2026-11-01。由人类用户在独立开发实例、干净原版 26.3 客户端执行。本次开发没有运行真实客户端。

修复前，正式轮次的服务端昼夜判定（亡灵日晒、床能否入睡、夜间刷怪、月相、袭击巡逻等）一直停在第 0 tick 的清晨，与客户端看到的天空不一致。修复后以本轮共享时钟为准。服务端 GameTest 已覆盖时钟→环境属性，以下只验证客户端可见结果。
