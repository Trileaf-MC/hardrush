# 集结区统一入场

日期：2026-11-02。状态：待人工测试。方案见[集结区统一入场](../plan/集结区统一入场.md)。使用本次构建，在独立测试实例中验证，客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端，没有启动真实客户端）：

- 挑战中站进集结区开始引导，动作栏为「离开集结区取消引导」，玩家不会被传出圈外
- 站不满 4 秒就离开，引导取消，不会加入本轮
- 站满 80 tick 后只提交一次加入请求；请求提交后离开圈，加入照常完成
- 世界准备中站进圈，不会被传出，动作栏说明「本轮世界准备中」；开放后仍在圈内的玩家自动准备并开始倒计时
- 极限死者（怪物）站进圈，不会被传出也不会开始引导，动作栏指向怪物庭院和复生祭坛
- 恢复隔离期间站进圈不会开始引导；已退出或被取消资格的玩家不能借集结区重新参赛
- 中途门讲台、菜单和确认流程已移除，救场可由新玩家站入集结区恢复

下面的画面、声音和手感由人类手动验证。至少准备两名玩家：A 先开局进入本轮，B 留在大厅。

## 挑战中站圈加入

- [ ] B 站进集结区（黄／绿羊毛圈）：顶部出现紫色 Boss 栏「世界已运转 X 天 Y 小时 · 中途加入无出生保护 · 祝你好运」，进度条在约 4 秒内走完；听到原版下界传送门的“呜呜”声，脚下冒紫色传送门粒子；动作栏显示「离开集结区取消引导」。
- [ ] Boss 栏里的天数和小时与本轮世界的时间一致：A 在本轮里按 F3 看到的天数相同；本轮睡觉跳过一晚后，天数照常增加。
- [ ] 引导中途走出圈：Boss 栏立即消失，粒子停止，不会加入；再走进圈重新从 4 秒开始。
- [ ] 站满 4 秒：Boss 栏消失，B 空装出现在本轮主世界远离出生点的荒野（见[入场落点分散](入场落点分散.md)），聊天栏提示已加入本轮。
- [ ] 在圈内跳跃、转头、贴着圈边站，不会意外取消引导；从圈外直线走过圈边缘时，不会被传送，也不会被镜头拉扯。
- [ ] 其他大厅玩家能看到 B 脚下的传送门粒子，但听不到 B 的传送门音效、看不到 B 的 Boss 栏。

## 未开放时进圈

- [ ] 世界准备中、结算展示、通关庆祝、换轮期间走进圈：不会闪一下被传走，镜头朝向不变；动作栏说明当前原因，例如「本轮世界准备中 · 开放后站在圈内自动准备」「本轮结束中 · 换轮后重新开放」。
- [ ] 世界准备中先站在圈里等待：进入等待阶段后自动准备，聊天提示「已准备，离开集结区可取消」，开局倒计时 Boss 栏出现。
- [ ] 极限模式中，死亡后成为怪物的玩家走进圈：不会被传走，不会出现引导 Boss 栏，动作栏为「你已化身怪物 · 去怪物庭院追猎，或到复生祭坛复生」。
- [ ] 主动退出本轮的玩家走进圈：动作栏为「你已退出本轮，下一轮可重新集结」，不会加入。

## 营地与文案

- [ ] 新建营地中原中途门的位置（集结区右侧）没有讲台、告示牌和木框架。
- [ ] 营地状态牌在挑战中显示「挑战中 · 站圈中途加入」，第 4 行为「前方：人类集结区」；集结区告示牌写明「开局前站入即准备」「挑战中站4秒加入」「离开即取消」，文字不超出告示牌。
- [ ] 救场阶段顶部条为「救场 · 祭坛复生／集结区加入」，动作栏提示站入集结区恢复挑战；规则讲台中途参赛一条改为站入集结区 4 秒。

## 管理员旁观

- [ ] 管理员旁观时试图传送到不允许的世界（例如旧轮世界）：被拉回的同时，动作栏显示「管理旁观只能前往大厅与本轮世界」，并听到一次试炼宝库拒绝的音效；连续尝试时音效约每 2 秒最多响一次。
