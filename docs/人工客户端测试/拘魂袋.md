# 拘魂袋

日期：2026-11-02。状态：待人工测试。方案见[拘魂袋](../plan/拘魂袋.md)，规则见[玩家怪物与原版差异 · 拘魂袋](../玩家怪物与原版差异.md#拘魂袋)。使用本次构建，在独立极限模式测试实例中验证，客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端与单元测试，没有启动真实客户端）：

- 升阶、扩容的价格阶梯（30／60／120、20／40／80），买满提示，出场、结束出场、更换角色都不消耗也不退款；没有拘魂袋规则的旧对局不出售、不发放
- 普通拘魂袋收编 3 只后拒绝第 4 只；相同的身体按原版合并为一叠；血量和装备经过袋子保持不变，放出的是新 UUID、不会自然消失的随从
- 收纳袋原版选择项决定放出哪一只；放到方块表面、水面，对着普通空气不放出
- 普通袋拒绝骷髅和牛；直接放进袋里的牛放出后是没有主人的普通生物；物种品阶表与末影龙排除
- 角色蛋孵出的僵尸收回到原来的僵尸蛋，不占名额；别人的随从不能收编
- 手动点击不能放入或取出、拿着袋子不能吸取格子，袋子本身仍可整袋移动
- 随从苦力怕不能把主人和己方随从当作目标，但爆炸判定会波及它们
- 带着收编蛋暂离后，袋子和蛋能写入本轮记录，恢复后重新绑定到新的出场

下面的画面、手感和完整流程由人类手动验证。至少准备两名玩家：A 死亡后成为营地怪物（选僵尸），B 保持人类。

## 外观与说明

- [ ] A 以僵尸出场，快捷栏第 4 格是白色收纳袋「普通拘魂袋」，名称为白色；切到这一格时原版显示名称。悬停说明写明收编、放出、滚轮挑选、普通品阶可收编的物种、可在女巫处升阶，以及不能收编末影龙和别人的随从。
- [ ] 按住右键使用拘魂袋（对空气、对地面）不会像原版收纳袋那样把内容倒出来。
- [ ] B 看到 A 的僵尸模型手里拿着收纳袋，没有异常。

## 收编

- [ ] A 右键一只自然僵尸：僵尸消失，原地出现少量灵魂粒子并播放收纳袋装入音效；袋子满度条增加约 1/3，悬停袋子能看到僵尸蛋图标。
- [ ] 继续收编尸壳、溺尸、僵尸村民，满度条随之变化；第 4 只时动作栏提示「拘魂袋已满（3/3）」，那只生物留在原地。
- [ ] 悬停袋内的蛋，名称为「收编的尸壳」等，描述写明当前生命，以及放出后是随从还是普通生物。
- [ ] 对骷髅、苦力怕、牛使用：动作栏提示需要罕见／稀有拘魂袋，生物不消失。
- [ ] 一只被拴住的生物（在稀有袋时测试牛）被收编，拴绳按原版掉落；骷髅骑着蜘蛛时点骷髅，只收走骷髅，蜘蛛留下。
- [ ] 点 B 的随从（让 B 也成为怪物后测试）提示「这是别人的随从」；保护区里的生物提示不能收编。
- [ ] 一次右键只收编一只，不会因为原版客户端连发两个交互包而重复处理或刷两条提示。

## 放出

- [ ] 在背包里悬停拘魂袋滚动滚轮，原版高亮切换选中的蛋；关闭背包后右键地面，放出的正是选中的那只，满度条减少。
- [ ] 不选时默认放出最近收进的那只。
- [ ] 收编时受伤、拿着武器的尸壳放出后，血量和武器保持不变，并且跟随 A、协助攻击 B。
- [ ] 站在水边对着水面右键，生物放在水里；潜到水下对着前方的水右键，生物出现在身边；对着水底方块右键，放在水底方块上。一次点击只放出一只（尤其是水下点水底时）。
- [ ] 抬头对着天空右键，不放出任何东西；袋子为空时右键地面，提示「拘魂袋是空的」。
- [ ] 放出的随从站着不动、远离玩家后不会自然消失。

## 背包操作

- [ ] 拿起一个普通物品去点拘魂袋，物品放不进去；空手右键拘魂袋，蛋取不出来；拿着拘魂袋右键空格或左键有物品的格子，既不会倒出蛋，也不会把格子里的东西吸进去。所有被拒绝的操作，客户端显示立刻恢复，不闪烁、不残留。
- [ ] 拘魂袋本身可以左键拿起、放到空格，数字键换到快捷栏；不能丢出，不能放进箱子。

## 自己的随从

- [ ] A 用成年僵尸蛋孵出一只僵尸，再拿拘魂袋右键它：僵尸消失，成年僵尸蛋数量 +1，袋子满度条不变。
- [ ] A 的随从僵尸被打时出现原版增援，拿拘魂袋右键增援僵尸，它进入袋子并占名额。
- [ ] 主动归返前把随从收进袋子：场上留下的随从照常清理，袋里的随从不受影响；继续出场后袋里的蛋还在，能正常放出。

## 升阶与扩容

- [ ] 女巫交易界面出现「拘魂袋升阶」（图标为下一品阶颜色的收纳袋）和「拘魂袋扩容」，说明写明本轮内一直有效。升阶依次为 30、60、120 怪物币，扩容依次为 20、40、80。
- [ ] 120 的价格在交易界面占用两个付款栏（64 + 56），能正常购买；买完升阶和扩容各 3 次后显示售罄。
- [ ] 购买后再出场，拘魂袋换成对应颜色和名称：罕见为黄色、稀有为青色、史诗为紫色，名称颜色与原版稀有度一致；满度条按新名额计算，例如 4 只时每只约 1/4。
- [ ] 暂离期间购买升阶，继续出场时袋里原有的蛋还在，袋子按新品阶和名额刷新。
- [ ] 改选骷髅再改回僵尸，升阶不退款也不丢失；A 复生为人类后再次成为怪物，升阶清空。

## 各品阶生物

- [ ] 罕见袋：收编骷髅、蜘蛛、史莱姆后放出，骷髅射击 B，蜘蛛和史莱姆跟随 A（史莱姆落后时传送过来）；大史莱姆被打死后分裂出的小史莱姆也是 A 的随从。幻翼放出后按原版自由飞行，不跟随 A。
- [ ] 稀有袋：带电苦力怕收编再放出后仍带电。随从苦力怕在 B 身边爆炸时，A 和 A 的其他随从也在爆炸范围内会受伤；女巫随从扔出的药水同样会波及 A。猪灵、疣猪兽放出后按原版行动，不跟随 A。收编一只牛、一只村民、一只被驯服的狼再放出：牛和村民保持原样（村民交易不变），狼仍跟随原主人。铁傀儡放出后会攻击 A。
- [ ] 史诗袋：唤魔者随从召出的恼鬼不攻击 A；劫掠兽跟随 A。凋灵、监守者放出后按原版行动：凋灵是否攻击 A、监守者是否追踪 A 的振动，记录实际表现。
- [ ] 对末影龙使用拘魂袋提示无法收编。

## 屠龙庆祝

- [ ] 末影龙被击杀后，A 被集结到龙池旁，拘魂袋和袋中的蛋都还在。A 能收编末影人等末地生物，也能放出袋里的随从；随从跟随 A，并在 A 攻击人类后协攻。
- [ ] 庆祝结束回到大厅时，A 的怪物形态解除，袋子和蛋消失；A 放出的随从以死亡表现清理，没有掉落；放出的普通生物留在末地。
