# 僵尸玩家破门

适用版本：Minecraft Java Edition 26.3。日期：2026-11-01。

自动验证使用无图形 GameTest；本清单需要人类使用原版客户端执行，尚未验收。

2026-11-01：交互已改为持续按住左键。86 项怪物 GameTest（含 6 项破门用例）、155 项平台 JVM 测试与打包通过。破门用例覆盖开始／中止挖掘包、连续挥手包、缺少持续输入、右键失效、本人裂纹、预测序号确认与属性恢复；使用独立测试存储。

## 准备

- 使用困难难度、允许生物破坏的测试对局，从营地选择僵尸并正式出场。
- 在保护区外准备橡木门、铜门、氧化／涂蜡铜门、铁门、木活板门和栅栏门；门必须放置完整并关闭。
- 清空主手（将出生武器移至背包其他格），另一名玩家在旁观察。测试与日常对局存储分开。

## 操作与预期

1. 贴近木门，主手空手对准门并按住左键。本人持续挥手，旁观者看到敲门动作，双方能听见原版敲门声并看到逐步加深的裂纹；约 12 秒后整扇门消失。只看着门或右键不应开始破门。
2. 敲击数秒后松开左键，应立即停止、清除裂纹；重新按住需从零等待约 12 秒，频繁点按不能累计进度。分别对准上、下半部都能敲门；切换所挖半部按原版换目标处理，重新计时。右键不能打开门；本人和旁观者都不得看到可穿过的假开门、取消后的残留裂纹或幽灵门。
3. 铜门及氧化／涂蜡变体同样可破；铁门、木活板门、栅栏门和普通方块不可破。手持斧等工具不能启动破门，也不能普通挖掘。
4. 敲击中转头、走远、换到非空主手、攻击实体、使用归返物品或其他交互，均应中断。人类把门打开、换门或在视线中加方块也会中断。重新开始必须重新等待约 12 秒。
5. 中途断线重连、死亡／归返、切换世界、转化为溺尸、暂停对局后恢复，旧进度均不得继续；门上不能残留裂纹。溺尸可重新空手按住左键破门，骷髅和苦力怕不能破门。
6. 将难度改为普通或关闭生物破坏，不能开始；敲击中修改也立即中断。恢复规则后需重新开始。大厅里的门、原版出生保护范围内的门不能破坏。
7. 两名僵尸同时敲门时，各自积累进度；其中一人离开不应清除另一人的裂纹。门被其中一人破坏后，另一人的动作应停止，重新放门不会被旧动作破坏。
8. 对准门、移开准星、开关背包、切换主手与副手物品、解除怪物形态后，确认普通挖掘／放置限制仍正确，恢复人类后正常挖掘速度未变。高延迟下确认松键、重新按住、换门、临时失焦不导致自动敲完或进度越积越快；木门与铜门均不能提前在本人客户端消失。

记录客户端版本、门种类、所挖半部、按住／松开时点、实际耗时，以及本人和旁观者看到的异常。音效、动画、客户端预测和手感以本清单的人工结果为准。
