# 怪物本人主题皮肤

适用版本：Minecraft Java Edition 26.3；更新日期：2026-11-03；状态：待用户手动测试，未运行真实客户端。

## 改动

此前怪物玩家看自己（第一人称手臂、F5、背包人像）是 Steve。现在按当前形态换成对应的主题玩家皮肤，旁人看到的仍是原版怪物模型：

| 形态 | 本人皮肤 | 手臂模型 |
| --- | --- | --- |
| 僵尸 | 经典僵尸 | 经典（4 像素） |
| 溺尸 | 原版溺尸（含外层海藻） | 经典 |
| 骷髅 | 骷髅，细肢体画在黑底上 | 经典 |
| 流浪者 | 流浪者，外层带破布 | 纤细（3 像素） |
| 苦力怕 | 苦力怕花纹的人形 | 经典 |

皮肤只发给本人，不改变认证资料。换皮肤沿用原有的本地刷新方式：在本人客户端原地重建玩家对象，不涉及服务端死亡、重生或换维度。现在转化时也会刷新，同一 tick 内的多次形态变化只刷新一次。来源见 [THIRD-PARTY.md](../../THIRD-PARTY.md#本人主题皮肤资料)，差异说明见[玩家怪物与原版差异](../玩家怪物与原版差异.md)。

## 验收步骤

使用更新后的服务端构建和两个原版客户端 A、B（无模组、无资源包），通过大厅选角与追猎正式出场，不要用管理员伪装代替。

- [ ] A 分别以僵尸、骷髅、苦力怕出场。第一人称空手时，手臂是对应怪物的皮肤（僵尸绿手、骷髅骨头、苦力怕花纹），不是 Steve。
- [ ] A 按 F5 查看前后视角：身体皮肤与形态一致，手臂宽度正常，没有错位或大块黑色、透明区域。打开背包，人像是同一套皮肤。
- [ ] 同时 B 看 A：仍是完整的原版僵尸／骷髅／苦力怕，看不到 A 的主题皮肤；TAB 栏中 A 的头像是 A 自己的皮肤。
- [ ] 换皮肤的瞬间：快捷栏选中格、手持物品、护甲、血量、经验、药水效果都不变；不会长时间停在“正在加载地形”；坐标不跳动。记录画面闪烁的程度。
- [ ] 僵尸浸水约 5 秒转为溺尸后，A 的皮肤换成溺尸，F5 可见外层海藻；骷髅在粉雪中转为流浪者后，换成流浪者皮肤，手臂变细。转化时如果正在拉弓或打开着背包，皮肤会在松手或关闭后再换，期间不中断操作。
- [ ] 目标在海上时以僵尸身份出击，A 直接以溺尸皮肤出现，出场过程中客户端只刷新一次（不会先闪僵尸再闪溺尸）。
- [ ] A 归返营地、阵亡、退出或本轮结束解除形态后，恢复 A 自己的原皮肤。
- [ ] 断线重连后仍在怪物形态时，重新显示该形态的主题皮肤。
