# 怪物币与女巫商人

日期：2026-10-30。状态：待人工测试。对应 [#11](https://github.com/Trileaf-MC/hardrush/issues/11)。使用本次构建，在独立极限模式测试实例中验证，客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端与单元测试，没有启动真实客户端）：

- 价格阶梯、上限、退款、伤害记账（小数累计、每人 20 点上限、倍率在上限之后计算）、礼包只发一次、击杀与阵亡奖励的来源判定
- 出场冻结、取消、结束、更换角色时订单与装备的迁移；存档 schema 7 往返及旧存档升级
- 伤害按秒批量提交、购买写入 SQLite 后重启仍在
- 宝库奖池的槽位、材质、附魔边界，装备文本编码
- 营地布局：新营地带有两台宝库，旧营地升级时只在空地补建；女巫为只发包的原版模型

下面的画面、手感和完整流程由人类手动验证。至少准备三名玩家：A、B 死亡后成为营地怪物，C 保持人类。旧营地升级请使用旧测试存档的副本。

## 怪物币显示与获取

- [ ] A 死亡进入营地，背包出现 6 个发光的绿色「怪物币」，描述写明总数、用途和本轮结束清空。A 复生后怪物币、已购商品和宝库装备全部清空；再次死亡时重新获得 6 枚。
- [ ] 怪物币不能用 Q／Ctrl+Q 丢出，拖到合成格或副手后会恢复原状，不会掉在地上，也不会被别人捡到。
- [ ] A 出场攻击 C：每次入账时行动栏显示「+N 怪物币（伤害）」，只有 A 听到经验球音效，C 和旁人听不到。C 穿护甲、吃金苹果（黄心）时，入账仍按实际扣掉的生命计算。
- [ ] 同一次出场对 C 造成远超 20 点的伤害（例如 C 反复回血），伤害收益停在 20 左右；返回营地后看到的余额与提示一致。
- [ ] C 在下界、末地时，相同伤害的收益分别约为主世界的 1.5 倍、2 倍；C 本条命在线存活满 10、30 分钟后再分别多 0.25、0.5 倍，总倍率最多 2.5 倍。C 复生或新玩家中途加入后，存活加成从 0 重新计算，离线时间不计。
- [ ] 营地庭院里，倍率高于 ×1 的可追猎人类，模型名牌显示「悬赏 ×1.25」等；倍率变化（换维度、存活跨档）后名牌更新，点击模型仍追猎正确的人。×1 的目标不显示倍率。
- [ ] 随从僵尸、箭、苦力怕爆炸和药水云造成的伤害都记给主人。
- [ ] A 被 C 用剑或箭打死，回营地时提示 +5；A 摔死或掉进岩浆没有这笔奖励。
- [ ] A 击杀 C：不给怪物币，复生次数 +1，A 立即被传回营地，提示前往复生祭坛。管理员在 A 出场时发放复生次数，同样立即传回。
- [ ] 持有复生次数的 A 右键庭院目标、怪物展位、女巫或宝库，都只收到「请先到营地的复生祭坛复生」的提示；营地行动栏持续显示剩余次数和复生提示。A 把复生图腾丢给 B 后，A 可以正常追猎，B 则被提示复生。

## 女巫商人

- [ ] 营地苦力怕展位东侧站着一只不动的女巫，名牌为「女巫商人 · 右键交易」，旁边有标牌。女巫不攻击、不喝药、不能被打伤或推走。
- [ ] 没在展位选角就右键女巫，提示先选择本次要化身的怪物，不打开界面。
- [ ] 选僵尸后打开原版交易界面：能看到成年／幼年僵尸蛋、迅捷、抗火、两种钥匙，付款物显示为「怪物币」。选骷髅看到药箭和钥匙，选苦力怕看到带电出场和再生。
- [ ] 点选交易项后，怪物币自动放进付款格；点击结果格完成购买，商品出现在营地背包，余额减少，女巫发出庆祝声。重复点结果格不会重复扣币。
- [ ] 连续购买成年僵尸蛋：价格依次为 6、12、24，涨价后原价显示删除线；买满 3 枚显示原版售罄标记。
- [ ] 怪物币不够时点击结果格只提示不足，不扣币、不发货。关闭界面后，付款格里的怪物币不会掉在地上，背包数量恢复正确。
- [ ] 买了僵尸蛋后到展位改选骷髅，蛋消失并按实付价退回怪物币，行动栏显示「退款」。
- [ ] 走远或在交易时被转为别的身份，交易界面自动关闭。

## 宝库

- [ ] 营地东侧有普通和不祥两台宝库，标牌说明用法。人类、未选角色或选了苦力怕的玩家靠近时，宝库不亮、不轮播。
- [ ] 选僵尸或骷髅后靠近宝库，只有自己看到宝库点亮并轮播本角色可能抽到的装备；其他玩家看到的宝库不受影响。
- [ ] 手持买来的试炼钥匙右键普通宝库：播放原版插入、开启、弹出动画，物品飞进背包，聊天提示抽到的装备；钥匙消失。不祥钥匙只能开不祥宝库，原版试炼钥匙打不开。
- [ ] 抽到的护甲直接显示穿在营地身体上；同一槽位抽到多件时，穿最新的一件，其余在背包里。
- [ ] 抽到骷髅才能用的弓后改选僵尸，弓留在营地背包，描述写明切回骷髅时才会带出。

## 出场与掉落

- [ ] 买了 2 枚成年蛋的僵尸出场，成年蛋数量为 3（自带 1 + 购买 2）；迅捷／抗火图标出现在出场后的状态栏；归返或死亡后再出场，购买的物品不再出现，价格回到初始价。
- [ ] 骷髅背包里有买来的 4 支缓慢药箭：射出的箭带缓慢效果，每射一支少一支，射完后改用普通箭。
- [ ] 买了带电出场的苦力怕：出场即显示电弧，爆炸威力明显更大，被炸死的生物可能掉头颅；下一次出场恢复普通。
- [ ] 宝库装备穿在身上出场，并且带入的槽位不再随机出生装备；用完一次后不再出现。
- [ ] 让 C 用抢夺 III 的剑多次击杀穿装备的怪物：偶尔掉落护甲或武器（单槽约 11.5%），掉出的是磨损较重的普通物品，C 可以拾取使用；背包里的备用件不掉。怪物摔死或主动归返时一件都不掉。
- [ ] 买了钥匙但没开就出场，钥匙消失并按实付价退回怪物币。
- [ ] 怪物 A 打出伤害后不到 1 秒就断线：重新上线回到营地后，这次伤害的怪物币已入账且只入账一次。
- [ ] 怪物 A 击杀人类的瞬间（例如苦力怕爆炸后几乎同时），A 也被另一名人类打死：服务器不进入故障隔离，A 回到营地且复生次数 +1，不额外获得阵亡奖励。
- [ ] 怪物刚对人类造成伤害，随后人类立即屠龙：胜者正常公布并进入庆祝，没有出现对局失败或卡住。

## 持久化与轮换

- [ ] 购买后正常停服再启动，余额、已购商品和宝库装备保持不变。
- [ ] 换轮后，所有玩家的怪物币、订单和宝库装备清空，下一轮第一次成为怪物时重新获得 6 枚礼包。
- [ ] 使用旧营地存档的副本启动：两台宝库和标牌被补建在原本的空地上，其他建筑不变；如果目标位置已被改建，日志给出提示且不覆盖原方块。
- [ ] 普通模式下营地没有怪物币，女巫提示只在极限挑战中营业。
