# 骷髅之弓三连射

适用版本：Minecraft Java Edition 26.3；更新日期：2026-11-01；状态：待用户手动测试，未运行真实客户端。

## 改动与依据

骷髅不再持有骨头形状的「三连射」技能物品。三连射改由手中的弓承载：潜行拉满弓后松手即发出。弓的技能状态只改写发给本人的背包数据包，服务端上的真实弓保持原样。

原版依据（本地 Java 26.3 源码）：
- `ServerPlayerGameMode.useItem` 会拒绝使用冷却中的物品，因此不用原版冷却遮罩，改用耐久条表示冷却进度。
- `ServerGamePacketListenerImpl.handlePlayerInput` 从输入包同步潜行状态。
- `LivingEntity.updatingUsingItem` 只比较物品类型，因此拉弓过程中更新显示不会打断拉弓。
- `Hud.tick` 只在名字变化时重新弹出物品名，说明文字、光效和耐久的变化不会触发。

自动测试已覆盖：
- 潜行松手、站立松手、冷却中松手三种情况的射箭数量。
- 本人收到的弓的名字、说明、光效和耐久条，以及转化后改名。
- 真实弓与旁人看到的弓保持原样。

画面与手感需要按下列步骤人工确认。

## 验收步骤

使用更新后的服务端构建和原版客户端，通过大厅选角与追猎正式出场为骷髅。另需一名人类玩家在旁观察。

- [ ] 出场后背包里没有骨头。主手的弓显示为「骷髅之弓」，切换到它时只弹出一行名字。悬停说明两行：「潜行时拉满弓松手，触发 3 连射」「技能已就绪」。快捷栏图标和手持的弓都有附魔光，没有耐久条。
- [ ] 站立拉满后松手：只射出 1 箭，弓仍然发光。
- [ ] 潜行拉弓，拉满时听到一声只有自己能听到的「上弦」提示音。松手后立即射出 1 箭，随后约 0.3 秒、0.6 秒各补 1 箭。
- [ ] 先站立拉弓，拉到一半再按潜行，松手后同样触发三连射。
- [ ] 三连射后弓的光效消失，说明第二行变为「冷却中」。耐久条从一点红色开始，约 20 秒内逐格变长并转绿；回满时耐久条消失、光效亮起，并听到一声就绪提示音。整个过程不再弹出物品名。
- [ ] 冷却中潜行拉满松手：射出普通 1 箭，动作栏提示「三连射冷却中 · 剩余 N 秒」。
- [ ] 冷却中照常拉弓、松手和瞄准，拉弓动作不会被耐久条或说明的刷新打断。
- [ ] 三连射途中把手里的弓切走：剩下的箭不再发出，冷却照常计算。
- [ ] 弓放在副手、主手拿其他物品时，副手拉弓同样可以触发三连射。捡起一把世界里的弓或使用宝库弓，同样显示为「骷髅之弓」，并且可以触发三连射。
- [ ] 旁观的人类看到：潜行时骷髅蹲下；三连射的 3 箭都是举着弓射出，最后一箭射出后手臂才放下。旁人看到的弓不会随技能就绪或冷却而闪烁，附魔弓仍按真实附魔发光。
- [ ] 站进粉雪转化为流浪者：转化完成时，弓立即显示为「流浪者之弓」，物品名只弹出一次。冷却进度不受转化影响，三连射照常可用。
- [ ] 把弓丢在地上、放进箱子，或被人类击杀后弓掉落：人类捡到的是普通的「弓」，没有「骷髅之弓」名字、说明或额外光效，耐久按原版规则显示。
- [ ] 归返或下一次出场以人类身份回到大厅后，背包里原有的弓显示为原本的名字和样子。
- [ ] 屠龙庆祝阶段，骷髅仍可以潜行拉满松手触发三连射，弓的就绪与冷却显示正常。
