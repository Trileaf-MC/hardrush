# 屠龙庆祝与提前返回大厅

日期：2026-10-16；时长规则于 2026-10-23 更新。由用户在独立 26.3 实例和原版客户端手动执行；自动服务端夹具不代表视觉或操作验收。保存制品 SHA-256、轮次 UUID、玩家 UUID、模式、服务端日志及截图／视频。不要清空日常数据库或存档来准备测试。

## 准备

使用已开启 P1 的独立实例。准备 A、B 两名末地玩家、C 一名本轮主世界／下界玩家、D 一名未参赛大厅玩家；另在极限模式安排一名已出场怪物进入末地。给参与者装满背包、穿胸甲，并保留可辨认的手持、合成栏和末影箱物资。低血量首龙或预设物品须明确标为夹具。

## 验收

| 操作 | 预期 |
| --- | --- |
| 通过有效攻击完成首龙致死 | 只公布一次结果，挑战时间冻结。A、B 和末地怪物领取临时装备；C 直接回独立大厅，D 留大厅 |
| 检查装备及 16 色烟花 | 自动穿戴不可损坏鞘翅，16 种颜色各 16 发，原背包满也可使用；原物资已经封存。每种烟花有对应彩色爆炸、拖尾和闪烁 |
| 切换快捷栏，在个人背包调整烟花，然后滑翔、用烟花助推、右键地面升空 | 原生客户端正常操作，怪物能以正常玩家身体庆祝。点击箱子时仅放烟花，不打开容器；不能丢弃／拾取、破坏或产生竞技伤害 |
| 消耗部分烟花后重连，另一人继续留在末地 | 回到原庆祝位置，鞘翅和烟花余量保持，不重新发满；计时不重启 |
| B 跳进龙池出口；设置床／重生锚的玩家也复测 | 直接到 `hardrush:lobby`，不回旧主世界、床或锚；临时装备移除，停止滑翔。A 还在末地时不提前换轮 |
| B 返回后重连 | B 保持大厅，无庆祝物资，不再被恢复到末地 |
| 庆祝开始后让新 UUID 上线 | 留在大厅，不补领庆祝装备、不进入旧轮；核验完成后不阻塞全员返回判定 |
| A 最后返回，或剩余末地玩家全部离线 | 在线玩家均在大厅时立即结束庆祝；先封存、保存回放及关闭旧三维度，再创建唯一下一轮 PREPARING |
| 另起一轮，至少一人始终留末地，实际观察默认 90 秒现实时间 | 到期统一回大厅并安全换轮；不可用假时钟作为此项人工通过证据。轮换 IO 耗时与庆祝倒计时分别记录 |
| 在独立测试服将 tick 速率调为 10 TPS，再用新默认规则通关，至少一人留末地；用外部秒表观察 | 仍在约 90 秒现实时间到期后开始撤离，不因低 TPS 变成 180 秒；允许下一服务端 tick 和安全保存造成处理延迟，分别记录到期与换轮完成时间 |
| 庆祝未结束时正常 stop，记录余量后重启并重连 | 正常停服余量保持，原胜者和成绩不变；临时物资余量、已返回标记保持。服务器恢复后无人在线时允许提前轮换 |
| 首龙致死与玩家死亡发生于同一原生伤害批次 | 只结算一次；死亡画面玩家经安全原生重生参与庆祝，不添加竞技复活／生命记录，不恢复旧生命物资 |
| 下一轮准备完成，再加入／就绪 | 新轮 UUID、种子与玩家档案代数更新，空装开始；无鞘翅、烟花或旧轮物资泄漏，原物资封存保留 |
