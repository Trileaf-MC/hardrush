# 2026-11-17 测试：界面挡住动作栏的提示

状态：待测试
覆盖范围：#37 女巫商店购买被拒时看不到原因，以及同一机制覆盖到的所有箱子菜单；#18 人类全部离线后的等待（含服务器重启后）与复生图腾禁止丢弃
人数：3 人——**你**（房主，OP）、**Alice**、**Bob**
预计用时：约 50 分钟，可以和别的测试合并成一局

## 这次改了什么

- 服务端打开的界面（女巫交易界面、各种箱子菜单）开着的时候，动作栏提示不再在界面背后悄悄消失，而是等界面关上后再完整显示约 3 秒。失败音照旧立刻响，聊天栏里不会多出任何消息。
- 女巫商店：购买被拒时立刻播放村民的“嗯哼”拒绝音，交易界面保持打开；关上界面后动作栏显示原因。结果返回前就关掉界面的，也照样有拒绝音和原因。
- 退出确认菜单：确认退出被拒时，菜单会自动关上并显示原因（以前菜单不关，原因被挡住）。

- #18 再次修复：对局进行中只要没有在线的人类，就一定有倒计时在走，不会再无限停着。等待离线人类重连的时间单独配置（`round.reconnectMillis`，默认 180 秒），和“人类全部阵亡”的 60 秒救场分开。服务器重启后，第一个参赛者回来而人类还没回来时，同样开始这 180 秒等待。
- 复生图腾不能再丢弃或转赠，只能自己去祭坛用掉。怪物币照旧可以丢给同伴。

## 开测前（房主）

1. 正常开服，三个人都用原版 26.3 客户端，不装模组和资源包。
2. 规则选极限挑战（女巫商店只在极限挑战开放）。

## 第一段：工坊工具箱（房主一个人，约 5 分钟）

这一段最容易触发，用来确认机制本身。

1. 房主进大厅工坊，把背包塞满杂物。
2. 打开工坊工具箱，点一个会往背包里放东西的按钮（例如拿魔杖）。
3. **重点看**：点下去时立刻听到音符盒低音；箱子界面开着时动作栏没有文字也没关系；关上界面后动作栏出现“背包满了”，能完整看清约 3 秒。
4. 顺带看：交易界面、箱子开着时，你在界面后面能否隐约看到动作栏？记一下你的分辨率和 GUI 缩放，以及看不看得清。

## 第二段：女巫商店被拒（Alice 当怪物，Bob 当人类，约 15 分钟）

1. 开一局，Bob 做人类，Alice 阵亡变怪物，在展位选好角色，攒一点怪物币（开局送的就够买一枚成年僵尸刷怪蛋）。
2. Alice 回营地打开女巫交易界面，选好商品**先别点**。
3. Bob 让这一局结束（例如自杀让人类全灭）。Bob 死的那一刻，Alice 连续点交易结果格。
4. **Alice 重点看**：
   - 被拒时立刻听到村民拒绝音，交易界面还开着，币没少、东西没到。
   - 关上交易界面后，动作栏出现原因（“本轮即将结束”或“女巫：这笔交易现在做不了”之类），能看清约 3 秒。
   - 聊天栏没有多出这条原因。
5. 如果交易界面在这一刻被自动关掉了，也记下来，同时看关掉后动作栏是否有原因。
6. 正常买一次（不在结束时点）：女巫欢呼音、币变少、东西到背包，动作栏不说话——和以前一样。

## 可选：退出确认被拒（任意一人）

不好刻意触发，碰上了再看：按住潜行 + 副手键打开“退出本轮并观战 · 确认”菜单，在本轮结束的瞬间点确认。被拒时菜单应自动关上，响音符盒低音，动作栏显示原因。

## 第三段：人类离线后的等待与复生图腾（三人，约 20 分钟）

接着第二段的极限挑战开新一局：Bob 当人类，房主和 Alice 阵亡变怪物。让 Alice 击杀一次人类拿到复生图腾（人手不够时，房主用管理命令给 Alice 发一个）。

1. **图腾丢不出去**：Alice 在营地选中复生图腾按 Q，再打开背包对着图腾按 Q 和 Ctrl+Q。
   - 重点看：图腾都留在背包里，地上没有掉落物，动作栏提示“复生图腾不能丢弃”。图腾描述里不再有“丢出可送给其他怪物”。
   - 顺带看：怪物币按 Q 仍然能丢出去，房主能捡到。
2. **人类离线**：Bob 直接退出游戏。
   - 重点看：房主和 Alice 屏幕上方出现“人类全部离线 · 等待重连或救场”的阶段条，倒计时从 180 秒开始；TAB 底部是“人类 0（离线 1）· 怪物 2”。
   - Alice 也退出：房主的 TAB 变成“人类 0（离线 1）· 怪物 1（离线 1）”，倒计时不重置。
3. **重连继续**：Bob 在倒计时内重新进服，阶段条消失，对局继续，Bob 还在原来的位置。Alice 也回来。
4. **重启后的等待**：Bob 再次退出，房主随后正常关服（`stop`）再开服。房主和 Alice 先进服，Bob 先不进。
   - 重点看：房主进服后，阶段条出现并从 180 秒重新开始倒计时（不是接着关服前的剩余时间）。
   - Bob 在倒计时内进服：对局继续。
5. **没人回来就换轮**：Bob 再退出一次，这次不回来。等 180 秒走完。
   - 重点看：提示本轮失败（原因是人类全部离线），约 30 秒后开始新一轮，大家回到大厅可以重新集结。
   - 如果嫌 180 秒太长或太短，记下你们的感受，这个时长可以调。
