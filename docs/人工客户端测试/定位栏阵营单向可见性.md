# 定位栏阵营单向可见性

日期：2026-10-23。状态：待用户手动检查。适用于本项目当前 26.3 构建；本次未启动真实客户端或执行代玩。

定位栏按服务端正式身份过滤：人类不能收到怪物玩家的位置，怪物仍可接收人类位置。人类之间、怪物之间维持原版定位行为。怪物大厅身份同样受此规则约束，不依赖玩家当前外观；身份变化会主动刷新已有定位连接。

在独立测试实例使用本次构建，至少准备两个原版客户端，条件允许时增加第三名玩家。保留日常实例与存档。确认所在维度启用了原版定位栏，并在同一维度、原版接收距离内测试；观察者面向目标方向，目标先保持站立、不隐身、不穿戴会隐藏定位的物品。

- [ ] 两名人类互相能看到对方的定位标记；第三名人类的标记也正常。
- [ ] 极限模式中一人死亡转为怪物并出场追猎后，人类的定位栏中不出现该怪物；怪物的定位栏仍能看到人类。
- [ ] 分别使用僵尸、骷髅、苦力怕身份，重复上述单向检查。
- [ ] 分别在近距离、超出已加载区块但不足 332 格、超过 332 格的距离测试，确保没有精确位置、区块位置或远距离方向标记泄露给人类。
- [ ] 两端保持静止，完成身份变化后旧标记能消失；怪物取得资格复生为人类后，其人类标记能重新出现。怪物观察者变回人类后不能继续看到其他怪物的旧标记。
- [ ] 怪物归返大厅、死亡重生、退出重连后，单向规则继续生效；大厅中的怪物即使显示玩家外观，人类也不能通过定位栏看到它。跨维度和回到同一维度时没有残留标记。
- [ ] 三人场景中，怪物观察者仍按原版规则看到另一名怪物；人类观察者看不到这两名怪物，但仍能看到其他人类。
- [ ] 人类潜行、隐身或使用原版隐藏定位的装备时，怪物端遵循原版隐藏规则；本次改动不提供强制反隐身或跨维度追踪。
