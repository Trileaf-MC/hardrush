# 团灭失败提示与通关庆祝

本次修复后的客户端显示待人工验证。以下项目均未进行真实客户端测试；自动测试不代替本清单的视觉与交互验收。

| 场景 | 操作与预期 |
| --- | --- |
| 极限团灭，无复生资格 | 最后一名人类死亡后回大厅。Boss 栏、TAB 标题及结果、大厅阶段标签和大厅菜单均显示“挑战失败”；不出现通关、龙池回厅或提前结束庆祝提示，不发庆祝装备。默认失败展示持续 30 秒，随后安全轮换。 |
| 救场超时 | 怪物持有复生资格，全部人类死亡后先显示救场；60 秒内不复生且无新人加入，到期后上述位置统一显示“挑战失败”，默认展示 30 秒后轮换。 |
| 失败期间重连／正常停服恢复 | 失败展示期间重连，或正常停服后恢复并重连，仍显示“挑战失败”，剩余时间延续，停服时间不扣倒计时。已有旧版 `FAILED + CELEBRATING` 快照也不得显示庆祝提示；不要手工改库构造快照。 |
| 正常屠龙通关 | 正式人类尾刀首龙后仍进入“通关庆祝”；末地玩家获得临时鞘翅、烟花，Boss 栏仍提示龙池回厅和全员返回提前结束，TAB 和大厅标签保持正常庆祝显示。最多 180 秒或在线全员完成回厅后安全轮换。完整交互见[屠龙庆祝与提前返回大厅](屠龙庆祝与提前返回大厅.md)。 |
| 普通模式全员死亡 | 保持原版重生流程，只暂停挑战计时；不出现“挑战失败”或“通关庆祝”，不自动团灭轮换。 |

记录每项通过／失败／未测，并保留出现问题时的截图、轮次 ID 和服务端日志。
