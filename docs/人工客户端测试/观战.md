# 观战

日期：2026-11-03。状态：待人工测试。方案见[观战](../plan/观战.md)。使用本次构建，在独立的极限模式测试实例中验证，客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端，没有启动真实客户端）：

- 主动退出后回到营地，背包里恰好一个望远镜，不再自动进入旁观；原版旁观菜单的传送包对营地身体无效
- 右键望远镜打开头颅箱子，在赛人类是带皮肤的玩家头颅，物品名为玩家名，描述第一行为「已存活 m:ss」
- 点击头颅后附身该玩家，观战身体进入对方所在世界；D 切到下一位，顺序循环
- 被观察者 TAB 底部显示「正在被 1 名玩家观看」；潜行后回到举起望远镜时的位置，恢复冒险模式
- 管理员对已退出者或观战中的玩家执行 `/gamemode spectator` 被拒绝；追加取消资格后望远镜仍在；下一轮收回望远镜
- 营地怪物左键庭院人像，从营地跨世界附身到末地的人类；D、A 在主世界／下界／末地之间切换；旁观菜单选营地里的怪物无效
- 被观察者收到一次望远镜音效；长按空格不满 1 秒不追猎，满 1 秒进入伺机，找到出场点后直接从镜头出场，镜头复位

下面的画面、声音和手感由人类手动验证。至少准备四名玩家：A、B 开局进入本轮；C 开局后死亡成为营地怪物；D 开局后主动退出（按住潜行 + 交换副手确认）。另备一名管理员。

## 失去资格回营地与望远镜

- [ ] D 确认退出后立即回到营地中央附近（落点随机散开，不会和其他人叠在一起），是冒险模式的人形，不能飞行或穿墙。
- [ ] D 的快捷栏里有一个名为「望远镜」的原版望远镜，悬停描述为「右键选择一名玩家，附身观察 / A/D 切换人选 · 潜行退出 / 本轮结束时收回」。不能丢出、不能在背包里拖动，也没有第二个。
- [ ] 管理员用 `/hardrush admin disqualify` 撤下 A 的资格：A 同样回到营地中央附近并拿到望远镜。管理员再对 A 执行 `/gamemode spectator A` 时提示「已退出本轮的玩家请在营地使用望远镜附身观战…」，A 没有变成自由旁观。
- [ ] D 断线重连后仍在营地，仍有一个望远镜。

## 望远镜菜单

- [ ] D 右键望远镜，打开标题为「望远镜 · 选择观察对象」的 6 行箱子。记下望远镜的缩放画面是否一闪而过、或在关闭菜单后残留。
- [ ] 上方是在赛人类的头颅，皮肤正确；中间一行灰色玻璃板；下方是已出场的怪物，分别显示为僵尸头、骷髅头颅、苦力怕头。营地里待命的怪物（C 在营地时）不出现。
- [ ] 悬停人类头颅显示玩家名和「已存活 m:ss」，菜单开着时时长每秒增长；悬停怪物头颅显示玩家名和「化身：僵尸／骷髅／苦力怕」，没有时长。
- [ ] 不能把头颅或玻璃板拿出菜单，不能把自己的物品放进去，Shift 点击和拖动也无效。
- [ ] 没有任何可观察的玩家时，菜单只有一张纸「暂时没有可以观察的玩家」。

## 附身与切换

- [ ] D 点击 B 的头颅：菜单关闭，画面直接切到 B 的第一视角；按 F5 能看 B 的第三人称。顶部 Boss 栏为红色，文字「正在观察 B · A/D 切换人选 · 潜行退出」，进度条随 B 掉血而缩短。
- [ ] 按 D 切到下一位、按 A 切到上一位，切换后画面立刻（1 秒内）进入新目标视角，不会停在空中自由飞行；只有一个可观察的人时动作栏提示「目前只有 B 可以观察」。
- [ ] 让 B 进入下界、再进入末地，D 的画面跟着 B 过去，不会留在原维度或卡在空中。
- [ ] 附身状态下按数字键打开原版旁观菜单，选「传送到玩家」里的在赛人类：直接附身该人；选营地里的人：动作栏提示，画面不动。附身时左键视野里另一名在赛人类，也会改为附身该人。
- [ ] 让 B 死亡：约 3 秒内 Boss 栏变白，显示「B 已无法观察 · 即将切换人选」；这 3 秒内按方向键不能自由飞走；之后自动切到下一位。所有人都不可观察时，回到营地并在动作栏提示「暂时没有可以观察的玩家，已返回营地」。
- [ ] 按潜行：回到举起望远镜时站的位置和朝向，恢复冒险模式，Boss 栏消失。松开潜行后人物不保持下蹲。
- [ ] 观战中按 Q、F、右键都没有反应，不会丢出或使用物品。

## 营地怪物观战与长按追猎

- [ ] C 在营地庭院瞄准 A 的人像，动作栏显示「目标：A · 当前角色：… · 右键追猎 · 左键观察」；D（已退出者）瞄准人像时显示「目标：A · 左键观察」。大厅里未参赛的玩家左键人像，动作栏提示「观战仅向营地怪物和已退出本轮的玩家开放」。
- [ ] C 左键 A 的人像，附身 A；Boss 栏为「正在观察 A · A/D 切换人选 · 长按空格追猎 · 潜行退出」。A/D 只在人类之间切换，看不到出场的怪物。
- [ ] C 短按空格无事发生；按住空格时 Boss 栏变黄，显示「按住空格追猎 A…」，进度条约 1 秒充满。中途松开不会追猎。
- [ ] 按满 1 秒后进入伺机，聊天栏提示「正在追踪 A 的足迹……对此人再次长按空格可取消」，Boss 栏变为「正在观察 A · 伺机追猎中 · …长按空格取消 · …」。找到出场点后，C 直接从 A 的视角切到出场点，面朝 A，不会先回营地。
- [ ] 伺机中按 D 切到 B：Boss 栏提示「长按空格改追此人」；长按 1 秒改追 B 并重新计时。对正在伺机的目标再长按 1 秒则取消伺机。
- [ ] 伺机中按潜行回到庭院，伺机继续，动作栏显示追踪进度；走出怪物营地才会取消。
- [ ] 出场冷却中长按空格，聊天栏提示冷却剩余秒数，不追猎。持有复生图腾时长按空格，提示先去祭坛复生。

## 被观察者

- [ ] 有人开始观察 A 时，A 的动作栏短暂显示「有玩家开始观察你」，并听到一声很轻的望远镜声音；10 秒内反复切入切出最多提醒一次。
- [ ] A 按 TAB，底部显示「正在被 x 名玩家观看」，人数包含营地怪物、退出者和附身 A 的管理员，没人观看时这一行消失。
- [ ] 观战者在 TAB 中按原版旁观者样式显示（灰色斜体）；观战者对 A 不可见、不可碰撞，不会被怪物或生物攻击。

## 阶段与边界

- [ ] 有人观战时进入结算或屠龙庆祝：观战者回到营地或被正常集结到末地庆祝，不会卡在旁观模式。
- [ ] 观战者断线重连后回到营地身体，不会恢复附身；服务器重启后同样如此。
- [ ] 等待加入、倒计时、结算和换轮阶段右键望远镜或左键人像，动作栏提示「挑战或救场进行中才能观战」。
- [ ] 下一轮开始后 D、A 的望远镜被收回，可以正常站入集结区参赛。

没有执行的项目保持未勾选。
