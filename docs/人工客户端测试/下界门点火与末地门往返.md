# 下界门点火与末地门往返

日期：2026-10-21。状态：待用户手动验证。适用于 Minecraft 26.3 的普通与极限轮次。

修复内容：点火生成下界门时，将 HardRush 管理的本轮主世界／下界识别为对应的原版语义维度。仍由原版校验门框、生成门方块并计算传送；末地禁止点亮下界门的原版规则保留。末地门补眼激活与往返也纳入服务端回归。

自动检查已通过：373 项 JUnit（core 166、persistence 94、mc263 113）与新增的 2 项无客户端 GameTest。GameTest 覆盖正式 P1 轮次和原版维度中的双朝向下界门、底边／无支撑侧边点火、不完整门框拒绝、末地禁用下界门，以及末地门最后一眼生成 9 个门方块、本轮末地进入／返回目标。末地门未发现同类激活问题，不增加额外行为修改。

复验命令：`scripts/p0-gradle.sh :core:test :persistence:test :platforms:mc263:test :platforms:mc263:jar :platforms:mc263:runGameTest -x :platforms:mc263:prepareDebugTools --init-script .local/vanilla-deployment-regression.init.gradle '-DhardrushTerrainFilter=hardrush-gametest:portal_activation_game_test*' --console=plain`。其中 `.local` 内的本地 init 脚本仅向 `runGameTest` 加入 `-Dfabric-api.gametest.filter=hardrush-gametest:portal_activation_game_test*`；服务端运行于新建的隔离存档。完整日志位于 `.local/portal-activation-after.log`。
