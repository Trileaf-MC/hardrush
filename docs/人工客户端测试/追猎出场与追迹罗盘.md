# 追猎出场与追迹罗盘人工检查

初版日期：2026-11-01。状态：待用户手动试玩。规则见[玩家怪物与原版差异 · 追猎出场与追迹罗盘](../玩家怪物与原版差异.md#追猎出场与追迹罗盘)，设计见[计划文档](../plan/追猎出场与重新循迹.md)。使用原版 26.3 客户端，至少两名玩家（一人人类、一人怪物），三人更好。本批未启动真实客户端，自动回归结果另行记录。

## 伺机出场

- [ ] 怪物右键庭院目标模型后，动作栏出现「正在追踪 某人 的足迹 · 已等待 N 秒」；人类在地面时通常 1–2 秒内出场。
- [ ] 按住右键对着模型不放，不会出现「开始、取消、开始」来回跳；松开 1 秒后再右键同一模型，提示已取消，且可以立即重新追猎。
- [ ] 等待期间右键另一名人类的模型，提示改追新目标；走出怪物营地范围、到展位换角色、去祭坛复生都会取消等待。等待期间可以正常找女巫购买、开宝库。
- [ ] 人类鞘翅飞行或在深海中游泳时，动作栏显示「不在地面，等待落地」；落地后自动出场。人类一直悬空超过 60 秒时，提示未找到位置并保留出场机会。

## 落点手感

- [ ] 平原：人类站着挖东西时，怪物出现在 8–24 格内，多数情况在人类背后或被遮挡处，落地视角朝向人类；僵尸几秒内能走到人身边。
- [ ] 平原：人类持续疾跑时，怪物出现在人类前进方向的前方，人类迎面跑过来能撞见。
- [ ] 多层建筑 / 村庄房屋：人类在二楼，怪物能从楼梯或门走上来，不会被放在走不进去的屋外。
- [ ] 下界：人类在基岩层下方，怪物从不落在基岩顶上；人类自己站在基岩顶上时，怪物可以出现在基岩顶上。
- [ ] 结构：人类在下界要塞、猪灵堡垒、林地府邸、废弃矿井、沙漠神殿、古城、要塞或试炼密室里时，怪物多数出现在同一结构的走廊或房间里，并且能走到人类身边。
- [ ] 封路：人类挖隧道后用方块封住来路，等待约 5 秒后怪物出现在封墙另一侧最近的位置，出场提示说明是兜底落点。人类搭 6 格以上的柱子时，僵尸落在柱子附近，骷髅则落在 15 格内能看到人类的位置。
- [ ] 音效：僵尸、骷髅在人类 16 格内出场时，人类能听到对应物种的原版环境音；苦力怕出场没有声音。

## 海上追猎（2026-11-02）

- [ ] 人类坐船全速划行时，骷髅、苦力怕追猎：动作栏显示「某人 在海上，正在等待它靠岸」，聊天栏出现一次灰色的「TIPS：现在改用僵尸出击，会化身溺尸从水下突袭」，颜色与玩家聊天明显不同；人类靠岸上岸后自动出场。
- [ ] 人类全速划船时僵尸追猎：动作栏显示「某人 在海上，正在寻找最佳出击时机」，不会出场。
- [ ] 人类停船钓鱼、慢慢漂流或在水里游泳时僵尸追猎：几秒内从人类附近的水下以溺尸出现，没有「僵尸转化为溺尸」的音效和提示，手里拿着三叉戟，人类在船上不容易一眼看见。
- [ ] 溺尸蓄力投掷三叉戟：手中三叉戟不减少，快捷栏显示约 2 秒的冷却遮罩；地上的三叉戟人类捡不起来。
- [ ] 海上出场的溺尸主动归返后再次追猎（目标在陆地）：以普通僵尸出场，没有三叉戟，剩余的蛋是僵尸蛋；购买的迅捷等药效继续生效且剩余时间接着上次。
- [ ] 骷髅转成流浪者后主动归返，再次出场是普通骷髅；闪电苦力怕主动归返后再次出场仍然带电。
- [ ] 僵尸用追迹罗盘循迹到在海上慢速漂流的人类附近：落入水中后不会瞬间变成溺尸，约 5 秒后按浸水正常转化。
- [ ] 怪物坐上运输船后，按潜行能正常下船。

## 追迹罗盘

- [ ] 出场后第 7 格是「追迹罗盘」，悬停说明三行能看懂；不能丢弃、转交或放进容器。
- [ ] 跟丢目标（距离 40 格以上）约 10 秒后罗盘开始发光；人类钻进下界传送门后罗盘立即发光。罗盘不发光时右键，提示目标就在附近。
- [ ] 右键发光的罗盘，动作栏显示「正在循迹 · 还需 N 秒」；期间移动、攻击或受伤会提示「循迹已中断」。
- [ ] 引导完成后出现在目标附近（可跨维度），视角朝向目标；随后快捷栏显示约 15 秒的原版冷却遮罩，罗盘不再发光，冷却结束且条件满足时重新发光。
- [ ] 循迹前后生命、背包、捡到的物品和经验条身价都不变；同维度的僵尸随从会自行跟上。
- [ ] 目标阵亡或离线后右键罗盘，提示罗盘失去方向、建议归返；屠龙庆祝期间右键提示无效。
