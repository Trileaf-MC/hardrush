# 复生祭坛

日期：2026-11-02。状态：待人工测试。方案见[复生祭坛](../plan/复生祭坛.md)。使用本次构建，在**新建营地**的独立极限模式测试实例中验证（旧营地不会补建祭坛），客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端，没有启动真实客户端）：

- 祭坛方块按蓝图建成；非挑战阶段信标上方是遮光玻璃，极限挑战中换成黄色染色玻璃
- 世界准备中站上金块，不开始仪式，动作栏为「祭坛沉寂中 · 极限挑战中死去的玩家会在这里复生」
- 没有复生图腾的营地怪物站上金块，不开始仪式，动作栏提示「尚无复生图腾」，身份不变
- 击杀人类获得复生次数后，怪物被召回到祭坛南侧台阶前，不会自动开始仪式
- 站上金块 40 tick 仪式进行中；走下祭坛立即取消，不消耗次数；再次站上满 4 秒后完成复生，恢复挑战
- 救场中由另一名怪物站上祭坛复生，只消耗一次次数
- 复生写入数据库失败时进入隔离，次数和身份保留
- 祭坛确认菜单、讲台和 `/hardrush revive` 已移除

下面的画面、声音和手感由人类手动验证。至少准备三名玩家：A、B 开局进入本轮，C 留在大厅不参赛。让 A 死亡成为营地怪物，再让 A 出场击杀 B 获得复生次数。

## 祭坛外观与光柱

- [ ] 营地北侧、人类集结区东面有一座石英台阶围成的 5×5 祭坛，中间 3×3 是金块，正中立着信标，四角是錾制石英块和灯笼。怪物大厅北口有一条石砖路直通祭坛。
- [ ] 祭坛南侧台阶左前方有告示牌：「复生祭坛 / 持复生图腾 / 站上金块4秒 / 空装回到世界」，文字不超出告示牌。
- [ ] 等待和倒计时阶段，信标没有光柱（上方是黑色的遮光玻璃）。挑战开始后，祭坛上方出现金色光柱，并听到信标启动的声音。从营地中央、集结区、怪物大厅和庭院都能看到这道光柱。
- [ ] 本轮结算、换轮时光柱熄灭，听到信标关闭的声音；下一轮挑战开始后重新点亮。
- [ ] 任何人右键信标都不会打开信标界面，营地里的玩家也没有获得信标状态效果或“带信标回家”进度。

## 召回与引导

- [ ] A 击杀 B 后，被召回营地，落在祭坛南侧台阶前，面朝光柱；聊天栏提示「…已被召回复生祭坛前，走上祭坛站立 4 秒复生」。此时没有开始仪式。
- [ ] A 背包里复生图腾的描述写明「走上营地北侧复生祭坛，站在金块上 4 秒」；营地动作栏提示走上祭坛站立 4 秒复生。靠近祭坛时，动作栏显示剩余复生次数。

## 复生仪式

- [ ] A 走上台阶、站到金块上：顶部出现黄色 Boss 栏「复生仪式 · 消耗 1 个复生图腾 · 空装回到本轮出生点 · 无出生保护」，进度条在约 4 秒内走完；先听到一声信标选择音，之后每秒一声越来越高的钟声；脚下升起越来越密的不死图腾粒子；动作栏为「复生仪式进行中 · 走下祭坛取消」。
- [ ] 仪式中途走下金块（走到台阶或地面）：Boss 栏立即消失，听到信标关闭声并冒一小团烟，次数不减；再站上去重新从 4 秒开始。
- [ ] 仪式中在金块之间走动、跳跃、转头，不会取消仪式。
- [ ] 站满 4 秒：Boss 栏变为「正在复生…」，随后 A 离开营地；营地里其他人看到祭坛上爆出一团不死图腾粒子，并听到图腾音效。
- [ ] A 出现在本轮主世界自然出生点，地形加载完成后屏幕中央播放原版不死图腾动画和音效，并显示标题「重获人身」、副标题「空装 · 无出生保护」。A 背包为空，复生次数减一。
- [ ] 主世界出生点附近的人类玩家能看到 A 身上的图腾粒子、听到图腾音效。
- [ ] 两名持有图腾的怪物同时站在不同金块上，各自看到自己的 Boss 栏和进度，互不干扰，各消耗自己的一次。
- [ ] 其他玩家看不到 A 的 Boss 栏，但能看到 A 脚下的粒子、听到钟声。

## 不能复生时

- [ ] 没有复生图腾的营地怪物站上金块：没有 Boss 栏和声音，动作栏为「尚无复生图腾 · 击杀在赛人类可获得，也可接住同伴丢来的图腾」。
- [ ] 仪式进行中把最后一个复生图腾丢出：仪式熄灭中断，动作栏改为「尚无复生图腾」；同伴拾取后可以站上祭坛复生。
- [ ] C（大厅里未参赛的玩家）在挑战中站上金块：动作栏为「祭坛只回应持有复生图腾的怪物 · 参赛请到集结区」。
- [ ] 等待、倒计时、结算阶段站上金块：动作栏为「祭坛沉寂中 · 极限挑战中死去的玩家会在这里复生」。
- [ ] 主动退出本轮的玩家站上金块：动作栏为「你已退出本轮，下一轮恢复资格」。
- [ ] 普通模式中站上金块：动作栏为「普通模式死亡后按原版重生，祭坛不开放」。
- [ ] 管理员旁观者飞过或停在金块上，不会收到提示。

## 文案

- [ ] 救场阶段动作栏为「救场剩余 N 秒 · 站上祭坛复生或站入集结区参赛恢复挑战」。
