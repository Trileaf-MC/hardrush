# 怪物形态进度隔离

适用版本：Minecraft Java Edition 26.3。状态：待人工验收，未运行真实客户端。

## 验收步骤

使用原版客户端，在独立测试对局中安排一名人类进入末地；追猎者应尚未完成「结束了？」进度。

- [ ] 追猎者死亡成为怪物，从营地追猎末地的人类。成功出场后不弹出「结束了？」等新进度提示，聊天中没有该怪物获得进度的公告，进度界面中也未完成该进度。
- [ ] 分别使用僵尸、骷髅和苦力怕检查上述行为；僵尸转为溺尸、骷髅转为流浪者后，也不应获得新进度。
- [ ] 化身怪物前已完成的进度、已完成的部分探索条件继续保留；怪物期间的探索不增加条件，也不获得进度奖励。
- [ ] 通过复生祭坛恢复人类后，再次进入末地，正常获得「结束了？」进度和原版提示。
- [ ] 另一名始终为人类的玩家正常获取进度，不受影响。

本次不清理旧版本已误授予的进度；检查时使用尚未完成相应进度的测试玩家或新对局。

## 自动验证范围

2026-11-01：新增两项回归在修复前均复现失败；修复后，启用比赛模式的 `ProgressGameTest` 共 5 项全部通过，平台打包通过。全部使用独立无图形服务端测试存储。

```bash
JAVA_TOOL_OPTIONS='-Dfabric-api.gametest.filter=hardrush-gametest:progress_game_test*' ./gradlew :platforms:mc263:runGameTest -PhardrushCompetition=true --console=plain
./gradlew :platforms:mc263:assemble --console=plain
```

`ProgressGameTest` 覆盖三种基础怪物形态的条件拦截、部分进度与既有进度保留、配方进度拦截、经验奖励、实际服务端末地往返，以及解除形态后的正常授予。服务端测试不代替上述原版客户端提示和进度界面的验收。
