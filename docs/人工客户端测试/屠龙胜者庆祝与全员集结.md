# 屠龙胜者庆祝与全员集结

日期：2026-10-29。庆祝改为围绕最终胜者 1 人进行：
- 全服所有在线玩家都被集结到末地龙池旁。
- 只有胜者获得鞘翅和烟花。
- 庆祝期间是原版生存，死亡后转为旁观。
- 胜者跳入龙池、阵亡或离线时立即结束，最长到默认 90 秒现实时间。

本清单由用户在独立 26.3 实例上用原版客户端手动执行；自动服务端夹具不能代表视觉或操作验收。请保存以下材料：制品 SHA-256、轮次 UUID、玩家 UUID、服务端日志、截图或视频。不要为了准备测试清空日常数据库或存档。

## 准备

使用已开启比赛模式的独立实例，准备以下玩家：
- A：本轮的尾刀胜者，留在末地。
- B：本轮人类参赛者，留在末地。
- C：本轮主世界或下界中的人类参赛者。
- D：未参赛的大厅玩家。
- 极限模式下再加：一名已出场的怪物在下界，一名待出场的怪物留在营地。

给 A、B、C 准备满背包和胸甲，并带上可辨认的物资。低血量首龙或预设物品都要明确标为夹具。

## 验收

| 操作 | 预期 |
| --- | --- |
| A 完成首龙致死 | 只公布一次结果，挑战时间冻结。全服广播胜者、集结规则和三种结束条件 |
| 观察所有人的去向 | A 留在原地。B、C 和已出场怪物带着自己的身体、物资和怪物形态被传到龙池周围一圈安全地表，面朝龙池。D 和营地怪物变成空手的生存身体，同样被传到龙池周围 |
| 检查 A 的装备 | 胸甲槽换成不可损坏的鞘翅，原胸甲进入背包。另得 16 种颜色的烟花，每种 16 发。原有物资全部保留；背包装不下的部分掉在 A 脚下 |
| 检查其他人的装备 | 只有 A 有鞘翅和烟花。B、C 保留原物资；D 和营地怪物的背包为空 |
| A 滑翔、用烟花助推、右键地面放烟花 | 原版客户端可以正常操作 |
| 其他人互相攻击、攻击 A、挖方块、放方块、开箱子、丢弃与拾取物品 | 均按原版生存规则生效。怪物仍是冒险模式，不能挖或放方块，但可以攻击，三连射和僵尸蛋可用。怪物的归返物品无效，并提示原因 |
| 庆祝期间观察进度和战绩 | 不弹出原版进度。TAB、历史和榜单中的死亡、击杀、复生和进度都不变化 |
| B 跳进龙池；带床或重生锚绑定的玩家也复测一次 | 什么都不发生：不去主世界，不回大厅，也不结束庆祝 |
| B 在庆祝中死亡（PvP、虚空、末影人都可以） | 原版掉落物品。约 1 秒后自动变为旁观者，停在死亡位置；掉进虚空的会回到龙池旁。不出现可点击的重生按钮，生命和复生次数不变 |
| 旁观中的 B 尝试传送到其他世界的玩家 | 被拒绝，只能留在末地观看 |
| B 断线后重连 | 回到末地，仍是旁观者 |
| 一个从未登录过的新 UUID 在庆祝中上线 | 以空手生存身体出现在龙池旁 |
| C 断线后重连（未在庆祝中死亡） | 以空手生存身体回到龙池旁；原物资不会恢复到这个身体上 |
| A 跳进龙池 | 庆祝立即结束。全员回到独立大厅，旁观者恢复成大厅身体；先封存、保存回放并关闭旧的三个维度，再创建唯一的下一轮 PREPARING |
| 另起一轮，A 在庆祝中阵亡 | 立即结束并换轮，A 在大厅原生重生 |
| 另起一轮，A 在庆祝中断线 | 立即结束并换轮；A 重连后在大厅 |
| 另起一轮，A 一直不进龙池，实际等待默认 90 秒现实时间 | 到期后全员回大厅并安全换轮。不能用假时钟作为此项的人工通过证据 |
| 庆祝进行中正常 stop，然后重启并重连 | 不再恢复庆祝，直接换轮。原胜者和成绩不变，所有人在大厅，不带鞘翅、烟花或庆祝期间拾取的物品 |
| 首龙致死和 A 死亡发生在同一次原生伤害中 | 只结算一次。A 在龙池旁原生重生，只带鞘翅和烟花，不增加竞技生命记录 |
| 下一轮准备完成后再加入或就绪 | 新轮 UUID、种子和玩家档案代数都已更新，空装开局；没有鞘翅、烟花或旧轮物资泄漏 |

每项记录为通过、失败或未测试。发现问题时，保留 SQLite 主库与 WAL、`hardrush/profiles` 中的封存文件、旧轮所有权清单、世界文件和录制文件。真实回放器未安装时只记录 disabled。
