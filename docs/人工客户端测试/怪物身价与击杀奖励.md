# 怪物身价与击杀奖励

日期：2026-10-30。状态：待人工测试。对应 [#8](https://github.com/Trileaf-MC/hardrush/issues/8)。使用本次构建，在独立极限模式测试实例中验证，客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端与单元测试，没有启动真实客户端）：

- 身价公式（基础 100、每计入伤害点 +10、悬赏倍率、上限 315）、原版经验等级换算、满 10 级才掉书且附魔等级为身价等级 × 2
- 已缓冲、排队中、写入中和已提交的伤害都只计入一次身价；回到营地后不再有身价
- 规则快照：旧对局不启用；身价参数必须完整、为整数且基础不超过上限
- 经验分 6 波喷出且总量等于身价
- 署名附魔书在真实服务端生成：附魔等级 20、30 时必有附魔，全部来自 `#minecraft:on_random_loot`，名称为物品名而非斜体改名
- `./gradlew build`：JVM 462 项、默认 GameTest 176 项全部通过
- `./gradlew :platforms:mc263:runGameTest -PhardrushCompetition=true -PhardrushLobbyRuntime=true`：出场怪物的经验条等于身价；被人类打伤后摔死时，死亡位置出现经验球，只有身价满 10 级时才掉 1 本署名附魔书

下面的画面、声音和手感由人类手动验证。至少准备两名玩家：A 死亡后成为营地怪物，C 保持人类；验证怪物互杀时再加一名怪物 B。

## 身价经验条

- [ ] A 在营地时经验条为空。出场后经验条立刻显示约 7 级（100 经验），刚出场不播放升级音效。
- [ ] A 攻击 C，经验条随伤害上涨；跨过 10 级时 A 听到原版升级音效，站在旁边的 C 听不到。
- [ ] C 在下界、末地时，相同伤害让经验条涨得更快（与怪物币悬赏倍率一致）。经验条最多到 15 级，之后继续打 C 也不再上涨。
- [ ] A 归返、阵亡或断线后回到营地，经验条清零；下次出场重新从约 7 级开始。
- [ ] 营地规则菜单里有一条附魔之瓶按钮，说明经验条就是身价。

## 击杀喷射经验

- [ ] A 没有伤害 C 就被 C 用剑打死：死亡位置约 1.5 秒内分几波向上喷出许多小经验球，总共大约 7 级的经验。C 拾取后等级上涨，A（以及其他怪物玩家）无法拾取。
- [ ] A 先把 C 打掉约 3 颗心以上（经验条到 10 级），再被 C 打死：喷出约 10 级的经验，并掉落一本附魔书，书名为「从 A 的玩家名 身上找到的书」（不是斜体），通常带 1 个以上较好的附魔，可以在铁砧上附到 C 的装备上。
- [ ] 经验条到 15 级的 A 被打死：喷出的经验让 0 级的 C 升到约 15 级，书的附魔明显更好（相当于附魔台 30 级）。
- [ ] C 用射箭、驯服的狼打死 A，或 C 打伤 A 后 A 立即摔死、掉进岩浆，都会喷经验；A 未受玩家伤害就摔死、主动归返、击杀人类后被召回，都不喷。
- [ ] 怪物 B 打死怪物 A 也会喷经验，附近的人类可以拾取。玩家建造的铁傀儡打死 A，不喷经验。
- [ ] 屠龙庆祝期间，任何玩家打死集结在末地的怪物 A，同样喷出经验。
- [ ] 抢夺 III 的武器不会让书变多；装备死亡掉落仍按原版概率，与书互不影响。
