# 黄昏契约与入夜开战

状态：待人工验收。本次只运行了无图形的服务端测试，原版客户端上的画面、音量、字幕截断和氛围还没有人看过。

契约从开局日出（0 tick）持续到原版的 `minecraft:night` 时刻（13000 tick）。正常 20 TPS、一倍昼夜速度下约为现实 10 分 50 秒。

## 准备

- 使用独立的 26.3 演示实例和本次构建的 HardRush JAR，两名原版客户端玩家；不需要客户端模组、资源包，玩家也不用输入命令。
- 从大厅集结区开始一轮全新的极限模式。不要复用日常存档来调时间。
- 至少一名玩家使用 1920×1080、界面尺寸“自动”的窗口，用来检查字幕会不会被截断。
- 音效受原版音量设置控制；确认客户端没有关闭主音量。

## 入场

- [ ] 加载地形的画面结束后，屏幕中央出现标题“黄昏契约”和副标题“契约保护你免受其他玩家伤害，持续到日落”，停留约 5 秒。公屏没有任何契约消息。
- [ ] 1080p 自动界面尺寸下，副标题完整显示，两端没有被截掉。
- [ ] 标题没有在加载画面期间悄悄播完。
- [ ] 同一轮内死亡后复活、重连、切换维度，都不会再次弹出入场标题。中途加入本轮的玩家看到一次。
- [ ] 准备世界和等待开局的时间没有占用第一天：入场时 TAB 显示接近 10:50。

## 显示与节奏

- [ ] 白天屏幕顶部没有契约状态条。按住 TAB，页脚有一行“黄昏契约 · 日落前暂息纷争 · xx:xx”，每秒更新。
- [ ] 保护期内攻击其他玩家时，行动栏短暂显示“黄昏契约期间，你不可攻击其他玩家 · 剩余 xx:xx”。连续挥砍不刷屏，也不遮盖正在进行的返厅进度或恢复提示。
- [ ] 剩余现实 03:00 时，顶部出现满格的黄色状态条“夜幕将至 · 距猎杀开始还有 03:00”，同时响一次轻音。之后进度条在 3 分钟内逐渐走空。服务器卡顿时以实际的昼夜进度为准，不会提前开战。
- [ ] 剩余 01:00 时状态条变红，只显示“准备作战”。这时天空应该正好开始变暗、太阳下山；整整这一分钟内不会逐秒响声。
- [ ] 最后 10 秒，状态条依次显示“准备作战 · 10”到“准备作战 · 1”，每秒一次短音，最后 3 秒音高稍高。同一秒不重复响。
- [ ] 13000 tick 时状态条消失，出现标题“黄昏契约已解除”和副标题“夜幕降临 · 极限追猎开始”，钟声响一次。公屏没有消息，PvP 同时开放。
- [ ] 解除后 30 秒左右，地表开始自然刷出怪物；玩家召唤的随从僵尸已经不会被太阳点燃。
- [ ] **状态条不再闪烁**：从状态条出现开始连续观察至少 3 分钟（默认每 60 秒做一次完整存档），状态条和文字一直在，不会短暂消失再出现；存档恰好碰上 03:00 或最后 10 秒时，提示音也不丢。
- [ ] 下界、末地里的玩家，状态条和解除时刻与主世界一致；怪物大厅里的本轮怪物也能看到倒计时。
- [ ] 其他阶段的集结、救场、庆祝状态条，以及技能、返厅行动栏都能正常显示；保护还没结束就进入结算或恢复隔离时，不会误报开战。

## 伤害与提示

- [ ] 保护期间玩家近战互击不扣血，也不会留下附带的点燃效果。
- [ ] 玩家射出的箭、火焰药箭、三叉戟、烟花，以及伤害型的投掷或滞留药水，都不能伤害其他玩家；药箭不留下火焰和中毒效果，治疗类的友好效果仍然正常。
- [ ] 玩家引发的 TNT、床、重生锚和末地水晶连锁爆炸，不会伤害或击退其他玩家；发起者断线或改变身份后，遗留的攻击同样受保护约束。
- [ ] 极限模式下，先让一名玩家死于自然环境、成为怪物：玩家怪物的近战、射箭、苦力怕爆炸和召唤物攻击都不能伤害其他玩家；人类也不能伤害玩家怪物。
- [ ] 自然生成的怪物、摔落、火焰、岩浆和自己引起的爆炸，伤害照常；没有可信攻击来源的环境伤害（例如普通碰撞、掉进别的玩家放的岩浆）不会变成无敌。
- [ ] 解除后上述玩家来源的攻击恢复原有规则；怪物攻击白名单、真实击杀奖励和归属仍正常。

## 生命周期

- [ ] 首日中途加入的玩家只获得剩余的保护时间；死亡、复生、跨维度和重连都不会重新得到完整保护时长。
- [ ] 重连后 TAB 和状态条显示当前余量；重复登录、连接被顶替不会造成重复的状态条。
- [ ] 12542 到 13000 tick 之间，原版已经可以睡觉。全员一起睡会跳到次日清晨，契约随之解除，不会在白天保留一段脱离昼夜的保护。主世界里只要有一名非旁观玩家醒着，就无法跳夜。
- [ ] 隔离实例正常停服后重开，首日剩余保护时间保持不变；已解除的契约不能通过回拨时间重新获得。
- [ ] 世界轮换后，新一轮重新开始一份契约，并重新弹一次入场标题；旧的状态条、声音、攻击提示和 TAB 行都不残留。
- [ ] 普通模式同样保护首日，解除副标题为“夜幕降临 · 祝你好运”，不提示不存在的极限追猎。
- [ ] 管理员关闭昼夜循环时，TAB 显示“黄昏契约 · 日落前暂息纷争 · 昼夜暂停”，顶部不显示状态条，也不会出现最后倒计时的提示。

## 自动验证入口

```sh
./gradlew build -PhardrushCompetition=true --console=plain
./gradlew :platforms:mc263:runGameTest -PhardrushDuskPact=true --console=plain
```

第二条命令使用新的隔离无图形 GameTest 存档，不启动真实客户端。自动验证覆盖：阈值和时速换算；状态条只从 03:00 开始显示；最后 10 秒的文案；入场标题等客户端加载完、并且同一轮只弹一次；解除时的标题、钟声，以及不发公屏消息；TAB 行；行动栏剩余时间；周期存档期间的状态提交能被识别出来（不再因此隐藏状态条）；原生伤害与附带效果；攻击来源；保护状态的序列化。这些都不能替代上面的人工项。
