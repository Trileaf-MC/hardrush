# 营地复生图腾与转赠

日期：2026-10-29。状态：待人工测试。使用本次构建，在独立极限模式测试实例中验证，客户端用原版、不装模组。

自动测试已覆盖以下内容（GameTest 跑的是无头服务端）：
- 次数规则与 SQLite 保存
- 背包投影
- Q 键丢出、他人拾取和交还

下面的画面和手感由人类手动验证。准备至少三名玩家 A、B、C，让 A、B 死亡成为营地怪物，C 保持人类身份。

- [ ] A 持有 3 次复生时，营地背包出现 3 个发光的“复生图腾”。数字角标为 3，名称为金色，描述写明“共 3 次”、祭坛复生方式、可转赠，以及 5 分钟作废。
- [ ] 管理员发放次数、怪物击杀人类加次数后，返回营地时数量实时同步。在祭坛复生后图腾消失，再次死亡回营地时显示剩余次数。
- [ ] 营地背包仍保持锁定，图腾不能拖动、换到副手或放进合成格。唯一可做的操作是丢出。
- [ ] 快捷栏选中图腾后按 Q 丢出 1 个：A 收到“已丢出 1 个…剩余 2 次”提示，地上出现发光图腾，描述为“来自 A 的 1 次复生”。按 Ctrl+Q 丢出整组，或在背包界面把光标悬停在图腾格上按 Q / Ctrl+Q，同样按实际数量扣减。
- [ ] B 走近拾取（2 秒拾取延迟后）：B 的次数 +1，B 收到拾取提示，A 收到“B 拾取了你丢出的…”提示。B 背包出现对应数量的图腾，可以到祭坛复生。
- [ ] A 可以捡回自己丢出的图腾。未参赛访客、已退出或已取消资格的玩家、管理旁观者碰到图腾不会拾取。
- [ ] 丢出的图腾 5 分钟无人拾取后消失，次数作废，不会返还给任何人。
- [ ] 怪物出场追猎时，图腾从背包移除，不会带进战场；返回营地后重新出现。C 作为人类在战场时，背包里没有复生图腾，管理员提前发放次数时也一样。
- [ ] 复生图腾不会免死。与原版不死图腾不会合并或混淆；原版不死图腾仍按原版生效。
- [ ] 正常停服或换轮后，地上未被拾取的图腾消失且不能再拾取。背包内的数量随存档余额恢复，轮次结束后全部清空。
- [ ] 救场期间丢出或转赠图腾，不会延长或重置 60 秒期限。有人拾取后在祭坛复生，可以恢复挑战。
