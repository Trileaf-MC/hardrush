## 集结与开局

- [ ] 世界／施工未就绪时入口关闭；准备期间不提前报名，开放后需主动入圈。单个玩家档案仍在核验时只隔离该玩家，其他合格玩家可集结。
- [ ] A 入圈即完成准备并开始 30 秒，B 稍后进入加入剩余倒计时，不重新计时；不需要加入或就绪命令。
- [ ] A 离圈立即取消，B 留圈时倒计时继续；两人都离圈则取消，重新进入从 30 秒开始。
- [ ] 跳跃、转身、查看 TAB、打开背包和读书不取消；约半格的进出迟滞避免边缘抖动，明确越界及时取消。准备成功的短音效、局部粒子、行动栏和“已准备 N 人”顶部条准确，不显示全员分母。
- [ ] 最后一秒离圈仍能取消；归零时只有仍有效准备者入场，访客留厅。一人准备也能正常开局。
- [ ] 快速进出、登记尚未结束就离圈、连续重进不导致迟到准备、重复入场或错误参与记录；界面“正在登记准备”不会被误读为已成功。归零后已受理的个人转换仅短暂锁定本人，其他大厅玩家仍自由移动。
- [ ] 普通断线取消个人准备；最后一人断线取消倒计时，重连落圈外重新集结。
- [ ] 正常停服记录余量后重启：无关访客不能放行原倒计时；两名原准备者中仅一人上线核验并恢复圈内站位即可按原余量续计，其他人不阻塞，提示离圈可取消；另一原准备者在归零前稍晚回来，也需本人核验及圈内恢复，沿用当时剩余时间而不重置。
- [ ] 正常恢复时原集结区域已不安全：受影响者落圈外并收到取消原因；不在错误站位自动准备。脏恢复保持隔离。

## 中途加入与身份

- [ ] 挑战开始后集结区关闭，中途门显示当前轮次、模式、挑战时间和空装自然出生点说明；确认前关闭留厅，确认受理后关闭不撤销或重复执行转换。
- [ ] 极限死者走进集结区或中途门不能恢复人类，收到怪物区或复生祭坛指引。
- [ ] 存活人类重连恢复原位置、背包和身份，不被当作新参赛者空装重置。
- [ ] 普通死亡使用原版重生按钮，床／锚及失效回自然出生点正确；不会转怪物或误触发极限团灭。

## 选角与皮肤模型

- [ ] 右键三种角色展位选择，提示与当前角色一致；本轮偏好保留，更换角色不重置技能或出场冷却。
- [ ] 庭院展示本轮人类原皮肤与名字，皮肤下载失败仍能凭名字选择。不会把本人 Steve 显示覆盖当成所有人的原皮肤。
- [ ] 所有人类目标模型的身体和头部均朝向通道／僵尸、骷髅、苦力怕模型一侧；逐排检查，并在翻页、目标状态刷新及重连后确认朝向保持一致（2026-10-23 朝向修正，待人工验证）。
- [ ] 在线活人可追猎；离线活人标注暂离，不能选择也不显示为已死亡。大厅访客与怪物不列为目标。
- [ ] 玩家死亡、复生、上线和离线后，状态及时更新，其他模型不被重排到原展台导致误点。
- [ ] 超过首屏展示容量时可通过翻页牌查看所有模型；本人翻页不改变其他人的陈列，刷新途中点击不会选到替换后的目标。
- [ ] 模型与提示不泄露装备、血量、背包、坐标、方向或距离；不可取得展示装备。

## 右键直接追猎

- [ ] 冷却结束后，右键 A 模型直接搜索并在 A 附近出场；全程无维度选择、投票、15 秒结算等待或第二道出场门。
- [ ] 分别对位于主世界、下界和末地的人类右键追猎，自动路由到目标所属的本轮维度，不进入旧轮或基础世界。
- [ ] C 选 A、D 选 B 可独立出场；多人选同一人也正常，不出现投票胜者替换或人数配额。
- [ ] 冷却中右键只提示余量；归零后不会自动传走，需再次主动右键。
- [ ] 快速右键同一模型或连续点击不同人，只产生一次有效出场。搜索期间反馈准确，成功与失败音效可分辨。
- [ ] 搜索期间目标换维度或移动：按同一生命的当前位置重新校验，搜索不无限重启；目标死亡、复生或离线时留厅，不换成其他人。
- [ ] 安全点保持距目标水平 24～40 格、距所有同维度在赛人类至少 16 格，接战距离比旧版缩短；山地、洞穴、水边、下界和末地均按实际玩家身体检查碰撞、岩浆与脚下支撑，不造战术平台。
- [ ] 安全搜索失败后留厅、保留出场机会，3 秒后可重试；期间换目标也不能绕过等待。真实世界、档案或存储故障有明确隔离提示。
- [ ] 出场后目标换维度，怪物不会自动跟随传送；可通过原版传送门行动，也能攻击其他合法人类并按实际击杀获得资格。

## 资格 复生与救场

- [ ] 怪物或其召唤物击杀合法人类后，每名受害者 +1 次复生，不会自动复生；没有选择该被害者为目标时，也按实际归属发放。
- [ ] 有资格者冷却中即可在祭坛确认空装复生，说明自然出生点无保护、进度保留和旧掉落不找回；重复点击不重复消费。
- [ ] 资格或阶段改变、出生点不安全、提交尚未结束时均有正确反馈，不伪装复生成功。
- [ ] 所有人类只是离线时暂停挑战计时，保留暂离模型，不开始救场或团灭。
- [ ] 无人类但有资格时显示 60 秒救场与祭坛指引；新玩家可从中途门加入，有资格者可复生，两者均能恢复挑战。
- [ ] 无人类也无资格，或救场到期无人类时团灭；苦力怕击杀最后一人并自爆后先发资格、回厅，再判断救场。
- [ ] 主人在大厅或离线时召唤物仍可按规则发资格；救场余量正常停服后保持，到期前受理复生按既有顺序完成。
