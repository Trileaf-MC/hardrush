# 追猎 Boss 血条

日期：2026-10-30。状态：待人工测试。对应 [#9](https://github.com/Trileaf-MC/hardrush/issues/9)。请在独立的极限模式测试实例中使用本次构建，客户端用原版、不装模组。

自动测试已覆盖以下内容（无头服务端与单元测试，没有启动真实客户端）：

- 出现、消失距离及中间的缓冲区，3 秒保留，潜行与隐身系数，只有追猎自己的怪物会因靠近触发，受伤触发（包括非追猎者、不包括随从），最多 3 条并按距离排序，天空变暗的开关和距离，配置解析与非法值回退
- 怪物侧四种目标状态及文案，击毙提示只出现一次
- 正式个人追猎整链：从 24～40 格外出场时不提醒目标；怪物立即看到目标血条；贴近到 3 格时只有被追猎的人类出现血条，旁边的另一名人类不出现；怪物打伤另一名人类时，该人类出现血条；怪物被召回营地后血条全部移除；苦力怕自爆后自身立即死亡，存活的非目标受害者仍看到血条已清空的追猎血条，保留期结束后移除

下面的画面、手感和完整流程需要人工验证。至少准备三名玩家：A 死亡后成为怪物，B、C 保持人类。

## 怪物侧

- [ ] A 在营地右键 B 的模型出场后，屏幕上方立即出现 `追猎目标 · B`，红色、分 10 格，每格对应一颗心。B 受伤或回血时，血条随之变化，动画平滑。
- [ ] A 转而攻击 C，血条仍然显示 B。
- [ ] B 退出游戏：血条变白，标题为 `目标离线`，进度停在离线前的血量；B 重新上线后恢复为红色并显示实时血量。
- [ ] B 进入下界：标题变为 `目标已不在当前维度`，没有透露 B 去了哪个维度；B 回到 A 所在的维度后恢复正常。
- [ ] B 被打死或摔死：血条清空，标题为 `目标已被击毙`，约 3 秒后消失；本次出场内不再出现。
- [ ] A 归返、阵亡或断线后回到营地，血条消失；下次出场改选 C 后显示 C。

## 人类侧

- [ ] A 刚出场时 B 看不到血条。A 走到距 B 约 5 格时，B 屏幕上方出现 `来自 A 的追猎`，红色、分 10 格，不显示僵尸、骷髅等物种。
- [ ] A 后退到 5～8 格之间时血条保持；退到 8 格以外约 3 秒后消失。在边界附近来回走动时血条不频繁闪烁。
- [ ] A 潜行接近时，要到约 4 格才出现。旁人看到的怪物模型不会做下蹲动作。
- [ ] 隔着墙或在洞穴里时，靠近同样会出现血条。
- [ ] A 追猎 B 时从 C 身边经过，C 不出现血条；A 打 C 一下，C 立刻出现 `来自 A 的追猎`，A 远离后约 3 秒消失。A 是骷髅时，在远处射中 C 也能触发。
- [ ] A 以苦力怕形态追猎 B，在 C 身边约 4～5 格处自爆，C 受伤但存活：C 屏幕上方出现血条已清空的 `来自 A 的追猎`，约 3 秒后消失，不会残留；B 离得远，不出现血条。
- [ ] A 召唤的随从僵尸攻击 B 时，B 不会因此出现血条；随从靠近 B 也不出现血条。B 攻击怪物，通过观察血条是否下降，可以分辨哪只是 A。
- [ ] 有两到三名怪物同时追猎 B 时，各自一条血条，近的在上，最多 3 条；对方移动导致远近交换时，顺序随之更新。
- [ ] B 的屏幕上同时有黄昏契约等其他血条时能够正常共存，追猎血条消失后不残留。

## 阶段与配置

- [ ] 屠龙庆祝、结算展示、恢复隔离期间所有追猎血条消失；旁观者和营地中的玩家看不到追猎血条。
- [ ] 默认不会出现天空变暗。用 JVM 参数 `-Dhardrush.hunt.bossBar.darken=true` 启动服务器后，A 距 B 3 格以内时 B 的天空变暗，A 离开后恢复。
- [ ] 用 `-Dhardrush.hunt.bossBar.showDistance=10 -Dhardrush.hunt.bossBar.hideDistance=14` 启动后，出现和消失距离相应变化。如果写成 `hideDistance=3` 这样的非法值，日志中有警告，并按默认 5/8 格生效。
