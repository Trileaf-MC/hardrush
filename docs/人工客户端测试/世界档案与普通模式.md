# 人工检查：世界、档案与普通模式

2026-10-16 更新：人工出生平台与出口已取消，以下旧出生出口预期由 [正式世界自然出生点](正式世界自然出生点.md) 替代；普通重生和档案恢复检查仍适用。

日期：2026-10-14。由人类用户在独立开发实例、干净原版 26.3 客户端执行。本次开发没有运行真实客户端。

首次测试需要全新比赛数据库并明确使用普通模式；`initialMode=normal` 不会改变已有极限轮次。保留原服务器的数据，使用独立测试实例。此清单对应当时的基础功能，不把这些检查当成完整比赛验收。

| 操作 | 预期 | 记录 |
| --- | --- | --- |
| 世界准备中登录，尝试移动、丢物品、点击容器和加入 | 留在大厅，旧轮状态不能参与，准备／档案尚未完成时拒绝加入；界面无卡住或背包不同步 | 实例、构建、轮次 ID、状态文字 |
| 准备完成后执行 `join`、`ready` | 持久化成功后收到回执；首次就绪开始 30 秒，倒计时期间仍在大厅 | 计时视频／操作时间 |
| 唯一就绪玩家执行 `unready` 或下线，再次就绪 | 前一倒计时取消，下一次重新从 30 秒开始 | 状态、剩余秒数 |
| 开局并分别沿已准备的出口走出出生区 | 空装安全进入本轮主世界，出生区与出口可通行，无窒息、跌落或被困；尚不验 保护规则 | 出生区与出口截图 |
| 第二人挑战中首次加入 | 从本轮出生点空装进入；本轮总时间不重新开始，个人时长从加入后累计 | 两人状态与计时 |
| 全部活人下线；随后一人重连 | 无活人时停表；重连核验后回原维度／位置，保留背包、末影箱、效果和进度，恢复计时 | 下线前后状态 |
| 普通死亡，在死亡画面停留，再按重生 | 无其他活人时停表，不团灭；有效床／锚优先，失效时回本轮出生点；末影箱和本轮进度保留 | 死亡／重生位置和计时 |
| 等待、倒计时、挑战分别正常停服重启 | 相同轮次 ID／种子，倒计时与成绩不包含停服时间；先核验再入场 | 停服前后状态 |
| 走原版下界门与末地门，再返回／死亡重生 | 始终进入同轮对应维度；不串到大厅或开发工具世界；原版进度显示正常 | 维度键和截图 |
| 同轮重启前在出生区旁放置箱子和普通建筑 | 重开后保留内容和建筑，不被准备流程清空；损坏核心安全点时明确留大厅等待恢复 | 重开前后截图 |

跨三轮离线的真实客户端检查需要使用自动轮换执行；本批先以自动档案夹具覆盖，不能用修改数据库或手动换维度冒充真实轮换。攻击尾刀与同归于尽的完整人工验收另行执行。

每项填写通过／失败、复现步骤、JAR SHA-256、轮次与玩家 UUID。客户端画面只由用户手动确认；失败时保留数据库、世界清单、档案封存和日志。
