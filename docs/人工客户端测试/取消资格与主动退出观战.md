# 取消资格与主动退出观战

状态：待人工客户端验收。仅使用可丢弃的独立测试存档，准备普通玩家 A、B、C，及 OP 2、OP 3 管理身份。无需客户端模组或资源包。

## 主动退出

- [ ] 三名玩家正式参赛；A 点击聊天消息中的“退出本轮并观战”，出现原版箱子确认菜单，明确提示本轮不可重新加入、物资封存和下轮恢复资格。
- [ ] 点击“取消”或关闭菜单，继续正常游戏，身份、物品、计时、生命序号不变。重新打开后确认退出，收到成功回执，观战身体清空，能飞行／穿墙；同服其他人的表现符合原版旁观者。
- [ ] 退出者使用原版旁观菜单选择在赛玩家，可以从大厅进入当前对局观察及切换视角；无需管理员 TP。不能借旁观菜单进入其他轮次或原始世界。
- [ ] 普通模式、极限人类、大厅怪物、外出怪物分别确认退出。已准备但尚未开赛者退出后不再计入准备人数；最后一人退出时倒计时取消。
- [ ] 退出者不能攻击、取物、破坏、放置、使用比赛容器、追猎、施放技能或复生，不能靠集结区、中途门、祭坛和重连重新参赛。普通玩家仍不能自行执行 `/tp` 或 `/gamemode`。
- [ ] 退出前打开容器／工作台、手持或光标携带物品、骑乘载具和投出末影珍珠，分别验证退出不会掉出／复制物资或被旧珍珠拉回比赛；首次退出物资封存文件存在。
- [ ] 退出前发出的箭、TNT、怪物箭／召唤物不会在退出后继续伤害玩家或首龙。不要把“碰巧未命中”算作通过。

## 管理员处罚与代办退出

- [ ] 普通玩家、OP 2 不能执行 `admin disqualify` 或 `admin withdraw`；OP 2 的既有只读 status／rules／audit 仍可用。
- [ ] OP 3 对在线玩家执行 `/hardrush admin disqualify A 原因`，A 回到安全大厅，随身比赛物资封存，默认冒险模式；本轮不得重入、复生或追猎。没有伪造死亡、击杀奖励、重复掉落或新增生命。
- [ ] 对离线玩家使用 UUID 执行命令；重连后身份仍为取消资格，不能恢复旧位置与旧背包参赛。名称不唯一、未知 UUID、空原因或重复命令均不产生第二次退出。
- [ ] 极限怪物正在引导返回／技能／追猎搜索时取消资格，旧模型、召唤物和异步回调不能让其重新出场。
- [ ] 普通模式玩家停留在死亡界面等待重生时取消资格，能正常回大厅，无卡死、重复重生和生命序号递增。
- [ ] 管理员可对已取消资格者另行 `/gamemode spectator A`，并 `/tp A B` 进入当前对局；资格仍取消。`/gamemode adventure A` 只结束旁观，不恢复资格。
- [ ] `/hardrush admin withdraw A 原因` 记作非处罚退出并进入观战；对主动退出者追加 disqualify 后，自动旁观结束，首次物资封存不被空背包覆盖。主动退出不能覆盖处罚。
- [ ] `/hardrush admin audit current` 包含动作 WITHDRAW／DISQUALIFY、操作者／程序来源、原因、目标 UUID 和前后身份；处罚轮次标待核验，主动退出不单独使整轮待核验。

## 边界与恢复

- [ ] 取消最后一名有效人类：存在其他可复生怪物时进入救场；否则显示“无有效参赛者”导致本轮失败。救场期间退出不会重置倒计时。
- [ ] 正常停服重启后，本轮退出／取消资格仍生效；主动退出者可继续观战，处罚者默认回厅。完整保存点恢复也保留该身份；保存点早于退出／处罚决定时，应拒绝自动回退并隔离，不得恢复其参赛资格。
- [ ] 对局结束、换轮后，退出者和处罚者都回正常大厅，下一轮可以重新准备和参加；不遗留旧物资、旁观授权或上一轮资格限制。
- [ ] 结束结算后尝试资格命令应拒绝，不改写已发布胜者／成绩。故障恢复隔离中也不能借命令恢复比赛。

数据库提交／审计失败的原子回滚已由隔离自动夹具覆盖；人工测试不得改名、删除或损坏日常数据库来制造故障。没有执行的项目保持未勾选。
