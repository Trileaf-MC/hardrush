# 断线重连与崩溃自动续局人工检查

日期：2026-10-23。状态：待用户手动测试。[实现说明](../p3-auto-resume.md)。使用原版客户端；崩溃项目只在独立可丢弃测试实例和存档副本执行，不操作日常对局。

- [ ] 人类在本轮主世界／下界／末地各退出重进一次。可以短暂进入大厅核验，随后自动回原维度、原位置；背包、末影箱、生命、经验、效果和进度符合退出前状态，无需再次准备。
- [ ] 连续快速退出重进 5 次。确认没有一直卡在准备大厅，不清空物品、不增加生命或扣复生次数；聊天出现恢复本轮身份的提示。
- [ ] 所有活人退出，只留怪物或大厅玩家。TAB 挑战计时暂停，离线资格仍保留，不因无人在线判团灭；一名原活人回来后续计。世界模拟与暂停计时是不同事项。
- [ ] 退出期间由其他玩家正常结束并进入下一轮，再登录。看到上一轮已结束和当前轮号提示；准备后按新轮空档案参赛，旧轮物资不带入。
- [ ] 本轮仍在运行时正常保存停服，然后重启。玩家自动回原局，停服时间不补算，最后正常保存后的进度不被较旧的完整点覆盖。
- [ ] 独立测试局中等日志出现 `Complete checkpoint saved`，记录物品和建筑；再改变物品数量、方块并强制结束该测试服务端。用同一副本重启，确认自动恢复同一轮和保存点状态、聊天说明从完整点恢复、成绩待核验；允许保存点之后的进度回退。
- [ ] 保存点生成时分别拿着鼠标物品、打开随身合成格和工作台。在上述崩溃恢复后核对物品总数，没有丢失或重复；原版跨维度关闭菜单后物品可能被收回背包。
- [ ] 在独立崩溃现场副本中破坏完整点文件后重启。聊天显示具体损坏原因，玩家留大厅，准备区和复生入口不能绕过隔离；修复资料前不得直接解除隔离。
- [ ] 在测试实例中观察默认每 60 秒尝试保存的停顿是否可接受。记录存档大小、保存耗时和硬盘情况；复制超预算或失败时，日志应说明仍使用上一个完整保存点。

每项记录实际服务端 JAR、版本、轮次、玩家名和时间。若同轮重连一直留厅，请附聊天提示与该时段服务器日志，以区分档案错误、跨轮、身份变化和恢复隔离。
