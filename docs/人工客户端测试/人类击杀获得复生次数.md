# 人类击杀获得复生次数

日期：2026-10-23。状态：待人工测试。在独立极限模式测试实例中准备至少三名已参赛的人类 A、B、C；不要使用日常存档测试死亡。自动化检查覆盖规则、死亡批次、SQLite 保存及复生消费，以下画面和游玩操作由人类手动验证。

- [ ] A 以人类身份近战击杀 B，A 收到“复生次数增加 1，剩余 1 次”提示，仍为人类，背包和位置不变；B 按原规则死亡成为怪物。
- [ ] A 再用弓箭击杀 C，提示剩余 2 次；继续击杀另一名人类时逐人加一。已有管理员发放次数时同样在当前余额上加一。
- [ ] B 出场成为玩家怪物后，A 击杀 B 不增加次数；击杀自然怪物、自杀或先推人再由摔落／岩浆致死也不奖励。
- [ ] A 正常停服重启或退出重连，之后死亡回怪物大厅，祭坛显示此前累计的次数。A 死亡时若已无人类且仍持有次数，应进入 60 秒救场。
- [ ] A 在祭坛确认空装复生，每次只减一；再次死亡后可使用剩余次数。重复点击不能多扣，出场冷却不拦截，次数用尽后不能继续复生。
- [ ] 人类使用床、重生锚、TNT 或末地水晶直接造成其他人类死亡时，按实际归属每人加一；同一爆炸击杀多人逐人累计，若攻击者同时死亡，回大厅仍持有奖励，自杀本身不计入。
- [ ] A 射箭后先死亡成为怪物，旧箭随后击杀人类，不增加次数；A 已复生到另一条生命后旧箭命中也不增加。怪物旧箭或召唤物不能为已复生的人类赚取次数。
- [ ] 原怪物击杀规则保持：余额为零时击杀人类获得一次，已有次数时不再增加。轮次结束清空余额，下一轮不能使用旧次数。
- [ ] 普通模式下，人类击杀人类不奖励次数，死亡仍按原版规则重生。营地规则讲台能看到人类击杀累计与怪物击杀奖励的说明。
