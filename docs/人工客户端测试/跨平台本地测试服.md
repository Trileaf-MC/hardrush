# 跨平台本地测试服人工检查

日期：2026-10-31。状态：macOS 已自动验证，Windows 与 WSL 待用户手动验证。

macOS 已验证的项目：首次启动会下载原版服务端，之后 `--reset world`、`--reset all` 和新建实例都没有再下载；`stop` 能正常保存并退出（退出码 0，日志里没有 ERROR）。本批没有在 Windows 或 WSL 上运行过，也没有用客户端连接过。

## Windows（cmd 或 PowerShell）

- [ ] 在仓库根目录运行 `test-server.cmd`：能完成构建并启动，中文提示不乱码，最后出现 `Done (`。
- [ ] 原版 26.3 客户端连接 `localhost` 能进入服务端，HardRush 正常加载。
- [ ] 控制台输入 `stop`：服务端正常保存并退出。
- [ ] 运行 `test-server.cmd --reset all --port 25570 --mode normal`：没有重新下载原版服务端（日志里没有 `Downloading`），端口和模式生效；客户端连接 `localhost:25570` 成功。
- [ ] 运行 `test-server.cmd --instance second`：新实例启动时没有重新下载。
- [ ] 运行 `test-server.cmd --bogus`：提示“未知选项”；运行 `test-server.cmd --help`：能完整显示用法。
- [ ] 在 PowerShell 里运行 `.\test-server.cmd`，行为和 cmd 一致。

## WSL2

- [ ] 仓库放在 WSL 自己的文件系统里（不要放在 `/mnt/c`），WSL 内已装 Java 25，运行 `./test-server.sh` 能完成构建并启动。
- [ ] Windows 上的原版客户端连接 `localhost` 能进入 WSL 里的服务端。
- [ ] `--reset world`、`--reset all` 的表现和 macOS 一致，并且都没有重新下载。
