# 玩家怪物的原版物种关系

初版日期：2026-10-23；机制更新：2026-10-26。适用版本：Minecraft Java Edition 26.3。状态：待用户手动验证。本轮自动结果见[差异文档](../玩家怪物与原版差异.md)，无图形服务端与模拟网络检查不代表客户端体验已验收。背包、转化和随从完整场景见[新版清单](怪物背包转化与原版机制.md)。

准备一个可丢弃的极限模式测试实例，至少两名原版玩家参赛。一人正常死亡后，经大厅选角和追猎出场成为怪物，另一人保留人类身份。原版生物可由管理员在该实例准备；每次场景先清除上一个场景的仇恨，避免把已受挑衅的报复误认为主动攻击。

## 自然选敌与物种差异

- [ ] 僵尸玩家靠近自然僵尸、骷髅和苦力怕，不会因其真实网络实体仍为玩家而被主动追杀；附近普通人类仍会被原版怪物发现、追击和攻击。
- [ ] 骷髅和苦力怕玩家重复上述场景，同样不会成为仅针对人类玩家的主动目标。
- [ ] 自然铁傀儡、玩家建造的铁傀儡均主动追杀僵尸和骷髅玩家，能实际命中并扣血；苦力怕玩家不被其选为攻击目标。
- [ ] 野生狼追近、攻击骷髅玩家，不因僵尸或苦力怕身份主动猎杀玩家。玩家自己驯服的狼不猎杀主人；其他驯服、坐下等限制按原版处理。
- [ ] 村民对僵尸玩家出现原版恐惧和逃离行为；改为骷髅后不残留僵尸恐惧。野生豹猫不再把玩家怪物当作人类逃避。
- [ ] 猪灵不因玩家怪物未穿金甲而主动攻击；末影人不因玩家怪物注视而被激怒；幻翼的人类猎物筛选不选中怪物玩家。凋灵不主动攻击僵尸、骷髅玩家，仍可选择苦力怕玩家。

## 主动攻击与报复

- [ ] 僵尸玩家可近战伤害普通动物、村民、自然怪物和铁傀儡；骷髅的普通箭与连射、苦力怕爆炸同样可伤害这些生物。伤害、附魔、点火、药水效果和击退正常，苦力怕仍不破坏方块或生火。
- [ ] 主动打伤可报复的自然怪物后，对方追打实际玩家身体，玩家能受伤；同类排除和呼叫同伴行为按对应物种的原版规则。没有额外的同阵营无敌或误伤免疫。
- [ ] 击杀原版生物不增加复生资格；世界物资可拾取、整理和转移，僵尸/骷髅可手动换装，苦力怕可携带但不穿甲或武器攻击。出生装备及控制物仅限制外流，不锁死本人库存槽位。
- [ ] 已出场玩家怪物之间、玩家怪物对随从可以造成合法伤害，怪物败退不产生人类击杀奖励。末影龙、龙部位、末地水晶、大厅、隔离、保护区和黎明契约边界继续有效。
- [ ] 随从永不攻击主人；没有主人成功攻击指令时，不攻击怪物玩家/其他随从，即使被其攻击。其他对象按原版选敌，溺尸保留白天限制；主人实际伤害合法目标后可以协攻。主人离场时整队及后代无收益清理。

## 身份与生命周期

- [ ] 人类被自然怪物追击后正常进入怪物身份，原来仅因人类身份建立的追击被清理；铁傀儡、狼按新物种重新选敌。
- [ ] 正常返厅换角、败退、复生为人类后，旧物种的追击或恐惧不残留；合法受击报复仍按当前物种处理。
- [ ] 僵尸转为溺尸、骷髅转为流浪者后，外观、声音、环境行为和自然生物关系一起更新；保留当前生命、装备与物品余量，不因模型重绑回到基础形态。
- [ ] 出场后正常重连、往返本轮三维度，物种识别和原版 AI 反应正确，不出现追打不可见模板、旧身体或错误维度的问题。
- [ ] 仅使用管理员外观诊断伪装，不进入真实怪物角色时，仍按普通人类被原版 AI 识别。
