# 管理员旁观与跨区 TP

状态：待人工测试。自动 GameTest 只验证无图形服务端命令、档案、身份和移动数据包；没有代替原版客户端验收。

## 使用方法

使用隔离实例，准备权限等级 2 及以上的管理员 A、未参赛普通玩家 B、正常在赛玩家 C。目标玩家必须完成档案核验，且本轮从未参赛／未准备，或已主动退出／被取消本轮资格；世界应已准备好。

- 管理员进入旁观：`/gamemode spectator`。
- 管理员让未参赛普通玩家旁观：`/gamemode spectator B`。
- 管理员传送自己：`/tp A C`，或 `/teleport A C`。
- 管理员传送获准旁观的普通玩家：`/tp B C`。
- 返回大厅：对大厅内的玩家执行 `/tp A <大厅玩家>` 或 `/tp B <大厅玩家>`。
- 结束旁观并回到大厅：`/gamemode adventure` 或 `/gamemode adventure B`；之后走正常入口参赛。

旁观授权不会赋予普通玩家 OP 或命令权限。管理员即使仍在大厅冒险模式，也可执行上述 TP／旁观管理命令。普通未参赛玩家若未先获准旁观，被 TP 出大厅后仍会被自动送回。TP 不改变任何人的参赛身份；取消资格与主动退出见[专用清单](取消资格与主动退出观战.md)。

## 人工检查

- [ ] 非 OP 和 OP 1 不能自行切换旁观或使用 TP；权限等级 2 的管理员可以在大厅执行自身及他人的旁观／TP 命令。
- [ ] A、B 旁观时可以飞行、转向、穿墙，在大厅及当前对局的主世界、下界、末地停留，不被拉回或强制改回冒险模式；第三方视角的可见性符合原版旁观者行为。
- [ ] B 获准旁观后仍不能自己使用 `/tp`、`/teleport`、`/gamemode`；可移动不代表获得管理员权限。
- [ ] A 能把 B 在大厅与当前对局之间双向 TP。退出旁观后回到安全大厅落点，恢复冒险模式，再通过正常入口参赛。
- [ ] 旁观者不能攻击、破坏、放置、拿取或转移比赛物品，不能使用集结区、中途入场门、怪物展位或祭坛；不增加存活人类数量、参赛时间、生命序号和复生次数。
- [ ] 已准备玩家必须先离开集结区。已参赛人类、死亡后怪物及重生中的玩家，即使是 OP，也不能通过 `/gamemode spectator <玩家>` 转为此管理旁观身份。
- [ ] 管理员从大厅只能额外使用 `tp`、`teleport`、`gamemode spectator`、`gamemode adventure`；`execute`、生存／创造模式等没有被这次放行。
- [ ] 管理旁观期间不能通过传送进入原始世界或其他轮次世界。退出、重连后回到大厅冒险模式，需要管理员重新授权旁观。
- [ ] 对局结束、换轮或进入故障恢复隔离时，旁观者回到大厅，授权失效；旧世界不会因旁观者滞留而无法释放。
- [ ] 完整保存点进行期间旁观者同样暂停移动，不能用管理命令绕过保存冻结；保存完成后可继续旁观。
