# P0：旁人怪物外观与本人 Steve 实现

记录日期：2026-10-14。用户已明确允许彻底重构：玩家成为怪物后，其他玩家看到所选怪物，本人允许原版玩家模型并优先使用 Steve 外观。本次实现外观层；它不通过外观推断身份，也不代替尚未实现的极限死亡、大厅、技能、复生资格和轮次控制器。P0 阶段仍未通过。

## 实现

- 三种怪物（僵尸、骷髅、苦力怕）仅向其他观察者发送原版实体类型及匹配元数据；复用真实玩家的 ID／UUID，只有一个移动、生命与受伤主体。元数据模板不加入服务端世界，也不向本人生成第二个实体。
- 本人的原版实体元数据、玩家模型、相机、F5、输入和装备保持原版路径。删除旧 `selfview hidden|visible` 命令、本人替身、伪装隐身、私有隐藏队伍、显示模式恢复队列及相机实验。
- 取消空装备和乘坐即解除的限制；保存真实装备，旁人使用原版装备包。旁人可见实体的属性取自真实玩家，限于该原版怪物支持的属性；不使用僵尸等实体的默认速度替代玩家速度。
- 选择按 UUID 保存于当前服务端会话；断线只释放实体 ID 映射，重连、原版死亡重生和换维度重新绑定当前权威玩家。死亡不删除已选择的外观；解除才移除选择。服务器停止清空原型会话状态，正式持久身份仍由后续赛制控制器负责。

源码：[外观层](../platforms/mc263/src/main/java/dev/hardrush/p0/disguise/DisguiseProbe.java)、[本人皮肤](../platforms/mc263/src/main/java/dev/hardrush/p0/disguise/OwnerSkin.java)。原有世界与末地实现保留，旧外观失败证据继续作为历史快照。

## Steve 皮肤

使用 2026-10-14 从 Mojang [MHF_Steve 公开 profile](https://sessionserver.mojang.com/session/minecraft/profile/c06f89064c8a49119c29ea1dbd1aab82?unsigned=false) 读取的固定皮肤资料，纹理 ID 为 `d5c4ee5ce20aed9e33e866c66caa37178606234b3721084bf01d13320fb2eb3f`；该快照是 Steve 外观、slim 手臂模型。发布包只包含公开纹理描述，不包含 Minecraft 图片或客户端代码，运行时不查询玩家账户 API。

本人外观包保留原 UUID、名字、TAB 状态、延迟、游戏模式及聊天会话字段，只替换发给本人的 `textures` 属性。该属性采用原版允许的本人无签名外观路径，不给他人发送，也不改变服务端认证 profile 或真实账号皮肤。解除时重新发送原始 profile。原版客户端根据登录 profile UUID 判断本地皮肤：正版服务器与此处的匹配 UUID 开发会话支持本人无签名皮肤；离线服改写 UUID 的组合另需验证。客户端无法下载纹理或不接受本地皮肤描述时按原版规则回退到默认玩家皮肤；旁人怪物外观及输入不依赖这个下载。

26.3 的 `AbstractClientPlayer` 缓存 `PlayerInfo`，仅更新列表不会即时刷新本人皮肤。因此使用同维度原版 `ClientboundRespawnPacket`（`KEEP_ALL_DATA`）更新客户端玩家对象，随后发送位置／速度、世界加载信号、能力、生命／饥饿、经验、效果和背包。真实服务端玩家对象不替换，不进行死亡或服务端重生，不改变维度或丢弃物品。乘坐、睡眠、使用物品、相机不在本人或打开容器时延迟刷新，避免关闭界面或破坏乘客关系；解除时同样等待安全点。

## 验证记录

运行命令：

```bash
scripts/p0-gradle.sh checkP0 :platforms:mc263:debugToolsJar --console=plain
python3 scripts/debug-tools.py start --side server
scripts/p0-gradle.sh :platforms:mc263:runClientGameTest --console=plain
```

服务端 GameTest 使用真实网络发送入口和 Mixin，连接由 EmbeddedChannel 模拟；覆盖本人原版数据、旁人怪物数据、共享／嵌套包不变、真实装备／生命／经验／效果／速度保留、重复调用、皮肤恢复、死亡重生、重连，以及乘坐时延迟刷新。

游戏测试客户端连接真实隔离服务端，直接读取原版皮肤、相机、准星和装备，切换原版 F5；旁人外观通过独立开发夹具 `HRVisualTarget` 的真实 ServerPlayer 展示并实际攻击。夹具只在 debugTools 内，旧相机实验已删除，不进入发布 JAR。它不是第二个干净原版客户端。

最终验证通过：9 项 JUnit、17 项服务端 GameTest（16 项项目测试＋1 项框架测试）、1 项游戏客户端 GameTest。客户端记录 24 个检查快照：三种角色的本人 Steve／前后 F5／第一人称、旁人怪物、实际近战、移动、跨维度和解除恢复；每种可见怪物的真实玩家生命值从 20 降到 13。实际图形客户端的装备和 7 级经验均保留。最终日志、截图及制品指纹见 [证据清单](evidence/observer-appearance-20261014/manifest.json)。早期测试夹具使用了错误的皮肤缓存 ID；26.3 实际使用纹理 ID 的 UTF-16LE SHA-1，即 `minecraft:skins/a37f02d925dbe17722606a1d624d0b4ddeaf398d`。后续客户端运行确认 Steve 已加载，并发现缺少 `LEVEL_CHUNKS_LOAD_START` 会停在地形加载界面，已补齐原版加载流程。第一次攻击发生在测试演员尚未完成加载保护期时，夹具补齐原版加载确认并等待保护期；从末地存档重连后准备主世界场地的测试也补齐区块加载等待。早期失败不作为通过证据。
