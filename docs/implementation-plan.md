## 如何维护

- `[x] 已完成`：只表示该任务写明的范围已有实现和验证证据，不代表整个阶段通过。
- `[ ] 未完成`：尚未开发，或只有部分实现／验证；已有进展写在条目内。等待前置任务也属于未完成，不等于发现技术故障。
- `[ ] 阻塞`：已有明确失败或无法继续的条件，必须引用下方阻塞编号，并写明解除条件。
- `依赖`列出直接前置任务；各阶段的共同前置条件也适用于阶段内全部任务。没有列出的任务不额外形成依赖，可以在满足共同前置后并行推进。
- `P0-G` 等为阶段验收任务。只有其前置全部完成、退出条件满足，才勾选阶段通过；自动测试通过不能替代原版客户端、录像或负载验收。
- 完成任务时补充日期、源码 commit；工作树未提交时记录源码／制品校验。附操作、结果和日志／截图链接，说明原版客户端、调试客户端或测试夹具的范围。条件变化后重新核对受影响任务，历史证据保留原样。
- 不以任务数量计算完成百分比；任务工作量不同。提交、发布与部署状态另外记录，勾选开发任务不代表已提交或发布。
