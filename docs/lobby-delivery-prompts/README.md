# HardRush 五轮开发启动提示词

每个文件包含一个完整的 text 代码块。按轮次打开文件，复制代码块中的全部文字，粘贴到一个新的 Codex 会话即可；无需携带原讨论历史。复制时保留必读文件、前置门槛、任务、验收和交接要求。

当前只准备提示词，没有启动任何一轮。五轮在同一仓库串行执行；每轮启动后先核验[计划](../lobby-delivery-plan.md)和[交接状态](../lobby-delivery-status.md)，只做指定一轮。

范围只含 Minecraft 26.3，另外两版适配后排。每份提示词都允许执行该轮必要的代码、自动验证和文档更新；不授权真实客户端、浏览器、computer use、日常实例操作或部署。第五轮的候选包和隔离演示准备也不等于发布或人工验收通过。

只需要提示词时复制代码块，不要将本索引或五份提示词一起发给一个会话，以免混淆当前轮次。
