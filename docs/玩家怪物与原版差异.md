# 玩家怪物与原版差异

适用版本：Minecraft Java Edition 26.3。更新日期：2026-10-30。

HardRush 尽量让玩家怪物的外观和战斗符合对应原版物种，但它仍是由玩家操作、参与比赛的身体。本页记录明确的玩法差异和实现边界，供玩家查阅，也作为后续改动时需要同步维护的清单。表中的数值是新对局默认值；已经保存的对局继续使用自己的规则快照。

## 共同规则

| 项目 | 原版生物 | HardRush 玩家怪物 |
| --- | --- | --- |
| 身体与客户端 | 生物自身决定尺寸、AI 和操作 | 仍由真实 Player 身体承载输入、视角和碰撞；旁人收到对应怪物的显示。战斗和物种判断使用原生怪物模型，不要求客户端模组或资源包 |
| 出场 | 受自然生成位置、亮度、群系、数量及难度等规则影响 | 从营地选择僵尸、骷髅、苦力怕，经正式追猎与安全落点流程出场；营地不直接选择溺尸或流浪者 |
| 基础数值 | 取决于物种、难度、装备及生成修饰 | 默认三种基础角色均为 20 生命；僵尸固有护甲 2，骷髅和苦力怕为 0。攻击、装备和效果尽量走原生模型；步行属性按玩家移动路径换算，不直接把生物属性当成玩家移动速度 |
| 移动与恢复 | 由物种的 AI、移动与生存逻辑控制 | 玩家自由操作，但不能疾跑、鞘翅滑翔、进食或依靠饥饿值自然回血；饥饿值固定为 6、饱和度为 0 |
| 日光 | 僵尸、骷髅等亡灵在满足条件时燃烧，并可能消耗头部装备耐久 | 玩家僵尸、骷髅及对应转化形态不因日晒燃烧，头盔也不因日晒磨损；真实火焰和岩浆仍会造成伤害 |
| 物种效果 | 亡灵的治疗/伤害反转、药效免疫、呼吸与冻结行为由物种决定 | 按当前形态的原版模型处理这些规则；转化会更新物种判断，而不是只换外观 |
| 自然生物关系 | 原版目标选择、报复和避让 | 自然生物按当前怪物物种识别玩家。铁傀儡、狼、村民、猪灵等保留相应关系；被实际攻击后的报复也按物种规则处理，没有统一的“同阵营无敌” |
| 玩家怪物的特殊随机形态 | 僵尸生成时可能成为幼年或鸡骑士，并获得生成属性修饰 | 玩家目前从成年基础角色开始；随机幼年和鸡骑士延期。玩家不加入领袖、随机击退抗性或随机追踪范围修饰 |
| 死亡与掉落 | 按生物战利品表、装备掉率和经验规则结算 | 玩家怪物败退不额外生成对应物种的战利品或经验。被玩家击杀时，穿戴中的出生装备与宝库装备按原版生成装备规则判定掉落（见下文）；本人携带的世界物资按离场规则结清，其余绑定物资清除 |

实际 Player 身体与旁人看到的生物模型并非完整实体替换。这也是幼年玩家和鸡骑士必须单独处理视角、碰撞与命中一致性的原因，不能把缩小外观当成功能完成。

## 出生装备与背包

### 玩家出生装备

僵尸和骷髅每次正式出场仅抽取一次装备。概率固定采用 Java 26.3 的困难难度、最高区域难度端点，不随出场位置的实际区域难度变化。苦力怕不抽取可装备的护甲和武器。

| 抽样项目 | HardRush 玩家出生规则 | 与原版的关系 |
| --- | --- | --- |
| 开始生成护甲 | 15% | 固定为原版最高区域难度概率 |
| 后续护甲槽中止 | 每个后续槽 10% | 固定为原版困难难度概率；不是每件护甲独立 15% |
| 护甲材质 | 保留原版材质抽样，包含铜甲 | 沿用 26.3 的材质映射与升级抽样 |
| 僵尸持械 | 5% | 原版困难难度概率；持械后铁剑 1/6、铁矛 1/6、铁铲 4/6 |
| 骷髅主手 | 弓 | 保留原版基础武器 |
| 主手附魔 | 武器存在时 25% | 固定为原版最高区域难度概率 |
| 护甲附魔 | 每件已生成护甲 50% | 固定为原版最高区域难度概率 |
| 附魔基础输入 | 整数 5–30，均匀随机 | 原版生成装备提供器以 5 为起点、17 为难度相关跨度；本模组扩大玩家出生装备的输入范围。这个输入不是最终附魔等级，也不保证每件装备都附魔 |

在营地宝库抽到、适用于本次角色的装备会占用对应槽位，该槽位不再进行上表的自然抽取；空槽位照常抽取。

这些增强只用于玩家出生装备。随从使用实际世界的原版生成、附魔和掉落规则；不会因为主人采用固定最高难度抽样，就一起获得相同的装备增强。

### 背包与物资

- 真实玩家背包是唯一物品库存。模型同步当前主手、副手和护甲，不再按固定槽位每 tick 清空、覆盖或补回物品。
- 所有玩家怪物都可以拾取、整理、交换副手、丢弃世界物资，以及使用允许的储物容器。僵尸、骷髅和转化形态可以手动换装，换装后的属性与旁人显示使用同一份装备。
- 普通食物、药水、末影珍珠等物品使用仍禁用；合成、熔炼等加工、附魔、破坏和放置方块仍禁用。储物容器不包括加工界面；打开箱子不等于获得使用其中普通物品的能力。
- 苦力怕可以搬运物资，但不能穿护甲或获得武器攻击能力。其原版模型不显示手持装备，携带的不死图腾也不触发装备保命，这是物种例外。
- 出生装备、两枚角色蛋、技能物品和归返物品绑定本人及本次出场身份。可以在本人库存内移动，但不能丢弃、转交、放进外部容器，或通过收纳袋藏入可转移物品。道具名称和初始槽位不参与授权判断。
- 引爆器初始在第 1 格；成年/幼年僵尸蛋、三连射和归返物品也有便于发现的初始位置。移动到其他快捷栏或副手后，仍按实际持有的绑定物品识别。
- 归返、死亡、断线、复生或退出前，绑定物资清除，仍由身体携带的世界物资只掉回原战场一次；真正死亡时遵守消失诅咒。已合法存入世界容器的普通物资不算随身库存。
- 例外：被玩家击杀（或最近受到过玩家攻击）时，穿戴在护甲槽和双手上的出生装备、宝库装备按原版 `Mob.dropCustomDeathLoot` 判定，每个槽位基础 8.5%，击杀者武器上的抢夺每级 +1%；带阻止装备掉落效果（如消失诅咒）的不掉，掉出物耐久按原版随机磨损，并解除绑定成为普通物品。背包里的备用件、归返和无玩家参与的环境死亡都不掉落。自己拾取后穿上的世界物品本来就会按上一条全部掉回。
- 屠龙庆祝时，已出场怪物原样被集结到末地龙池旁：形态、背包、绑定物品和技能都保留，仍是冒险模式（不能破坏或放置方块）。三连射在庆祝中照常使用，冷却从本轮已记录的时间点开始，只保存在内存里，不写入本轮记录。归返物品在庆祝中无效，会提示等待统一回大厅。庆祝中死亡按原版掉落一次，随后由服务端在末地转为旁观，不进入怪物营地，也不计入生命、死亡或任何统计。庆祝结束回大厅时，怪物形态解除。

### 营地复生图腾

- 极限模式下，在营地待命的玩家怪物背包里显示“复生图腾”。图腾数量即本轮剩余复生次数，最多显示 99 个，描述写明真实总数。复生次数以本轮存档为准，图腾只是显示，每 tick 按余额补足或删减。出场、复生、退出、离开营地或轮次结束时移除，返回营地后重新出现。
- 复生图腾移除了原版的死亡保护组件，不能免死，也不会被带进战场或人类背包。复生仍在祭坛确认，不能通过使用图腾触发。
- 营地背包仍保持锁定，图腾不能拖动，唯一例外是丢出。在营地丢出图腾（快捷栏 Q / Ctrl+Q，或背包界面悬停图腾格按 Q）会先提交扣减，成功后才生成掉落物；提交失败时图腾放回背包。只有本轮在营地待命的怪物可以拾取，拾取成功提交后获得对应次数，由此可以转赠复生次数。旁观、退出、未参赛访客和人类不能拾取。
- 掉落的图腾保留原版 2 秒拾取延迟，5 分钟无人拾取即消失，次数作废。地上的图腾不写入存档，停服、崩溃或换轮后同样作废。

## 僵尸、溺尸与随从

| 项目 | 当前规则与差异 |
| --- | --- |
| 召唤入口 | 旧的 90 秒冷却召唤已退役。每次出场给予成年、幼年僵尸蛋各 1 枚，每枚独立使用；成功生成才消耗，失败不扣。角色蛋不能修改刷怪笼 |
| 玩家水下转化 | 使用原版水下转化计数器的 600/300 阶段参数，眼睛离开水会取消。转为溺尸时保留生命、库存、物品余量和出场身份；不回血、不重抽装备、不补发用掉的蛋 |
| 剩余蛋转化 | 本人库存和鼠标所持的未用绑定僵尸蛋转换为对应年龄的溺尸蛋，数量与绑定身份保留 |
| 溺尸蛋产物 | 这些蛋产生的溺尸随从必持三叉戟，附魔和正常死亡掉落按实际世界的原版规则；必持有不代表必掉落 |
| 自然转化装备 | 玩家本人和已经存在的僵尸随从转为溺尸时保留装备，不额外赠送三叉戟 |
| 铁矛 | 僵尸、溺尸支持左键刺击和右键举矛，使用原生怪物模型执行射程、速度、附魔和目标检查。骷髅不因此获得原版不支持的矛攻击能力 |
| 玩家溺尸三叉戟 | 持三叉戟右键蓄力，至少 10 tick 后松开投掷，间隔 40 tick；采用溺尸发射参数并保留手中武器。复制出的投射物不可拾取，不启用玩家激流冲刺或忠诚回收入包 |

随从是真实原版僵尸或溺尸，保留日晒、自然装备、拾取、正常死亡掉落、经验、增援和尸系转化。角色蛋明确指定年龄，并禁止额外生成鸡骑士；不会从一枚蛋额外得到骑乘鸡。

HardRush 额外为随从加入以下规则：

- 按狼的同维度寻路与安全传送方式跟随主人；不自动跨维度追随，不强制加载区块，也不传入保护区。
- 永不攻击主人。未经主人成功造成伤害的攻击指令，不攻击怪物玩家或其他随从，即使被其攻击；其他目标仍走原版选敌规则，溺尸保留白天自动选敌的限制。
- 主人成功攻击合法目标后，随从尝试协攻。增援、感染生成的僵尸及尸系转化体继承原主人与原出场战斗来源；增援新生成的鸡坐骑也随队清理，借用的已有普通鸡保持独立。治愈为普通村民后不再作为本次随从。
- 主人和其他合法攻击者可以伤害随从，正常死亡按原版掉落。主人离场时，整队及其后代以死亡表现清理，不生成掉落、经验或击杀收益；已卸载实体下次加载时补做失效检查。

## 骷髅与流浪者

- 骷髅按原版粉雪转化计数器的 140/300 阶段参数转化，离开粉雪取消；按当前物种处理抗冻结。成为流浪者后保留生命、装备和出场身份，跨维度重绑保留当前形态；下一次出场从基础骷髅开始。
- 弓箭优先级为 **副手 → 快捷栏第 1–9 格 → 主背包从左上到右下**。不消耗箭的数量，没有真实箭时使用虚拟普通箭；不再在第 9 格补回箭占位。唯一例外是向女巫购买的药箭：每射一箭消耗一支，射完回到其他箭或虚拟普通箭。
- 普通射击使用原版怪物蓄力门槛；三连射仍为 3 箭、每 0.3 秒 1 箭、默认冷却 20 秒。每一箭都重新读取当前朝向和优先弹药，期间不能叠加普通射击，离场只取消尚未发出的箭。
- 使用实际物种的原版箭生成方法。流浪者的普通箭带缓慢，药箭保留其药效并按原版逻辑添加效果；光灵箭不额外附加缓慢。不将所有箭统一改写成固定的缓慢时长。
- 箭的伤害、散布、附魔及命中副作用走原版投射物路径，角色复制箭不可拾取。既有三连射属于 HardRush 技能，原版骷髅没有这个主动三连射入口。

两种环境转化均保留原版进入、重置和倒计时结束的边界；600/140 与 300 是阶段参数，不代表完成时刻恰好为第 900/440 tick。正常 20 TPS 下分别约 45 秒、22 秒，低 TPS 时按服务端 tick 推进。

## 苦力怕

| 项目 | 当前规则与差异 |
| --- | --- |
| 引爆输入 | 绑定火药名为“引爆器”，按住右键膨胀、松开逐渐消退。用原版持续使用物品协议识别按键，不改变火药外观，不消耗物品，不降低正常步行速度 |
| 膨胀进度 | 按住每 tick +1，松开每 tick -1，最低为 0，默认到 30 爆炸；再次按住从剩余进度继续。玩家输入替代原版 AI 的目标距离/视线判断，不再是点击后无法取消的倒计时 |
| 归返与死亡 | 进度未归零时不能归返；松开并消退到 0 后允许。死亡、断线和失去出场资格终止使用，不留下延迟自爆 |
| 摔落 | 先按原版结算摔伤，再增加 `int(摔落距离 × 1.5)` 的进度，上限为引信长度减 5；原版上限也可能降低原本已经更高的进度。未按住时继续消退，落地本身不直接爆炸 |
| 带电 | 真实雷击按原版伤害/点燃路径处理后，使当前身体带电并显示电弧，爆炸强度乘 2。模型重绑保留带电，离场后新身体不继承。向女巫购买「带电出场」时，下一次出场开始即处于同样的带电状态，不受雷击伤害 |
| 爆炸 | 默认强度 3，带电为 6，保留原生爆炸伤害、距离、遮挡、难度和装备结算；不破坏地形、不生成火。爆炸命中与本人自死归入同一死亡批次 |
| 头颅 | 使用真实带电 Creeper 来源，沿用 26.3 `charged_creeper` 战利品表及单次额度，受原版掉落条件限制；玩家及玩家化身怪物不新增头颅掉落 |
| 药水云 | 身上有现有效果时生成原版参数的云：半径 2.5、每次命中半径减少 0.5、等待 10 tick、持续 300 tick、效果持续时间倍率 0.25，并按原版逐 tick 缩小半径 |
| 云的归属 | 保存原主人及冻结的本轮、生命和出场来源；主人之后死亡或换身份不改写旧云来源，仍受当前保护/旧轮校验。持续药效的延迟死亡沿用既有直接结算规则，不新增持续伤害记功系统 |

原版协议只同步膨胀方向等状态，不能精确传送摔落造成的瞬时进度跳变。服务端按实际进度决定爆炸时机，旁观者动画是否可理解、何时恢复一致，列入人工验收；本页不承诺视觉插值与服务端每一 tick 完全相同。

## 战斗边界与奖励

玩家怪物可以攻击合法的人类、其他已出场怪物玩家、普通原版生物和随从。追猎菜单仍只列合法人类，不能用“可以战斗”推导“可以作为追猎出场目标”。

伤害、击退、点燃、药效、卸骑及附魔副作用共用战斗准入规则。黎明保护、保护区、旁观/隔离、退赛、旧轮来源和比赛冻结继续有效；末影龙、龙部位和末地水晶仍不接受怪物竞技伤害。随从额外遵守主人保护与协攻规则。

屠龙庆祝期间，末地里的资格、阶段和身份过滤全部取消：怪物可以攻击同一末地中任何存活、非旁观的玩家（包括胜者和空手访客），以及普通生物。仍然保留的限制有：只能由原版模型出手、不能伤害自己或自己的模型、不能攻击末影龙和末地水晶。随从照常遵守主人协攻规则。这些战斗不封存战斗来源，也不产生证据、击杀或复生奖励。

击杀怪物玩家或普通生物不会产生人类击杀复生奖励。怪物击杀合法人类按既有来源与资格规则判定，每名受害者 +1 次复生，可与已有余额累计；启用怪物币的对局中，仍在出场的击杀者随即被传回营地，须先复生才能再次追猎；不能根据最近攻击者、距离或主人当前身份给未知/旧轮伤害补记功。已发出的合法投射物与云保留冻结来源；随从则在主人离场时清理。

## 追猎血条

原版普通怪物不显示 Boss 血条；玩家怪物在追猎期间使用原版 Boss 血条（[#9](https://github.com/Trileaf-MC/hardrush/issues/9)），只在挑战和救场阶段显示，结算、庆祝、恢复隔离、营地、出场搜索和旁观时都不显示。

| 项目 | 规则 |
| --- | --- |
| 怪物看到的 | 出场成功后全程显示营地所选目标的血量：`追猎目标 · 名字`，红色、分 10 格。中途攻击别人不切换目标。目标离线时为白色 `目标离线`，血量冻结；不在同一维度时为 `目标已不在当前维度`；目标死亡（含环境死亡）或这条命已结束时清空并显示 `目标已被击毙` 约 3 秒，本次出场不再显示 |
| 人类看到的 | `来自 名字 的追猎`，统一红色、分 10 格，不透露物种。追猎自己的怪物玩家在同一维度距离 ≤5 格时出现，>8 格时开始约 3 秒的保留，之后消失。任何怪物玩家本人（近战、箭、苦力怕爆炸等）伤到人类时，不论距离和目标都立即显示，每次受伤重新保留约 3 秒；随从造成的伤害和随从本身不显示。最多 3 条，近的在上 |
| 察觉修正 | 出现/消失/变暗距离乘以怪物身体的原版可见度 `LivingEntity.getVisibilityPercent`：潜行 ×0.8（默认约 4 格出现），隐身按原版盔甲覆盖率折算。不要求视线，隔墙也会触发 |
| 服务器配置 | JVM 系统属性，启动时读取一次：`hardrush.hunt.bossBar.showDistance`（默认 5）、`hideDistance`（默认 8，不小于出现距离）、`darken`（默认 false，开启后用原版凋灵的天空变暗）、`darkenDistance`（默认 3）。距离须为 0～64 的正数；任何一项非法时整组回退默认值并在日志中警告。不写入规则快照，不影响榜单分组 |

## 怪物币与女巫商人

极限模式的新对局启用怪物币；没有 `coin.*` 规则的已保存对局不启用。数值写在规则快照中，下表为默认值。

| 项目 | 规则 |
| --- | --- |
| 存储与显示 | 余额只在本轮有效，保存在本轮存档；换轮清零，复生为人类时连同已购商品和宝库装备一起清空。营地里显示为发光的「怪物币」绿宝石，最多显示 3 组，描述写明真实总数。出场期间不显示，入账时只对本人提示并播放经验球音效。不能丢出、转赠或放进容器 |
| 伤害收益 | 对合法在赛人类每造成 1 点实际伤害（生命加伤害吸收的减少量）记 1 枚，按每次出场、每名人类分别累计小数并取整。每名人类每次出场最多计入 20 点，计入后乘悬赏倍率。来源与击杀复生奖励相同：近战、箭、苦力怕爆炸／药水云、随从 |
| 悬赏倍率 | 1 + 维度加成 + 存活加成，上限 ×2.5（两者相加而非相乘）。维度按人类受击时所在维度：下界 +0.5、末地 +1。存活按人类本条命在线存活时长：满 10 分钟 +0.25、满 30 分钟 +0.5；开局、复生和中途加入都从 0 计，离线和挑战暂停期间不计。存活档位在伤害提交时判定。倍率高于 ×1 的可追猎目标，在营地庭院模型名牌上显示「悬赏 ×N」 |
| 其他收益 | 每次成为怪物送 6 枚；出场中被人类的直接攻击击杀 +5。击杀人类不给怪物币，只照常每名受害者 +1 次复生。环境死亡、击杀怪物或普通生物没有收益 |
| 复生优先 | 持有复生次数的营地怪物不能追猎、在展位选角、向女巫购买或开启宝库，营地行动栏和这些入口都会提示前往复生祭坛。出场途中获得复生次数（击杀人类或管理员发放）时立即结束本次出场传回营地，随身世界物资按归返结算。若召回生效前，这具身体已在另一次伤害中被击杀，该死亡视为已结束出场的结算，不再给阵亡奖励，也不会重复结束出场 |
| 入账方式 | 伤害先在服务端内存中汇总，约每秒提交一次；死亡与屠龙结算前按该结算的时间先行提交，正常停服时也会提交。归返、断线或被召回后才提交的伤害仍记入原出场并受原出场的上限约束，下一次出场开始后不再接受旧出场的收益。崩溃最多损失约 1 秒的伤害收益 |
| 商人 | 怪物营地的女巫只发数据包、不是活体。必须先在展位确认本次角色，右键打开原版交易界面，按角色显示货架。从结果格取走时才提交扣币，提交成功后商品作为订单写入存档，营地背包只显示投影 |
| 价格 | 同一商品每次出场窗口内每买一次价格翻倍，买满显示原版售罄；出场结束后重置。成年僵尸蛋 6 起限 3 枚，幼年僵尸蛋 16 起限 2 枚；迅捷 3:00 价 10、抗火 3:00 价 6，各限 1；再生 0:45 价 8 限 1，仅苦力怕（原版亡灵不受再生影响）；缓慢、剧毒药箭每组 4 支，8／10 起各限 2 组，仅骷髅；带电出场 40 限 1，仅苦力怕；试炼钥匙 15 起限 2、不祥试炼钥匙 40 限 1，仅僵尸和骷髅 |
| 生命周期 | 已购消耗品只在下一次出场带入：额外的蛋叠加到角色蛋上，药水效果出场时生效，药箭放入背包。出场结束（归返、阵亡、断线）时剩余全部清除。出场时未开启的钥匙按实付价退回。更换角色时，新角色买不到的已购商品按实付价退回 |
| 宝库 | 营地有普通、不祥两台原版宝库。原版宝库自身逻辑在营地停用，改为对每位观察者单独发包：靠近时轮播其当前角色奖池，手持对应钥匙右键后先在服务端抽取并写入存档，再播放原版开启、弹出和拾取动画。原版试炼钥匙打不开 |
| 宝库奖池 | 槽位在 4 件护甲和武器中均匀抽取。护甲材质沿用 `Mob.getEquipmentForSlot` 的 6 档（皮革、铜、金、锁链、铁、钻石），不含下界合金。普通宝库起点 0–2 档、3 次各 10.87% 升档、50% 附魔且输入 5–30；不祥宝库起点 2–3 档、3 次各 25% 升档、必定附魔且输入 15–30。僵尸武器：普通为铁剑／铁矛／铁铲 1/6、1/6、4/6，不祥为铁剑／铁矛各半；骷髅武器为弓。附魔候选与出生装备相同 |
| 宝库装备 | 只用于一次出场。出场时适用于当前角色的全部装备带入：每个槽位穿最新抽到的一件，其余作为绑定备用件放进背包；不适用的装备留在营地，切换到能用的角色时再带出，换轮清除。营地最多存 16 件 |
