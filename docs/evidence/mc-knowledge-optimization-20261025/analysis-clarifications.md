# 分析实现补充说明

以下调整发生在正式样本运行期间，只改变可观察日志的分析与导出；未改参与者提示、分组、CLI、skill、随机顺序、超时或首次结果保留规则。预注册 protocol.md 保持原字节。

1. 原生工具输出有时是多段文本数组。既定 `tool_output_tokens_o200k` 对非字符串输出做JSON序列化后估算，包含存储表示的转义开销，因此不能准确称为模型所见净正文token。保留这个既定指标，另外增加 `tool_output_decoded_text_tokens_o200k`：解码原生文本段后逐段估算，仍包括工具包装，仍不是原生计费量。主上下文结论使用原生 `peak_input_tokens`；两种估算均可复算，不混用。
2. 原生外层 functions.exec 经常批量调用多个子命令，原审计将这些输出保守标为unknown。增加CLI的 `item.completed/command_execution` 事件级核验，只静态解包标准shell -c/-lc，使用该子命令的精确aggregated_output。复杂shell、重定向和无法对应的输出继续unknown；帮助和doctor单列，不放进业务采用率分母。原外层审计保留。
3. 结束态增加最初输入文件SHA复核，用于识别参与者是否改写CLI、skill或配置；只记录，不修复、排除或替换样本。
4. 答案盲评分批交付已经完成的case；case映射和量表始终固定，两位评分者互不读取结果、组别或成本。未开始case不评分，最终覆盖全部27份首次结果。

上述辅助分析不用于选择有利样本，也不替代或隐藏既定指标。分析脚本与测试随证据包保存。
