冻结于正式参与者运行之前；参考答案不进入参与者目录。

## 对照

- J：最终 CLI，默认 JSON，旧 skill。
- O：最终 CLI，compact，旧 skill。
- S：最终 CLI，compact，新 skill。
- O − J 估计输出格式及其总预算的整体影响；S − O 估计在 compact 基础上的 skill 调整影响。错误引导改进在三组共有，收益不单独估计；J 不是未经修改的旧 CLI。
- T1 复用此前骷髅／狼题和冻结量表；T2 铁傀儡伤害；T3 普通／试炼刷怪笼。每题每组3次，共27次。
- 固定随机种子20261025；9个题目×重复波次打乱，每波3组随机顺序启动且并发。模型必须以原生记录核对 GPT-6.1 Sol / high。
- 三组公共提示、配置、最终 CLI、原版JAR一致；只有格式环境和 skill版本按组变化。每次独立空生成缓存，原始Gradle缓存和OS/网络缓存共享且不清空。
- 主分析保留每个分配样本的第一次结果，包括失败、超时、部分答案及协议偏离。不自动重跑或补样；额外诊断若有，单独报告。

## 指标

1. 原生逐请求 input_tokens 的峰值：描述单请求上下文规模。另列首请求、请求次数、累计原生 input/output/cache tokens，避免把累计用量或缓存量称为单次上下文。
2. 可见工具返回文本的 o200k_base token估算：包含外层工具包装，非原生计费token；同时保留字符数与调用次数。
3. 从进程开始到退出的墙钟耗时，包含网络、工具和并发扰动，不据单次排名作普遍性能承诺。
4. 冻结题目量表的事实与覆盖90分、证据10分。两位独立评分者只读匿名最终答案和相应参考，不读分组/成本/对方评分。报告两人均分、评分差异和影响结论的错误，不按长短或自信程度打分。
5. 执行失败、模型/effort隔离核验、格式采用、显式异格式覆盖、无法确认的复杂调用和输出截断单独记录。实际采用不确定不能按环境变量直接假定正确。

主表按题给出每组3次中位数和全部逐次值，并给出全9次的中位数。各题配对重复的差值作为补充；小样本不做显著性或普适性声明。若收益在题目间反向，明确列出。未完成样本质量仍计入主样本；未定义的耗时/用量保留缺失，并报告分母。

另做固定6个有效源码/数据查询的确定性JSON/compact重放，用字符和估算token说明输出层的直接变化。它与模型自适应调查路径分开，不当作LLM成本节省的替代。新实验不追加量化噪声评分，避免在主质量盲评中混入格式可见的过程评判。

## 验证与交付

正式运行前通过针对输出、游标、告警、来源、参数和错误引导的单元测试，以及冻结旧CLI与新CLI真实查询语义兼容检查。先完成独立短预检以核对模型/effort及工具子进程格式继承；预检不进入27次主分析。

所有可观察工具调用、返回、最终答案、原生数值用量、冻结输入、评分和汇总可复核。私有推理、私有系统指令、凭据和原始会话不公开导出。缓存引用所需证据保存为可移植档案。无需真实客户端、服务器或浏览器验证；本次不启动这些测试。
