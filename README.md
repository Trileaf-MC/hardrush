# HardRush

HardRush 是面向原版客户端的多人速通挑战模组。主要特性如下：  

## 榜单和荣誉

模组会统计每一轮的获胜玩家名单和耗时，并在下一轮中给予历届获胜玩家不同等级的荣誉反馈。  

快来竞争成为服务器里史上最快速通之王吧！  

## 亡灵追猎

死亡后的玩家可以化身不同种类的原版怪物追猎未被淘汰的玩家，并通过击杀获得再次作为人类参赛的资格。

追猎中对人类造成伤害、甚至英勇战死都能赚到「怪物币」，活得越久、越接近通关的人类悬赏越高，回到营地后可以向女巫商人换取刷怪蛋、药水、药箭或闪电苦力怕形态，还能用试炼钥匙在宝库里抽一件原版怪物会穿的装备。越积极追猎，下一次出场就越难缠！

友情提醒：初始时你可能只是一只原版的普通僵尸，但会随着不同的活动变得越来越强！

体验一下成为一只 ～～平平无奇～～（并非）的 MC 僵尸是什么感觉！  

## 本地测试服

需要 Java 25。在仓库根目录运行一条命令，就会从当前源码构建模组，并在 `test-server/<实例名>/` 里启动一个已装好 HardRush 和 Fabric API 的 26.3 服务端。

```bash
./test-server.sh                     # macOS / Linux / WSL
test-server.cmd                      # Windows（参数相同）
```

常用参数（`--help` 查看全部）：

| 参数 | 作用 |
| --- | --- |
| `--reset world` | 只删除存档，保留配置、白名单、OP 和 mods |
| `--reset all` | 实例恢复为全新状态，只保留已下载的原版服务端和依赖库，不会重新下载 |
| `--instance NAME` | 使用另一个独立实例，默认 `default` |
| `--port` / `--seed` / `--memory` | 端口（默认 25565）、新存档种子（默认 `3leaves`）、最大内存（默认 2G） |
| `--mode normal\|hardcore` | 新一轮的初始模式，默认 `hardcore` |
| `--offline` / `--online` | 关闭／开启正版验证 |
| `--no-competition` | 关闭比赛运行时 |
| `--no-build` | 不重新构建，直接启动 |

除 `--reset` 和 `--no-build` 外，其余参数会记在实例的 `server.properties` 和 `launch.properties` 里，之后不用重复传。每次启动时只替换 `mods/` 里的 HardRush 和 Fabric API，你自己放进去的其他模组会保留。控制台输入 `stop` 即可正常保存并退出。

新实例和 `--reset all` 使用 [默认服务端配置](gradle/test-server.properties)：困难难度、固定种子 `3leaves`、正版验证开启、白名单关闭、出生点保护 16 格、空服 60 秒后暂停，以及三葉Leaves 的彩色服务器介绍。管理密钥由 Minecraft 为各实例独立生成。已有实例的配置会保留，`--reset world` 也不会重新套用默认配置；命令行参数优先于默认值。

## 建设自己的大厅（大厅工坊）

准备大厅的建筑和功能都可以在游戏里自己做，做好后打包成一个 `.hrlobby` 文件，自己安装或分享给别的服主。全程用原版客户端，工具都是原版物品和箱子菜单。

### 谁能做什么

| 操作 | 需要 |
| --- | --- |
| 打开菜单、新建草稿、进入工坊搭建、绑定功能、把建筑文件贴进草稿 | 2 级 OP |
| 发布草稿、删除草稿、从存档或建筑文件新建草稿、安装大厅包、回到上一个大厅 | 4 级 OP |

在营地里输入 `/hardrush lobby` 打开菜单，之后全部点选。

### 搭建

1. 菜单里选一个草稿，或者“新建草稿”：可以从当前大厅复制、从空白开始、从包库里的某个大厅包复制，或从存档、建筑文件导入（见下）。第一次打开菜单时会自动从当前大厅建一份。
2. “进入”后你会被传进这个草稿的独立世界，切到创造模式，背包里只有**工坊工具箱**（第 9 格）和**绑定杖**（第 8 格）。原版命令（`/fill`、`/clone` 等）照常可用，装了 WorldEdit 也可以直接用。离开时背包、经验、生命和模式都会恢复成进入前的样子。
3. 只有本轮处于准备、等待或倒计时阶段时能进工坊；开局时里面的人会被送回营地，草稿保留。
4. 建造范围就是草稿世界的世界边界，默认 256×256，可在工具箱里调整中心和直径。

### 绑定功能

大厅的功能（集结区、怪物庭院、复生祭坛、规则、战绩、角色展位、女巫商人、宝库、翻页、各类落点、追猎目标展位、状态牌、署名牌）都用**标记**来指定。标记是一个小盔甲架，头上戴着代表该功能的物品，名牌写着功能名，放在哪里就在哪里生效。创造模式下打一下就能删掉。

- **工具箱**里按类别领取标记物品，像放盔甲架一样放下即可。
- **绑定杖**右键一个方块，选“把这个方块绑定为…”，会在方块上方放好标记；也可以选“在这里创建点击范围”，放一个看不见的点击框再选功能。右键一个实体（盔甲架雕像、物品展示框、展示实体等）可以直接给它绑定或解除功能。
- **区域**（集结区、怪物庭院、祭坛踏板）有两种：
  - 连片：把标记放在地板上，与它脚下方块同材质、同一层连在一起的地板都算。手持其他方块右键标记，可以把那种方块也算进来。
  - 方框：空手右键标记打开菜单，调整宽、高、深。
- 同一个功能可以放多个，例如几个规则讲台、几处集结区。宝库必须是对应的宝库方块，祭坛光柱必须是遮光玻璃，状态牌和署名牌必须是告示牌或文字展示实体；其他点击功能可以绑在任何方块或实体上。
- 标记周围会显示粒子，有问题的标记显示红色。屏幕上方的 Boss 栏显示“还缺 N 项”，工具箱里的“验收清单”列出每个问题，点一下就传送过去。
- 工具箱里的“步行预览”切到冒险模式，可以检查走位、跳跃和门。功能本身要安装到正式大厅后才能试。

大厅里玩家可以开关门、活板门、栅栏门，按按钮、拉拉杆、踩压力板，敲音符盒和钟，红石信号也会照常传递；放置、破坏方块，活塞，以及打开箱子等容器都不行。

### 发布、安装与回滚

1. 4 级 OP 在草稿页点“发布”。发布前会检查一遍；有错误会列出来，不会生成文件。警告（例如“安装时将被移除”的内容）不影响发布。确认作者名单后，大厅包写到服务端的 `hardrush/lobby/packs/<草稿名>-v<版本>.hrlobby`。
2. 在菜单的“大厅包库与安装”里选一个包安装。新大厅会先在后台建好，等本轮回到准备或等待阶段时再切换，切换时大厅里的人会被传到新大厅。
3. 不满意可以选“回到上一个大厅”。
4. 如果大厅包缺少新版本模组要求的某个功能（例如它做好时还没有这个功能），安装时会在中央落点旁自动放一个临时设施，并告诉 OP 缺了什么。

### 安装别人分享的大厅包

把 `.hrlobby` 文件放进服务端的 `hardrush/lobby/packs/` 文件夹，然后在包库里安装。包库会列出每个包能否安装、问题和警告。

安装时会清洗包里的内容，以免陌生人的大厅包带来风险：

- 命令方块、结构方块、拼图方块、刷怪笼、试炼刷怪笼、末地传送门、屏障等方块会被去掉；
- 所有容器会被清空，告示牌和名字里的点击命令、悬停内容会被去掉；
- 只保留盔甲架、物品展示框、画、展示实体和点击范围这几类实体；
- 方块实体或实体数量过多、文件过大或格式不对的包会被拒绝。

### 导入已有的大厅

已有大厅的话，不必在工坊里重建。把文件放进服务端的 `hardrush/workshop/import/`，4 级 OP 在“新建草稿”里选择：

- **整个存档**：放进存档文件夹（或只含 `region/` 的文件夹）。会复制主世界的区块，坐标不变。存档常带着整片地形，可以在工具箱里用“底部高度设为脚下”排除地下部分，用“清除生物”去掉生物，用范围设置缩小边界。
- **建筑文件**：`.schem`（WorldEdit／FAWE）、`.litematic`（Litematica）、`.nbt`（原版结构方块）。建筑会居中放在 `(0, 64, 0)`；只导入方块和方块实体，不导入实体，不支持旋转和镜像。在工坊里也可以用工具箱把建筑文件“贴”到自己脚下（没有撤销）。
- `.mcfunction`：放进数据包，在工坊里执行 `/function` 即可。
- 旧版 `.schematic`（1.13 之前）：先用 WorldEdit 载入再另存为 `.schem`。

导入不会带来任何功能绑定，导入后照常放标记、发布。

### 默认大厅

模组自带的默认营地也是一个大厅包：`platforms/mc263/src/main/resources/hardrush/lobby/default.hrlobby`，与服主自己的大厅包走同一条安装路径。以后要改默认大厅，就在工坊里打开默认草稿修改并发布，再用发布出的包覆盖这个文件。
